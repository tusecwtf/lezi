# 布局编辑态：安卓桌面式图标拖动

| 字段 | 值 |
|------|-----|
| **Date** | 2026-07-29 |
| **Status** | Spec + Implementation |
| **Related** | `CONTEXT.md` 布局编辑态 / 常用记录 / 本机已删除；`docs/prd/ui.md` §2.2、§5.2；ADR-0006 |

## Overview

将「常用四槽 + 所有记录 + 本机已删除」的布局编排，从**二级长 `AlertDialog` 列表**改为记录页就地的**全屏编辑画布**：四列图标网格、跟手拖放、落点替换/互换，交互对齐安卓桌面编辑布局。

## Goals

1. 去掉长弹窗，进入编辑态后短按不写记录，「完成」或系统返回退出。
2. 所有记录按分类四列图标网格展示（视觉对齐「更多」）。
3. 长按拖动：目录 → 槽绑定/替换；槽间互换；拖出坞外清空快捷；拖入本机已删除隐藏；已删除拖回恢复；类内拖到落点排序。
4. 保留本机-only 布局契约（ADR-0006）；不恢复设置里的槽位/全量项目对话框。

## Non-goals

- 完整启动器（多页、文件夹、壁纸、重度 jiggle）。
- 「更多」占槽或可拖。
- 跨记录类别改变领域分类。
- 家庭同步布局。

## Surface

| 包含 | 不包含 |
|------|--------|
| 记录 Tab 全屏布局编辑画布 | 设置 → 记录设置内的布局入口 |
| 长按坞（非更多）/ 更多内项目长按进入 | Widget 快捷配置（独立路径） |
| `warm` / `journal` 同一画布 | 搜索页 |

## Interaction matrix

| 源 | 落点 | Intent |
|----|------|--------|
| 目录项 | 槽 | `AssignToSlot` |
| 已绑槽 | 另一槽 | `SwapSlots` |
| 已绑槽 | 坞外且非删除区 | `ClearSlot` |
| 目录/已绑槽 | 本机已删除 | `MoveToLocalDeleted` |
| 本机已删除 | 删除区外 | `RestoreFromLocalDeleted` |
| 目录项 | 同 section 另一图标 | `ReorderItemInSection` |
| 目录项 | 异 section 图标 | 忽略 |
| — | 完成 / 返回 | 退出编辑态 |

## Visual feedback

- **纯图标启动器形态**：大方图标 + 短标签，无文字列表、无 ↑↓、无槽位「×」。
- 进入编辑态图标轻微 jiggle；长按后源位弱化；**浮层图标**跟 pointer。
- 悬停坞槽 / 删除区描边高亮；拖到坞槽即替换/互换。
- 删除区用 ⌫ 图标托盘，不用长说明文。

## A11y

- 热区 ≥ 48dp；完成、各图标名称、删除区可读。
- 拖动手势对 TalkBack 弱；清空主要靠拖出坞外。

## Implementation notes

- 纯逻辑：`LocalLayoutEditPolicy` / `QuickRecordSlots` / `RecordCatalogOrder.moveCatalogKeyToIndexInSection`。
- UI：`LayoutEditCanvas` 替换 `LayoutEditModeDialog`；`LogScreen` 编辑态全屏替换内容区 + 日常坞。
- 测试：既有 drop/reduce 测试保留；补 reorder toIndex。
