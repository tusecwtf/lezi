# 布局编辑态：与“添加记录”同源的四列卡片目录

| 字段 | 值 |
|------|-----|
| **Date** | 2026-07-29 |
| **Status** | Implemented |
| **Related** | `CONTEXT.md` 布局编辑态 / 常用记录 / 本机已删除；`docs/prd/ui.md` §2.2、§5.2；ADR-0006 |

## Overview

将「常用四槽 + 所有记录 + 本机已删除」的布局编排，从**二级长 `AlertDialog` 列表**改为记录页就地的**全屏编辑画布**。编辑目录以当前“添加记录”为视觉权威：复用四列圆角卡片、柔色图标底板、分类标题、排版和主题 token；拖动仍保留源位弱化、跟手卡片和合法落点反馈。

## Goals

1. 去掉长弹窗，进入编辑态后隐藏日期 chrome 与主导航 tabs；短按不写记录，「完成」或系统返回退出。
2. 所有记录按分类四列卡片展示，与“添加记录”使用同一组件和权威 token；编辑目录不重复“常用补充”。
3. 长按拖动：目录 → 槽绑定/替换；槽间互换；拖出坞外清空快捷；拖入本机已删除隐藏；已删除拖回恢复；类内拖到落点排序。
4. TalkBack 与键盘无需精确拖动即可完成同一组布局动作，且与触摸共用 `LayoutEditIntent`、reducer 和完整快照 writer。
5. 保留本机-only 布局契约（ADR-0006）；不恢复设置里的槽位/全量项目对话框。

## Non-goals

- 完整启动器（多页、文件夹、壁纸、重度 jiggle）。
- 「更多」占槽或可拖。
- 跨记录类别改变领域分类。
- 家庭同步布局。

## Interaction matrix

| 源 | 落点 | Intent |
|----|------|--------|
| 目录项 | 槽 | `AssignToSlot` |
| 已绑槽 | 另一槽 | `SwapSlots` |
| 已绑槽 | 自身槽 | 无操作 |
| 已绑槽 | 锁定“更多”或 Dock 内间隙 | 无操作 |
| 已绑槽 | 整个 Dock 外且非删除区 | `ClearSlot` |
| 目录/已绑槽 | 本机已删除 | `MoveToLocalDeleted` |
| 本机已删除 | 删除区外（包括槽） | 只执行 `RestoreFromLocalDeleted`；槽不高亮、不绑定 |
| 目录项 | 同 section 另一图标 | `ReorderItemInSection` |
| 目录项 | 异 section 图标 | 忽略 |
| 目录项 | 目录空白 / 坞外空白 | 无操作 |
| — | 完成 / 返回 | 退出编辑态 |

替代输入不建立第二套规则：目录项目的“设为常用槽 1…4 / 类内前后移 / 仅在本机隐藏”、已绑槽的“左右移动 / 清空 / 隐藏”、已删除项目的“恢复到所属类别末尾”和分类标题的“分类前后移”都直接发出上表既有 intent。键盘 Tab / Shift+Tab 与普通方向键只移动焦点；Ctrl+方向键移动项目、类别或槽，Ctrl+1…4 指派目录项，Delete 隐藏或清槽，Enter 恢复。

## Visual feedback

- 静止目录保持“添加记录”的四列卡片形态，不使用独立的桌面大图标墙。
- 长按后源位弱化；**同款卡片浮层**跟随 pointer，不切换成另一套图标表达。
- 每个 pointer 时刻只显示一个合法当前目标；悬停合法坞槽 / 删除区 / 同类排序项时描边高亮，视觉目标与最终 reducer intent 相同。
- 命中只读取当前可见节点边界；节点离开组合树、滚出可见区或重组移动后立即注销/替换旧边界，陈旧回调和陈旧 drag token 不产生 intent。
- 本机已删除区保留可读标题、明确的文字空态与恢复操作，并与底部 Dock 分区清晰。
- Dock 与日常记录页共用外边距、单元高度、图标尺寸、四槽加固定“更多”的顺序；编辑态将“更多”明确标为锁定。

## Edge auto-scroll

- 只有 `CatalogItem` 与 `CategoryHeading` 拖动源获准驱动主目录；`BoundSlot` 和 `LocalDeleted` 永远返回零速度。
- 目录视口使用窗口坐标测量。上、下边缘带最多占各半个小屏视口，速度随指针接近边缘线性增加并封顶；指针离开视口/边缘带或到达内容边界时速度归零。
- `LocalDeleted`、四个 `QuickSlot`、锁定“更多”和 Dock 内间隙的命中优先于滚动。进入任一固定区域会立即取消帧循环，但保留该区域原有投放/no-op 语义。
- 自动滚动循环仅在有效拖动 token 且速度非零时逐帧调用目录 `ScrollState`；速度、拖动 token、取消、放下或画布销毁变化都会取消旧协程，不保留后台任务。
- 滚动后的目标继续由 `LayoutVisibleTargetRegistry` 当前窗口边界解析；源节点触摸点用 `LayoutCoordinates.localToWindow` 转换，兼容滚动、旋转和缩放，不使用会过期的“窗口原点 + 局部偏移”。

## A11y

- 热区 ≥ 48dp；完成、分类、项目、槽、删除区以及固定“更多”的名称、位置/状态和可用动作可读。
- TalkBack 自定义动作覆盖指派、槽换位/清空、隐藏/恢复、项目排序和类别排序；编辑空槽只说明可指派，不提供虚假激活，“更多”可读固定/锁定但无动作。
- 键盘焦点按编辑画布源序稳定移动，普通方向键不触发布局 mutation；跟手浮层从无障碍树隐藏，不产生陈旧焦点。
- “正在保存 / 已保存 / 保存失败”使用 polite live region，并只绑定 writer 的当前最新完整快照；旧完成或失败不会播报虚假成功。

## Implementation notes

- 纯逻辑：`LocalLayoutEditPolicy` / `QuickRecordSlots` / `RecordCatalogOrder.moveCatalogKeyToIndexInSection`。
- UI：`LayoutEditCanvas` 替换 `LayoutEditModeDialog`；`RecordCatalogCard`、`RecordCatalogVisualSpec` 同时服务“添加记录”和编辑目录；`QuickDockVisualSpec` 保持日常/编辑 Dock 几何连续。`LogScreen` 通知根容器隐藏日期与主 tabs，编辑页只显示“编辑布局 / 完成”。
- 持久化：版本化 `DeviceLayoutSnapshot` 在一个 DataStore 事务内保存四槽、隐藏集合、类内序与类别序；FIFO writer 串行完整快照并让完成/返回等待最后写入。失败保留上一份耐久值并可重试，未来版本只读拒写；该状态永不进入家庭同步。
- 测试：权威 `LayoutDragSession` 覆盖完整命中矩阵、互斥目标、陈旧 token/revision 与取消；`LayoutEdgeAutoScrollPolicy` 覆盖授权来源、上下边缘速度、边界、小视口与固定目标抢占；Compose 设备测试在 320×640、放大字体的 24 项目录中验证持续滚到末项、取消后稳定与无误提交。现有 Drop Matrix、类别拖动和本机已删除设备测试继续证明精确投放/no-op；reducer/writer 断言精确顺序、槽唯一与 latest-wins。
