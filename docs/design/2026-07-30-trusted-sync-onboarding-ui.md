# 家庭服务器连接、登录与成员设备 UI/UX

- Date：2026-07-31
- Status：Active
- Product authority：[`sync-trusted-endpoint.md`](../prd/sync-trusted-endpoint.md)
- Architecture：[`ADR-0011`](../adr/0011-root-admin-and-multi-device-membership.md)

## 1. 设计目标

小白用户只需要理解三件事：连接家庭服务器、以管理员或家庭成员身份登录、记录是否已经同步。
IP、证书、token 和协议只在建立信任的必要时刻出现，不成为日常账户信息。所有入口复用同一
状态机，Onboarding 与账户页不各自维护一套登录流程。

## 2. 页面地图

```text
账户
├─ 家庭名 / 我的称呼 / 一句同步结果
├─ 家庭成员与设备
│  ├─ 成员分组与设备
│  ├─ 待确认设备（Owner）
│  ├─ 改名申请（Owner）
│  └─ 添加 / 改名 / 删除 / 撤销 / 生成成员 QR
├─ 未登录时：连接家庭服务器
│  ├─ 输入并验证 HTTPS endpoint
│  ├─ 必要时确认首次证书
│  ├─ 空实例：新建家庭
│  └─ 已有家庭：加入家庭
│     ├─ 我是家庭管理员
│     └─ 我是家庭成员
└─ 页面底部：退出这台设备 / 退出家庭 / 删除家庭

记录、汇总、成长
└─ 下拉刷新触发同步 + 一句浅状态
```

没有独立「家庭同步」页、没有「服务器与安全」页、没有仅 Wi-Fi 设置、没有迁移/恢复页、没有
管理员登录历史页。管理员设备接管属于「加入家庭 → 我是家庭管理员」。

## 3. 账户首页

### 3.1 已加入

```text
账户

家庭
我们家
我的称呼：妈妈 ★
已同步 · 2 分钟前

家庭成员与设备                         3 人 ›
                                           [2]  ← Owner 待确认角标

宝宝
……现有宝宝卡与档案……

退出这台设备
删除家庭                                  ← Owner only
```

- 普通成员不显示星号和待确认角标，底部第二项为「退出家庭」。
- 整行「家庭成员与设备」进入二级页；首页不展开成员或设备。
- 同步行只显示最后成功、待同步数量、临时失败或等待批准；无独立 action。
- 未登录或等待审批时仍保留现有本地宝宝和记录入口。

### 3.2 未连接 / 未登录

```text
家庭
记录会先安全保存在这台手机

[ 连接家庭服务器 ]
暂不连接也可以继续使用乐记
```

若已记住一个通过 probe 的服务器但尚未登录：

```text
家庭服务器已找到
https://family.example.com

[ 继续登录 ]
[ 忘记此服务器 ]
```

这里可以展示域名或用户刚输入的地址以帮助恢复任务；加入后日常账户页不再显示地址。

## 4. 连接家庭服务器

### 4.1 初始页

```text
连接家庭服务器

请输入部署乐记家庭后台的地址
[ https://________________ ]

[ 连接 ]
暂不连接，保持离线
```

- 不先问新建/加入，不出现 NAS/VPS 选择，不出现 Wi-Fi 名称。
- 仅接受完整 HTTPS origin；自动 trim，不猜测 path，不默认降级 HTTP。
- 输入只是草稿；通过证书信任和 setup probe 后才可保存为已验证 endpoint。

### 4.2 首次证书确认（自签名）

```text
确认家庭服务器证书

这个服务器的证书尚未被手机系统认识。
请向部署服务器的人确认以下指纹：

7A:91:…:4F

[ 信任此证书 ]
[ 返回修改地址 ]
暂不连接，保持离线
```

- 只显示完整可复制指纹和清楚的风险说明；不用额外校验码或配对码。
- 当前连接者明确点击「信任此证书」后立即固定 SPKI；该确认发生在角色选择、setup probe 和
  发送根密码之前，不要求先登录 Owner。建家场景下当前连接者通常是管理员。
- 已固定证书发生变化时，页面标题改为「服务器安全信息已变化」，只提供「返回账户」和
  「忘记此服务器并重新连接」；没有忽略按钮。

### 4.3 Probe 结果驱动

```text
正在确认家庭服务器…
```

| 结果 | 标题 | 主行动 | 次行动 |
|------|------|--------|--------|
| 非 Lezi / 无法连接 | `这里没有可用的乐记家庭后台` | `修改地址` | `重试`、`保持离线` |
| 版本不兼容 | `家庭服务器需要更新` | `查看部署说明` | `保持离线` |
| 未 ready | `家庭服务器正在维护` | `重试` | `保持离线` |
| empty | `这里还没有家庭` | `新建家庭` | `保持离线` |
| configured | `已找到家庭` | `加入家庭` | `保持离线` |

App 不显示 setup-status 返回的内部枚举，也不在 configured 前泄露家庭名。

## 5. 新建家庭

仅 empty 服务器可见。

```text
新建家庭

[ 家庭名称 *            ]
[ 我的称呼 *            ]  默认「管理员」，可编辑
[ 这台设备的名称 *      ]  默认 Android 设备名
[ 管理员根密码 *        ][显示]

根密码由部署家庭服务器的人保管。

[ 新建并登录 ]
暂不连接，保持离线
```

- 根密码字段默认遮蔽，离开页面立即清空，不进入自动填充/截图/状态恢复。
- 服务端再次确认仍为空；并发已建家时转入「加入家庭」，不得创建第二家庭。
- 成功后耐久保存设备 session，再执行首次完整同步；同步失败不重复建家。

## 6. 加入家庭

### 6.1 角色选择

```text
加入家庭

[ 我是家庭管理员 ]
用管理员根密码在这台设备登录

[ 我是家庭成员 ]
声明称呼，等待管理员确认

暂不连接，保持离线
```

管理员不显示「扫码登录」。普通成员可以手动申请，也可以从系统扫码入口直接进入 QR flow。

### 6.2 管理员登录

```text
以家庭管理员登录

[ 这台设备的名称 *      ]
[ 管理员根密码 *        ][显示]

[ 登录这台设备 ]
丢失设备并接管…
```

「丢失设备并接管」进入危险确认页：

```text
接管管理员身份？

所有旧管理员设备都会退出家庭；普通成员不会退出。
只有确定旧设备已丢失时才使用。

[ 确认接管 ]
[ 取消 ]
```

### 6.3 普通成员手动申请

```text
申请在这台设备登录

[ 我的家庭称呼 *        ]
[ 这台设备的名称 *      ]

管理员会看到你的申请，并决定新建成员或绑定原有成员。

[ 发送确认请求 ]
暂不连接，保持离线
```

请求成功后：

```text
等待管理员确认

已申请：奶奶
设备：Pixel 10
申请将在 23 小时后失效

[ 检查结果 ]
[ 取消申请 ]
保持离线使用乐记
```

没有倒计时动画、后台轮询或 push。App 前台、手动检查时更新；批准后自动领取设备凭证并进入
首次同步。称呼冲突时仍由管理员决定绑定旧成员或要求换称呼，不在申请端自动认定身份。

### 6.4 普通成员 QR

系统扫码入口读取一段二维码，同时获得 endpoint、证书固定材料与十分钟单次登录授权：

```text
登录家庭

已由家庭管理员授权：妈妈
[ 这台设备的名称 *      ]

将信任管理员提供的家庭服务器配置。

[ 在这台设备登录 ]
[ 取消 ]
```

- 不显示原始 QR、grant、token 或 server ID。
- 管理员 QR 说明「未安装可用系统相机下载；安装后用乐记重新扫描」；系统相机进入的邀请安装页
  不显示家庭名、成员称呼或邀请状态，也不替代乐记内的登录确认。
- grant 已用/过期时说明「这个二维码已失效，请让管理员重新生成」，可转手动申请。
- 相机权限被拒绝时仍可走手动 endpoint + 申请；不要求位置权限。

## 7. 家庭成员与设备

### 7.1 普通成员

```text
家庭成员与设备

妈妈（我）
  Pixel 10（这台设备）              刚刚 ›
  平板                              昨天 ›
  [ 申请修改称呼 ]

爸爸
奶奶
```

普通成员只展开自己的设备；其它成员只显示称呼。点自己的设备可改设备称呼；点当前设备还可
「退出这台设备」。改名申请提交一个新唯一称呼，等待管理员批准前继续显示旧称呼。

### 7.2 管理员

```text
家庭成员与设备                         [+ 添加成员]

待确认设备                                      [2]
  奶奶 · Pixel 10 · 3 分钟前                     ›
  妈妈 · 新手机 · 12 分钟前                      ›

管理员 ★
  我的 Pixel（这台设备）                         ›
  家庭平板                                      ›

妈妈
  Pixel 10                                     ›
  [ 为这个成员生成登录二维码 ]

奶奶
  暂无设备
```

待确认详情：

```text
确认这台设备

对方声明称呼：妈妈
设备：新手机

[ 绑定到现有「妈妈」 ]
[ 用此称呼添加新成员 ]    ← 称呼冲突时禁用并解释
[ 拒绝 ]
```

管理员可主动添加无设备成员，随后为其生成 QR；也可重命名成员、批准改名申请、重命名/撤销设备
或删除普通成员。破坏性 action 必须二次确认，并清楚区分：

- 撤销设备：只让这一台设备退出；
- 删除成员：身份和全部设备彻底删除，历史记录作者显示为「家人」。

## 8. 退出与删除确认

### 8.1 退出这台设备

```text
退出这台设备？

本机家庭记录和照片会被清空；你的成员身份和其它设备不受影响。
[ 退出并清空本机 ]
[ 取消 ]
```

只有服务端确认退出后才清本机；离线时提示联网后再试。

### 8.2 普通成员退出家庭

```text
退出家庭？

你的成员身份、全部设备和称呼会被彻底删除，无法恢复。
家庭记录会保留，但作者只显示「家人」。
[ 退出家庭并清空本机 ]
[ 取消 ]
```

### 8.3 管理员删除成员

确认正文与退出家庭一致，并列出设备数量。按钮为「彻底删除成员」。不出现保留旧成员或恢复选项。

### 8.4 管理员删除家庭

```text
删除整个家庭

这会删除服务器上的全部家庭数据，且无法恢复。
[ 输入家庭名            ]
[ 管理员根密码          ]

[ 永久删除家庭 ]
[ 取消 ]
```

家庭名必须规范化后精确相同。失败时不清本地；成功后当前设备清空，其它设备下次连接清空。

## 9. 记录、汇总、成长的同步反馈

用户可主动触发的「立即同步」只有记录、汇总、成长三页的下拉刷新；账户页不提供同步按钮或
独立同步页：

```text
下拉中：正在同步家人记录…
完成：  已同步 · 刚刚
离线：  已保存在本机 · 待同步 3 项
失败：  暂时无法同步 · 下拉重试
审批：  等待管理员确认
```

浅提示不占用长期卡片空间，刷新完成后回到一行次要文字。同步失败不能盖住记录主操作，也不能
阻断本地新增。回前台、本地写入成功和进入页面节流仍会静默自动同步，但都不是用户「同步
动作」，不增加额外 UI 入口；进入页面自动节流同步时不强制显示 loading 动画。

## 10. 状态机与恢复

```text
Offline
  -> EndpointDraft
  -> TrustDecision?
  -> Probing
     -> ProbeFailed | ServerUpdate | ServerMaintenance
     -> EmptyServer -> CreateFamily -> FirstSync -> Joined
     -> Configured -> RoleChoice
        -> OwnerLogin | OwnerTakeover -> FirstSync -> Joined
        -> MemberRequest -> PendingApproval -> FirstSync -> Joined
        -> MemberQrLogin -> FirstSync -> Joined

Joined
  -> CredentialLost -> Reapply (keep local data)
  -> TrustMismatch -> Blocked (send nothing)
  -> DeviceRemoved | MembershipDeleted | FamilyDeleted -> ClearLocal
```

进程重建只恢复非敏感地址草稿、可信 endpoint、pending request ID 与 device session；不得恢复
根密码、QR grant、access token 或未提交的危险确认。首次 pull 失败保留已签发 session，只重试
同步，不重跑建家、登录或审批。

## 11. 无障碍与隐私

- 所有触控目标至少 48dp，正文支持 1.3× 字号而不截断，危险按钮不能只靠红色表达。
- TalkBack 先读状态与后果，再读 action；角标有「2 个待确认设备」语义。
- 只在用户选择扫码时请求相机；不请求位置来读取 SSID。
- 根密码、token、grant 和 QR payload 不进入日志、截图、analytics、SavedState 或剪贴板默认值。
- QR 展示页使用 `FLAG_SECURE`；显示剩余有效时间，但不制造伪精确秒级倒计时。
- 网络错误使用中性提示；证书变化、接管、删除使用明确危险语义。

## 12. 测试设计 seam

- 共享 family auth reducer/state machine 覆盖所有状态、取消、进程恢复与 effect 幂等性；
  Onboarding 和 Account 仅是 caller。
- Compose semantics 覆盖角色可见性、待确认角标、只展开本人设备、危险确认与大字体。
- credential loss 与明确删除分别验证「保留本地」和「清空本地」，不得共用模糊 401 分支。
- 两设备黑盒 smoke 覆盖管理员登录、成员申请批准、多设备绑定、QR 单次使用、同步浅状态与撤销。

## 13. 拆票边界

（见 git 历史）；尤其不应再实现独立同步/安全页、Wi-Fi 偏好、管理员 QR 登录或客户端迁移 UI。
