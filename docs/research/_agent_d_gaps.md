## 一、可确认的补强（Confirmed / Cross-checked）

### 1. 共享：人数

| 项 | 结论 | 可信度 |
|----|------|--------|
| 人数上限 | **官方口径无硬性上限**；夫妻为主，亦见双方祖父母共 5+ 人实操 | `[官方访谈]` + `[二手]` |

- BabyTech 官方访谈（PiyoLog 公关）：被问「共有人数有上限吗？」→ **There is no upper limit**；一般夫妻，也有与双方祖父母共享的用户。  
  来源：https://babytech.jp/en/2021/04/piyolog/
- 官方 FAQ：可与实母/義母等共享（不仅限伴侣）；**不可**别世帯合并两套日志。  
  来源：https://piyolog-official.blogspot.com/2020/12/q.html
- 二手：明确写「人数制限はない」；5 人以上案例存在；实用建议 3–5 人同步更稳。  
  来源：https://kosodateeell.com/piyologshare/ ；https://kosodate-update.com/app-piyolog-share-data/

**克隆建议**：不硬编码人数上限；产品文案写「家庭规模无上限」，工程可设软告警阈值。

### 2. 共享 / 不共享内容边界

| 共享（家庭域） | 不共享（本机/本用户） |
|----------------|------------------------|
| 全部育儿记录（授乳・睡眠・排泄・体温・日记等） | 主题色、图标风格 |
| 自定义项目（最大 10）及名称 | 记录项目显示/隐藏、排序 |
| 输入候选 / サジェスト（メモ等历史文案） | 暗色/ナイトモード |
| | 下次授乳通知 / 授乳间隔（**各机独立**） |
| | Widget、时间制（12/24h）等操作偏好 |

- 官方 FAQ：
  - **不可部分字段隐藏共享**（「一部の情報だけを共有」→ 否）
  - 伴侣新记录 **无推送通知**
  - 解除：メニュー > アカウント > 共有中のユーザー > 共有を停止する  
  来源：https://piyolog-official.blogspot.com/2020/12/q.html
- 二手交叉列表与 FAQ 一致，并强调「下次授乳通知」不随共享同步。  
  来源：https://kosodate-update.com/app-piyolog-share-data/ ；https://kosodateeell.com/piyologshare/

**共享码细节（二手，操作路径多源一致；官方仅确认「共有用コード」流程）**：

| 项 | 二手结论 | 状态 |
|----|----------|------|
| 路径 | アカウント → 共有用コードの発行（ぴよログ ID + 码 / QR / 邮件） | 与 FAQ 路径一致 |
| 码位数 | **8 位** | `[二手·交叉]`，未见官方静态页写死 |

  来源：https://kosodate-update.com/app-piyolog-share-data/ ；https://kosodateeell.com/piyologshare/ ；https://higuma-papa.com/piyolog_datashare/

**克隆建议**：共享码短时效（可配置，默认 24h）+ 8 位数字；QR 优先；已有数据设备二次确认后覆盖/清空再加入。

### 3. 管理者权限（二手细化 + 官方可核验部分）

| 能力 | 管理者（亲用户） | 参与者 |
|------|------------------|--------|
| 数据编辑/删除 | **全部**数据 | **自己输入**的数据 |
| 增删共享用户 | ✓ | × |
| 移交管理权 | ✓（付与） | × |

### 14. 声控计时器 vs Siri / 语音助手（官方区分清晰）

| 通道 | 能力 | 平台 | 来源 |
|------|------|------|------|
| **App 内声控授乳计时器** | 打开计时器后说「左」「右」「ストップ」控制计时 | **仅 iOS**（Speech Recognition）；iOS 14.5+；设置「音声での操作」ON；需 Siri 可用状态；**Android 不可用** | https://prtimes.jp/main/html/rd/p/000000013.000019025.html |
| **Siri / Google 助手 / Alexa** | 语音 **录入记录**（おしっこ、ミルク ml 等） | 多平台（各助手） | FAQ / 商店 / BabyTech |

   相关：https://piyolog-official.blogspot.com/2020/11/blog-post.html

## 七、方法与诚实边界

1. **未编造**任何未在源中出现的官方声明。  
2. 价格以 **商店订阅列表公开数字** 为「近官方」，**不等于** 开发者官网定价页或应用内实时价截图。  
3. 设计复盘（note）按 **近一手用户/设计师观察** 使用，不升格为官方 PR。  
4. 负向结论（中国商店无官方包、无 App 锁证据、无挤奶库存）= **检索未找到**，非「官方否认」。  
5. 关闭「便便枚举」的关键依据是 **piyolog.com 记法规范** + **官方 X 功能说明**，可直接服务数据模型。
