# Android 原地升级永久保留已承诺的本地数据

从 Android 0.3.0（versionCode 6、Room v24）的本地数据契约 v1 起，后续 APK 必须提供连续、
幂等且可校验的相邻迁移链；迁移前只快照会被修改的 Room、设置、家庭凭证或媒体域，空间不足、
迁移失败或校验失败时保留原数据与快照并阻断全部业务入口，绝不自动回退为清库。已校验的
持久化 journal 允许进程在迁移写入中断后重放同一幂等步骤；契约账本将永久兼容下限锁定为 v1，不得在
后续发版中抬高。应用内安装还
必须在交给 PackageInstaller 前确认目标 APK 声明的可迁移范围包含当前契约。用户仍可在稳定
恢复界面经过两次确认调用系统清除本机数据；0.3.0 之前的数据不纳入永久兼容承诺，但同样只能
无破坏阻断。该决定取代 ADR-0008 的 Android 本地持久化部分；NAS schema 和同步 wire 继续
fresh-current。
