# 家庭身份用设备 membership 称呼，账户首屏只做家庭概览

家庭协作身份绑定在设备 membership 的**家庭称呼**上（自由文本，建家/加入硬必填），不引入跨设备「照护者」实体；同人多机呈现为多个成员。家庭另有**共享家庭名**（仅管理员可改，可空并用兜底），全员所见一致。记录上传者按写出该记录的 membership 解析；时间轴仅在非本人时展示对方当前称呼（跟当前名，不写历史快照）。账户 Tab 首屏只呈现家庭名、成员人数、宝宝与一句结果导向的同步状态；成员名单二级展开，服务器/Wi‑Fi/立即同步/离开删除进网络设置二次界面；未加入用「新建/加入」家庭向导，已加入管理员主行动为「邀请家人」。

## Considered Options

- 照护者一等身份（多设备合并为一人）：能统一同人双机，但需新身份层与迁移，首版不做。
- 家庭名仅本机别名：实现快，但成员之间对不齐，违背「相互了解」。
- 账户首屏保留三步同步引导与成员全列表：身份更直给，但把小白卷进网络运维话术。

## Consequences

- NAS `families` 需持久化共享 `name`（或等价字段），并在成员可见的家庭摘要/会话中下发；改名权限仅 owner。
- 建家/加入 API 的 `display_name` 在产品层为必填；客户端不得上传「我（本机）」占位名。
- 时间轴与成员列表依赖 membership → 当前称呼的解析；离线或无名时用角色/「家人」兜底，不把本机占位名展示给他人。
