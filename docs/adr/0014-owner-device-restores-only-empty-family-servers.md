# 只允许旧 Owner 设备恢复空家庭服务器

乐记允许仍保留旧 Owner 身份与完整本机护理副本的设备，把数据灾难恢复到经过可信 TLS
验证的空服务器；恢复在服务器 staging 中完整校验后一次激活，新家庭历史作者统一归新 Owner。
这取代“客户端不提供恢复”的旧边界，但不把客户端变成多主迁移工具：普通成员不能恢复，已配置
服务器不能作为目标，两个既有家庭不能合并，旧 endpoint 的凭证也绝不发送给候选服务器。

## Consequences

- Room/Outbox 继续是离线工作的本机事实；恢复成功前旧 endpoint、会话和本机数据都不改变。
- 根密码只验证恢复开始和提交；中间使用限时可撤销凭证与 `/data` 持久 staging/journal。
- 服务器 SQLite current schema 与 `user_version` 不因恢复协议改变；恢复以 current wire 数据集
  构造一次新的家庭，而不是导入旧身份、设备、申请、设置、墓碑或游标。
- ADR-0010 中“灾难恢复要求完整身份备份”的历史假设不再适用；服务器完整数据根搬迁仍是
  运维路径，设备恢复只是 Owner→空服的最后救援路径。
