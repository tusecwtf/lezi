# 系统日历采用三级内容披露

系统日历副本由用户在当前设备选择披露级别：仅显示“乐记 · 护理计划”、显示“宝宝昵称 · 记录类型”，或在基本信息之外把文字备注写入描述；首次启用时默认预选第二级“宝宝昵称 · 记录类型”，但仍要求用户在授权流程中看到并确认。Android 标准日历事项没有可移植的照片附件字段，因此最高级别只显示“照片 N 张，打开乐记查看”，并通过应用 URI 返回乐记预览；照片文件仍只保存在乐记与家庭 NAS，不上传给系统日历账户。

用户首次主动启用系统日历副本时授予权限并明确选择一个可写日历，应用不静默采用默认账户。目标日历与披露级别保存在当前设备；权限撤销或目标日历消失只导致副本写入失败并显示提示，不得阻断乐记护理计划的本地保存与家庭同步。

安排未来护理时，“同步到系统日历”单条开关默认开启；当前设备尚未完成权限、目标日历和披露级别配置时，点按该开关进入设置流程，取消设置仍允许护理计划正常保存。

每台设备只为同一计划保留一个提醒来源：系统日历副本及其开始时提醒经严格回读确认就绪时，乐记不重复安排通知；系统日历未启用、权限被拒，或 provider 已确认旧提醒释放/不存在时，才由乐记回退为本机非精确提醒。若 provider 写入结果不确定或仍持有旧提醒，设备保持 provider 单源并把投影标为待恢复，前台/重启后继续收敛，禁止同时启用乐记提醒。家庭中的其他设备按各自本机设置独立决定。

修改本机披露级别时只更新尚未发生的系统日历事项，不批量扩大已完成或已过期事项的历史披露。

所有家庭成员设备默认提醒共享护理计划，但每台设备可单独关闭且该偏好不上传。任一成员履行后，其他设备在下次前台同步时取消提醒；离线或未回前台设备可能仍发出一次旧提醒，产品不为此引入后台轮询或推送。
