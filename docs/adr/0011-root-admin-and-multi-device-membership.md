# 根密码声索唯一管理员，成员与设备分层

每个家庭只有一个 Owner membership。`LEZI_BOOTSTRAP_SECRET` 是声索、登录或恢复该 Owner
身份的唯一根密码，但不作为日常 API Bearer token；登录成功后，服务器给每台管理员设备
签发独立、可轮换、可吊销的 opaque access/refresh token。管理员可选择添加一台设备，或在
设备全部丢失时接管并撤销此前所有管理员设备。更换部署环境中的根密码并重启服务会撤销全部
管理员会话，但不影响普通成员会话。

普通 membership 表示一个家庭成员而不是一台设备，并可绑定多台设备。家庭称呼在当前
家庭内唯一；新设备可以声明称呼申请加入，但只有管理员的明确批准或管理员 App
生成的单次二维码授权才能把设备绑定到既有 membership。`membership_id`、家庭称呼和设备名
都不是凭据。产品不引入全局 User、设备私钥、签名挑战、Android attestation 或普通成员继承
管理员的机制。

生产连接只在系统 PKI、当前连接者明确接受并固定的 TOFU/SPKI，或 Owner QR 传递的 pin 之后
发送根密码或设备凭证。自签名首次连接的证书确认发生在角色选择和 setup probe 之前。SSID、
IP/端口可达、ping、health 文本与 server ID 文本都不建立身份。App 不承担 NAS 到 VPS 的
迁移协议；服务端部署可搬迁同一数据库，但 endpoint 改变后各设备仍走普通登录或审批。
普通镜像 CD、回滚或容器重启不属于 TLS 身份生命周期，必须保留已有证书与私钥；有意轮换
证书是独立授权的维护操作。证书变化测试只能使用自建隔离服务，不得借真实家庭 NAS 验证。

成员删除是身份硬删除：membership、设备、凭证与申请一并删除，称呼立即可复用；既有家庭
事实保留，但作者引用清空并显示「家人」。单台设备删除只撤销该设备。显式成员、设备或家庭
删除会在设备下次可信连接时要求清空本地家庭数据；普通凭证丢失或失效则保留本地数据并重新
申请，不把无法保证的远程即时擦除当作安全承诺。

## Considered Options

- **一设备一 membership：** 实现较简单，但无法表达同一成员多设备的「本人」权限，也让称呼
  重复和设备更换变成伪成员；拒绝。
- **membership ID 或同名即可补发凭证：** 体验顺滑，但公开标识和显示名无法证明调用方；拒绝，
  必须由管理员批准或单次授权。
- **设备私钥、DPoP 或系统 attestation：** 可增强持钥证明，但恢复、跨设备与兼容成本超过家庭
  自托管模型；本阶段使用可信 HTTPS 与独立设备会话。
- **多个管理员或成员投票恢复：** 能减轻根密码丢失，但引入权限转移与共识模型；拒绝。服务器
  运维者通过更换根密码恢复唯一 Owner。
- **保留成员墓碑与历史称呼：** 有利于审计，但与用户要求的彻底删除冲突；只允许无身份信息的
  短期 token-hash 吊销标记。
- **客户端迁移 handoff：** 能隐藏地址变化，但扩大协议和 UI；拒绝。部署负责数据搬迁，设备重新
  登录或申请。

## Consequences

- 服务端数据模型必须把 membership、device 与 credential 分层，并从凭证解析权限；同一
  membership 的多台设备可管理其共同作者数据。
- 根密码必须只存在于部署环境和短暂登录请求，不进入二维码、日志、数据库日常会话或 App
  展示；改密的会话撤销语义必须可测试。
- 家庭 NAS 的例行部署必须在前后取得相同 SPKI；缺失、无效、错配或不可读的 TLS 身份使发布
  失败关闭，不能由 CD 自动生成替代身份。只有经确认的全新空数据根允许首次生成。
- 管理员审批成为新成员、新设备与改名的唯一身份裁决点；没有管理员在线时，普通成员可以继续
  本地记录，但申请只能等待管理员下次前台打开 App。
- 删除合同需要服务端给出明确的 `device_removed`、`membership_deleted` 或
  `family_deleted` 结果，使客户端与普通 401/凭证丢失采用不同的本地数据策略。
- ADR-0009 的一设备一 membership 和 ADR-0010 的客户端迁移、可选 Wi-Fi 目标被本文取代；
  fresh-current 切换仍遵循 ADR-0008。
