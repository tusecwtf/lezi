# Triage labels

| Role | Label string |
|------|----------------|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

For local markdown issues/specs, record the label in a `Status:` line near the top of the file.

These are **not** required on GitHub Issues (tickets live in `.scratch/`). If a
human opens a rare GitHub issue, the same strings may be used as labels for
consistency, but they are optional.
