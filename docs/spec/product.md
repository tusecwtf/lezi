## 1. 产品原则

1. **夜喂能记**：常用入口大热区、单手可达，先打开预填 Composer。
2. **确认后写入**：所有新增记录都必须在 Composer 中确认；打开入口本身不得落库。
3. **家庭一份日志**：数据模型按家庭/宝宝/成员；同步后全量共享。
4. **本地可用**：无网完整记账；同步是增强，不是门槛。
5. **核心全开**：主题色、暗色、导出等不设付费墙。
6. **自有品牌**：禁止使用 PiyoLog / ぴよログ / Piyo日志 商标与小鸡官方素材。

## 4. 功能规格（精简）

### 4.1 通用记录

1. 底部 **图标网格** 打开按点击时刻预填的类型 Composer（可排序、隐藏）；仅点确认后写入。
2. 点时间轴或搜索中的护理记录：能编辑则打开编辑会话（时间/量/备注/照片，可保存或删除）；不能编辑则打开同一张卡的查看会话（只读投影，照片可预览，只有关闭）。搜索不再因不能编辑而提示无权管理。
3. 备注支持最近输入候选（本机）。
4. 时间轴默认 **新→旧**，可设置切换。
5. 日汇总：睡眠时长、尿/便次数、奶量等。
6. **一日时间条**：三轨（睡眠/喂养/护理）画在一条连续的绝对时间轴上，空数据也显示；今天默认并实时吸附 `[现在−24h, 现在]`，历史日默认完整自然日。横拖走系统横向 scrollable（跟手 + 惯性），向过去无天数限制，只在「现在」边界夹紧。松手/惯性结束后按粘性规则提交选中日（当前选中日仍占视窗 ≥ 1/4 则保持，否则取占比最大的本地日），并同步 TopBar、汇总/成长/日历日期锚点；换日时轨道像素不动。今天脱离吸附后停在松手处，只有右边界回到现在才重新吸附，「返回今天 / 回到现在」按钮可一键恢复；换日保持同宝宝类型筛选与高亮，无匹配时显示分类空态，切换宝宝才清除。选中日以外的标记变浅。轨上竖线只有本地午夜日界（加重，顶端极小月/日标签）与「现在」线（无字）。已加入家庭且未结束睡眠在上次成功同步时已存在、距该时刻满 1 小时：实心到 `lastSuccessAt`，其后到现在为虚线不确定尾。记录、当前时刻、午夜分隔、跨午夜/DST 睡眠、绘制/命中与拖动共用同一瞬时轴；完整合同见 `ui.md` §3 / §5.2。
7. 全量删除需多重确认。
8. **排泄**：尿尿大中小图标档；便便量/软硬/色图标档（见 §3.1）。
9. **最近备注**：候选严格按当前宝宝与记录类型查询。
10. **记录照片**：所有记录类型的公共备注区均可添加，单条新记录最多 3 张；
    支持缩略图、大图预览、左右切换与删除。选择后复制到应用私有目录，并作为
    记录附件参与新增、编辑、删除、家庭同步与导出，不再限定为备注/日记载荷字段。
    带照片记录与全部照片作为一个原子同步包：发送端完整上传后才发布，接收端
    完整下载后才显示；失败时不暴露只有记录或只有部分照片的中间状态。
11. **未来时间**：任一已开启的具体记录项目可保存为护理计划，但不得提前写入
    护理记录、汇总或启动计时/睡眠状态；到点后由用户履行，才形成关联记录。
    首版仅支持单次计划，不支持循环规则。

### 4.1.1 配方奶剂量步进（5ml）

| 项 | 要求 |
|----|------|
| **默认步进** | **`amount_step_ml = 5`**（5ml 一档） |
| **UI 同步** | 滚轮 / 加减按钮 / 快捷芯片（如 100、120、150）的间隔均按当前步进；改设置后**立即**作用于下一次打开的配方奶录入页 |
| **选择式** | 候选量按 5 的倍数生成；**上次量居中**（上次非 5 倍数时可对齐到最近档或仍居中显示精确上次值，实现二选一并单测固定一种） |
| **数字键盘** | 仍允许手输任意正整数 ml（不强制 5 的倍数），保存后时间轴显示实际值 |
| **设置** | 可配置步进（建议选项：**5 / 10 / 15** ml）；默认出厂为 **5** |
| **范围建议** | 常见 30–300ml；加减到边界时按钮禁用或不再增减 |

**挤奶 / 母乳瓶喂** 录入 ml 时 **共用同一 `amount_step_ml`**，与配方奶 UI 行为一致。

### 4.2 母乳计时

- 全屏左右大圆钮开始/停止；提示「上次侧」。
- **关 App 仍计时**（前台服务）；可设记录时刻为开始或结束。
- 点“完成并记录”先冻结点击时刻与左右时长，再在二级面板核对仅左（`L`）、仅右（`R`）、先左后右（`LR`）或先右后左（`RL`）、可选奶量、备注和圆盘结束时间；确认后才落库。
- 可在设置中关闭计时入口（纯配方奶用户）。
- **下次喂养计划**：新增母乳、配方奶或母乳瓶喂事实后可按默认间隔（如 3h）或调整时间确认；生成同类型的单次家庭护理计划，并出现在乐记日历与待履行区。计划不预填虚假奶量/时长，履行后才产生事实记录。
- 同一宝宝最多保留一条由此入口生成的开放计划，后续确认更新其稳定身份与时刻；选择「不提醒」只保存刚才的事实。通知与系统日历失败不回滚计划，提醒仍遵循护理计划的本机单一来源策略。

### 4.3 睡眠

- 「睡下」「醒来」；自动算时长。
- 连续两次睡下等异常：仍写入，列表标 `!`。
- 睡下为 SleepStart 记录；醒来为独立 WakeObservation（可多条、暂定最早合法观察、作者/Owner 确认有效观察）；重叠开放睡眠不自动改写。详见 [`data-model.md`](./contracts/data-model.md) §3.5.1 与 ADR-0021。

### 4.4 体温

- 手动录入。
- 可选：月龄 &lt; 3 个月且 ≥38℃ 显示就医建议（可关 + 免责声明）。

### 4.5 周汇总

- 喂养量/时间、睡眠条、排泄次数、体温。
- 周 Tab 为滚动周：锚点日（默认今天）及往前共 7 个自然日，不按周一起始的自然周划分；锚点日翻页时窗口随之平移。
- 可选：与前 7 天对比、平均睡眠。
- Log、Summary、24 小时时间条和 Widget 必须复用同一 `CareAggregation`，
  对跨午夜与进行中睡眠给出一致结果。
- 聚合时钟：点事实仅 `timestamp ≤ now` 计入累计；睡眠按
  `[start, min(end, now)]` 裁剪。履行允许的「已确认但时刻未到」记录可在时间轴
  展示，但暂不进汇总，到点后自然计入（见 [data-model.md](./contracts/data-model.md) §5.1）。
- 近邻同型由服务器自动写成 **来源关系**（展示版 + 来源）；未 pull 到关系前未确认组汇总显示 **上下界**；对齐后按展示版单值聚合，其它来源/照片永久保留（见 [data-model.md](./contracts/data-model.md) §5.2、ADR-0023）。同 UUID 冲突徽章不阻断录入。
- 家庭页 **待处理** 徽章 = 未解决 branched 冲突 + 可处理未对齐项（本机多出、家里没收下、拉取洞）。点徽章或「N 项未收下」进同一底栏。未对齐项用同一套裁决皮肤，确认句是「只从这台手机去掉，不通知家里」，不伪造 `conflict_id`。

### 4.6 成长

- 录入体重，以及 2 岁以下的身长、2 岁起的身高；成长页不统计头围趋势。
- 百分位曲线离线内置中国 `WS/T 423—2022` 7 岁以下按性别 P3/P50/P97 表，月龄按出生日期的实际年龄计算，不使用早产矫正月龄。
- P3/P97 只表示同年龄同性别的生长水平参考带，不单独用于营养或疾病诊断；越界时提示复测与咨询儿保/儿科。
- 性别未设置、7 岁及以上、早产或特殊疾病场景不套用默认参考带；产品不新增地区或人种字段。

### 4.7 家庭与同步

## 7. 非功能（摘要）

| 项 | 目标 |
|----|------|
| 快记 | 主路径为“点记录类型 → 核对/确认”；点击时刻在首次点选时冻结 |
| 单手 | 两套模板固定底部快捷坞；惯用手偏好持久化但不决定坞槽序（四槽按编排的绝对左右序展示，不随惯用手镜像）；二级面板确认键位于拇指可达区 |
| 电池 | 计时用前台服务，避免无意义唤醒 |
| 隐私 | 数据默认本机；同步前明示全量共享；不采通讯录/物理位置；可信同步目标不读取 SSID、不申请仅为 SSID 存在的位置权限 |
| 无障碍 | 触控 ≥48dp；图标有描述；支持系统字体缩放 |
