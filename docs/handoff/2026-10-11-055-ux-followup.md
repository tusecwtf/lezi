## 本机验证边界

适用根 AGENTS 的 B 行（Android 非 sync）。使用 JDK21、Gradle8.11.1、Android SDK35，
共享 Gradle lock 和 `--max-workers=2`。最终完整提交统一执行以下模块 JVM 与设备源码构建：

```bash
flock /tmp/lezi-055-gradle.lock env JAVA_HOME=/usr/lib/jvm/java-21-openjdk \
  ./gradlew --max-workers=2 \
  :core:model:test :core:ui:testDebugUnitTest :designsystem:testDebugUnitTest \
  :feature:family:testDebugUnitTest :feature:log:testDebugUnitTest \
  :feature:search:testDebugUnitTest :feature:summary:testDebugUnitTest \
  :app:assembleDebug \
  :core:ui:assembleDebugAndroidTest :designsystem:assembleDebugAndroidTest \
  :feature:family:assembleDebugAndroidTest :feature:log:assembleDebugAndroidTest \
  :feature:search:assembleDebugAndroidTest :feature:summary:assembleDebugAndroidTest
```

JVM 回归包含字段解析、相机取消/owned capture、切换失败范围、档案脏/净与配置重建
会话状态、查找失败回调解锁、搜索范围延迟/查询挂起/重试恢复、图表缺失/真实零值
和缓存 pin/LRU 观察。设备测试只构建，不视为运行通过。
本轮没有 sync/server 运行时代码变更，不堆叠 Rust、隔离服务器或 NAS 门禁。

## 后置研究与已知限制

- 07：现有单行 CTA 在 360dp、大字、IME、短视口下有静态风险，尚无截断/重叠证据，
  未无证据改通用布局。用户后续按 warm/journal × 明暗 × l1/l2/l3 检查可读、可达和触控。
- 10：`localPhotoCacheSnapshot()` 是同模块按需内部入口，返回 entries、pinnedEntries、
  totalPins、estimatedDecodedBytes；没有自动采样、身份/路径日志或缓存策略变化。
  数字是解码字节估计，不能当作 PSS。本轮未测五路径或三图。
- 11–14：只完成精确新基线静态研究；没有分段 collector 或真实性能数字。pull、heartbeat、
  media GET 已有连接复用，commit 媒体发布已移出短锁，不重复实施。media prepare 的其余
  connect 成本要消费 11 的样本；流式下载须保持 hash/length、整页原子 apply 和临时文件所有权。
- 14 静态风险：部分 async handler 持锁，而已开始的 blocking closure 在 HTTP timeout 后可能
  继续工作；不能把 HTTP 超时视为服务器停止。未复现数据损坏、未运行被冻结的并发实验，
  暂不改变锁/超时合同。
- 搜索以既有本地 ACL 为准。普通 reauth 保留本地数据与 ACL；终端撤销后由现有同步清理。
  本轮直接范围验证用于防止旧结果复用，不新增远端权限证明，也不改变离线使用合同。
- 出生体重保留既有 Double→克截断合同；档案净草稿判定已单独覆盖初始 4015g 的浮点边界。

未来性能采样须固定源码/APK、设备/API/刷新率、合成记录与三图字节/SHA、冷热状态；
每条路径先预热5次再至少30次探索样本，保留原始值。三图进入/快滑/退出后5s及30s
并列记录 PSS 和 pin，退出后 pins归零、unpin后缓存恢复原约束且多轮 PSS 不无界上升。
少量样本不声称稳定 P95/P99，loopback 不冒充真机/NAS。FULL、hash、鉴权、TLS、
完整照片原子发布、两模板等价和本地优先合同保持；新唯一副本保留/删除政策另行决策。
