# 乐记 — 画风与页面设计

> 对齐调研中的 **信息架构与交互模式**；视觉资产自有，不使用原版小鸡商标素材。  
> 主 PRD：[`README.md`](./README.md)

---

## 1. 设计原则

1. **单手大按钮**：两套模板都固定底部快捷记录坞；最高频入口贴近所选惯用手一侧，喂奶计时圆钮刻意做大。
2. **先写入、后提示**：睡眠异常等用 `!` 标记，不拦截录入。  
3. **三层日信息**：时间条（节奏）→ 日汇总（合计）→ 时间轴（明细）。  
4. **可定制降噪**：图标显隐/排序；可关喂奶计时入口。  
5. **家庭数据、安静同步**：家局域网 NAS 全量共享（同步域内）；**不**对每条对方记录推送；**打开/下拉/前台**才更新（见 [`sync-home-lan.md`](./sync-home-lan.md)）。
6. **无广告位**：布局不预留横幅广告条。  
7. **深色护眼**：菜单一键切换；夜喂低眩光。  
8. **多宝宝防误记**：每宝宝主题色；昵称/长按 Tab 切换。  
9. **辅助信息就近**：相对时间「N 小时前」、发热说明、平均睡眠等。  
10. **记录可回忆**：日记照片；后期 PDF/TXT。

## 2. 设计系统（Token）

### 2.1 两套等价模板

乐记提供两套本地界面模板；切换只改变视觉表达，不改变导航、记录类型、表单字段、计时状态、汇总口径、成长数据或家庭同步行为。

| 模板 | 设置文案 | 视觉语言 | 图表语言 |
|------|----------|----------|----------|
| `warm` | 温暖卡片 | 奶油底、柔和大卡、三条横向 24h 轨道 | 圆角柱、简洁折线、留白优先 |
| `journal` | 紧凑记录簿 | 珊瑚顶栏、白/浅灰分区、细分隔、紧凑日志、纵向 0–24h 轨道 | 七日矩阵、事件点/睡眠块、密网格百分位线 |

- 默认模板为 `warm`；入口：菜单 → 显示 → 界面模板。
- 选择持久化在本机，并与深色模式正交组合。
- `journal` 的密度、层级与图表形态由 Compose `designsystem` 与各 feature
  实现固化，并使用乐记品牌和自有绘制组件。
- 两套模板必须共享同一 ViewModel/domain/Room 数据流；禁止复制业务分支形成两套功能实现。

| Token | 规则 |
|-------|------|
| **主色** | 每宝宝 **主题色** 驱动顶栏、选中态、强调按钮 |
| **浅色表面** | 浅底列表 + 卡片 |
| **深色表面** | 全局深灰/黑；图标保持对比 |
| **语义色** | `!` 警告、体温偏高提示；睡眠/喂养在时间条上分段着色 |
| **午睡** | 汇总睡眠图中可用橙色区分（设置可开） |
| **圆角** | 大圆 CTA / 圆形记录图标 / 中圆角列表 cell |
| **触控** | 常规 ≥48dp；计时器按钮显著更大 |
| **媒体** | 照片统一压缩（建议长边约 1200～2000px，一档即可） |
| **字体** | 顶栏昵称/日龄强调；时刻中等；相对时间次级灰字；汇总数字突出 |

品牌色板自定（建议一组柔和、夜喂不刺眼的主题色 8～12 色，**全部免费可用**）。

### 2.2 单手操作契约

- `warm` 与 `journal` 共用同一固定底部快捷记录坞，不允许某一模板退化为滚动列表末尾入口。
- 默认右手；可在“菜单 → 显示设置 → 单手操作”切换左手，偏好保存在本机。
- 快捷记录坞固定为四个用户自定义记录槽位和一个不可关闭的“更多”入口；四个槽位位于惯用手侧，“更多”位于较远一侧。
- “最高频”只约束位置与可达性，不代表选中态；所有无真实交互或领域状态的空闲槽位使用同一中性容器，记录类型仅由名称、图标和类型色区分。
- 四个槽位可绑定任一已开启的内置记录项目或未删除的自定义记录项目；槽位绑定项目身份，自定义项目改名或换图标后同步更新显示。
- “更多”不能占用常用槽位；睡眠等有状态项目进入槽位后仍按自身状态切换动作与文案。
- 关闭或删除占用常用槽位的项目时不自动替换；原位置显示“＋ 选择常用记录”，可暂时留空并直达记录项目设置。
- fresh install 以尿尿、睡眠、母乳、配方奶作为四个常用槽位的初始值。
- 点击任一快捷槽位后先打开对应的预填二级确认面板；未确认不得写入。
- 母乳、奶瓶、睡眠及“更多”中的全部项目统一进入类型专属二级面板，均包含基本信息、备注、点击时刻与圆盘调时；确认后才写入。
- 睡眠二级面板按全局未结束睡眠切换“确认睡下 / 确认醒来”；睡眠进行中头像显示月亮睡帽与“{昵称}睡觉中”。
- “更多”从固定入口打开可滚动的四列底部项目面板；所有项目热区至少 48dp。
- 完整记录表单允许滚动，但“保存”始终固定在底部且为全宽按钮。
- 搜索、换日、删除等低频或高风险操作可以保留在顶部，不占用拇指区的主记录入口。

## 5. 页面规格

### 5.1 启动引导

```
[ 自有插画 ]
  开始            （主按钮）
  加入家庭        （次按钮；进入账户/邀请加入流）
→ 昵称 / 性别 / 生日
→ 主题色
→ 可选短教程气泡 → 记录
```

- 必填：昵称、生日（性别可选但建议要）。  
- 无宝宝不可进主记录。

### 5.2 记录首页（核心）

```
┌─────────────────────────────────────┐
│ [昵称 ▾]  生后 N 日 / N 个月 N 天    │  主题色顶栏
│ ‹  2026/07/22 (三)  ›               │
├─────────────────────────────────────┤
│ 睡眠 8h · 尿 5 · 便 2 · 奶 600ml    │  日汇总
├─────────────────────────────────────┤
│ ████░░░░██░░████   时间条 0–24h     │
├─────────────────────────────────────┤
│ [喂奶计时] [搜索] 或 [返回今天]      │  动作按钮可配置
├─────────────────────────────────────┤
│ 待履行 · 19:00 用药                  │  计划状态色
│ 已错过 · 08:00 体温                  │  点按进入履行面板
├─────────────────────────────────────┤
│ 09:30  配方奶 160ml  · 2 小时前     │
│ 08:00  睡眠  …  (!)                  │  时间轴
│ …                                    │
├─────────────────────────────────────┤
│ [常用1][常用2][常用3][常用4][更多] │  固定快捷坞
├─────────────────────────────────────┤
│ 记录 | 汇总 | 成长 | 账户 | 菜单    │
└─────────────────────────────────────┘
```

| 手势 | 效果 |
|------|------|
| 点图标 | 当前时间快记 |
| 点 cell | 编辑 |
| 点日期 | 月历跳日 |
| ‹ › | 逐日 |
| 点昵称 | 切换宝宝 |
| 长按昵称 | 跳到兄/姐 **相同日龄** 那天（多孩时） |
| 长按底 Tab | 切换宝宝 |
| 下拉 | 家网允许时 push+pull；非家网轻提示 |

- 待履行计划明细固定在护理记录时间轴顶部，并通过计划状态色与已发生记录区分。
- 点击待执行或已错过计划，进入该计划的履行面板；完成确认前不得混入护理记录时间轴或汇总。
- 查看今天时，待履行区先展示全部已错过计划，再展示今天尚未到点的计划；已错过计划按原计划时间从早到晚排列。
- 查看其他日期时，待履行区只展示所选日期的计划。
- 待执行使用主题强调色，已错过使用琥珀警示色；不使用同时承担保存失败或医疗危险语义的红色。

空状态：引导「点下方图标添加第一条记录」。

### 5.3 喂奶计时（全屏）

- 左 / 右两大圆：开始、停止；累计分钟。  
- 中央：上次停在哪一侧。  
- 底部“完成并记录”只冻结点击时的左右时长与结束时刻，再打开确认面板；面板可调整时长、顺序、可选奶量、备注和圆盘时间，确认后才写入。
- 计时中可进其它页；状态持久。  
- 设置关闭后：记录页不显示计时入口。

### 5.4 记录编辑

通用：新增记录使用底部二级面板，类型标题 · 点击时刻（圆盘可调）· 类型特化控件 · 备注 · 确认 / 取消；已有记录编辑另提供删除。

| 类型 | 特化 UI |
|------|---------|
| 母乳 | 左/右分钟、顺序、可选 ml |
| 配方奶 / 挤出乳 | **5ml 默认步进**（`amount_step_ml`，可设置 5/10/15）；加减钮与快捷量芯片间隔 = 步进；上次量居中；可切数字键盘手输任意 ml；改设置后下次打开录入页立即生效 |
| **尿尿** | **三枚量档图标：小 / 中 / 大**；默认可一键「中」；选中高亮 |
| **便便** | **三行图标芯片**：量 1–4 · 软硬 1–4 · 色 0–7（色块+图形）；非纯文字列表 |
| **尿+便** | 上排尿尿三档图标 + 下方便便三行图标 |
| 睡眠 | 无进行中记录时确认“睡下”；有进行中记录时确认“醒来”；补记使用开始/结束时间 |
| 体温 | 数字 + 单位 |
| 日记 | 多行文本 + 多图 |

**时间轴排泄 cell：** 优先渲染小图标组合（尿：一枚量档；便：量+软硬+色最多三枚），字号次级可附短标签。

### 5.5 汇总

- 顶：周标签 `‹ 本周 ›`，点日期进该周。  
- 模块：喂养、睡眠、排泄、体温（可滚动）。  
- 空：示意空图 +「记几天就有图表」。

### 5.6 成长曲线

- 指标切换：身长 / 体重 /…  
- 曲线 + 实测点；可选数据源。  
- 空：引导从记录或本页添加测量。

### 5.7 账户（当前默认行为）

账户面向小白：**首屏只讲家庭与宝宝**；网络运维下沉。术语与决策见根目录 `CONTEXT.md`、[`docs/adr/0002-family-identity-and-account-overview.md`](../adr/0002-family-identity-and-account-overview.md)。

#### 账户概览（首屏）

家庭卡与宝宝区**分开**（不改记录/汇总/成长全局顶栏）。家庭卡替换现行「存储/设备 ID / 三步网络引导」等技术态文案。

| 区块 | 行为 |
|------|------|
| **家庭卡** | 已加入：共享**家庭名**（可空则兜底「我的家庭」/「{宝宝昵称}的家庭」；管理员可点改，成员只读）· **成员人数**（如「3 位家人」，点进成员二级）· **本人家庭称呼**（管理员 ★）· **一句结果向同步状态**（整句可点 → 网络设置；不露 SSID/host/Idle） |
| **宝宝区** | 独立当前宝宝卡 + 宝宝档案列表，不塞进家庭卡。未加入或 owner 可添加/编辑/删除/合并；member 只读家庭权威档案并可切换，显示「家庭管理员管理」。存在加入前本机孤宝宝时仅提供「并入家庭宝宝」；一个权威宝宝自动收敛，多个时明确选目标，零个时显示等待管理员空态 |
| 同步状态文案 | 还没和家人一起记 / 家人记录已对齐 / 连上家里 Wi‑Fi 后才能同步 / 正在同步… / 同步遇到问题 |
| 未加入主行动 | 「新建家庭」「加入家庭」→ **家庭向导**（内含必要时的网络配置，再进建家/加入） |
| 已加入管理员主行动 | 「邀请家人」→ 邀请码/QR 弹窗（**QR 含 baseUrl+code**；展示期 FLAG_SECURE；完整载荷默认折叠） |
| 次要入口 | 「网络设置」→ 二次界面 |
| 去掉 | 首屏设备 ID、SSID/服务器摘要、三步「网络→身份→同步」条 |

#### 成员二级列表

| 项 | 行为 |
|----|------|
| 行内容 | **家庭称呼**；家庭管理员行标 **★**；本人可编辑自己的称呼 |
| 称呼规则 | 自由文本；引导语「我是宝宝的？」；建家/加入时**硬必填**；不得上传「我（本机）」；仅本人可改自己的，不改他人 |
| 移除家人 | **仅家庭管理员**可对**非本人、非管理员**成员显示「移除」；二次确认后调用服务端移除；对方凭证吊销、名单消失；**不**删历史记录；管理员不能移除自己（须「删除家庭」） |

#### 网络设置（二次界面）

| 区块 | 行为 |
|------|------|
| 服务器 | **host + 端口**（默认 8765）；空态预填 host=`192.168.50.4`；可扫码带入 baseUrl 后拆解 |
| Wi‑Fi 名称白名单 | **最多 2 个**；空态第一格预填当前 SSID；「使用当前名称」写入空槽；**仅本机** |
| 同步细节 | 上次成功时间、立即同步；技术原因（读不到 Wi‑Fi 名、health 失败等）仅此处展开 |
| 新建家庭（向导内） | 共享家庭名（可空+兜底）+ 家庭称呼（必填）+ NAS 初始化口令（仅本次请求，不持久化、不进邀请载荷） |
| 加入家庭（向导内） | 家庭称呼（必填）+ 邀请码/扫码；**Network 步可扫码**带入 host/port/SSID+短码；完整 QR 预填后可直达 Identity；邀请码框只显示短码；进度「✓ 家庭网络」仅当 host+≥1 SSID 就绪 |
| 离开 / 删除家庭 | 成功后本机清空服务器与 SSID 配置及会话；离开/删除需确认 |
| 换机继承 | 回家网再同步（系统 D2D 不迁移 token/DB） |

**无** 会员订阅区；**无** 首屏三步「网络→身份→同步」条、**无** 首屏设备 ID/SSID 摘要。

**Onboarding**：首屏「加入家庭」为 **真实 join**（进账户/家庭向导），小白默认同上；禁止「同步将在后续版本提供」类 stub。

#### 时间轴与记录上传者

- 上传者 = 写出该护理记录的 membership 的**当前家庭称呼**（改名后所有记录展示跟当前名，不写称呼快照）。
- 时间轴 cell：**仅当上传者不是本机**时在次要信息展示对方称呼；本人不标。
- 未加入家庭时时间轴**不**显示上传者。

### 5.8 菜单 / 设置

分组建议：

1. 宝宝管理（未加入或 owner 可编辑/添加家庭档案；member 只保留切换与本机主题/排序，不显示添加旁路）
2. 记录与快捷设置
3. 显示（深色、日龄算法、12/24 小时、单位）
4. 导出（TXT / PDF）
5. 关于 / 数据（**清除全部记录**两步确认 — 清除本机 Record、CarePlan、履行候选及其媒体/提醒，**保留宝宝档案、自定义项目与家庭会话**；已加入家庭时两级正文说明只清本机、家庭服务器记录仍保留且下次家庭同步可能重新下载，未加入家庭时只说明本机范围与宝宝档案保留且不出现服务器/同步提示；产品有意不暴露 domain `clearAllLocalData` 全清入口，见 ISS-028）

清除只有在本机记录、相关 Outbox/媒体、Android 系统日历副本、设置与应用内提醒全部
收尾后才显示成功。提交后若日历权限撤销或外部收尾失败，界面说明本机可能已部分清理
并要求重试；已加入家庭时同时明确家庭服务器记录仍保留。恢复日历权限后重试或重启恢复
必须继续同一耐久清理，不得把遗留系统日历提醒当成成功，也不得删除清理提交后新设置的
喂养提醒或新建立的系统日历副本。

“记录与快捷设置”是统一二级菜单，替代原先平级的“记录设置 / 记录项目 / 自定义项目”：

1. **常用记录**：配置四个快捷槽位，支持选择、拖动排序与清空。
2. **所有记录项目**：按类别展示内置与自定义项目，类别区块和类别内项目均支持拖动排序，项目支持开启/关闭；项目只能在所属类别内排序，不能跨类别改变领域分类。自定义项目统一归入“自定义”类别，其新增、改名、换图标和删除也在此完成。
3. **分项目设置**：只展示确有专属设置的项目。例如母乳包含计时入口、记录开始/结束与提醒间隔，配方奶/挤出乳包含剂量步进，体温包含婴儿发热提示；没有专属设置的项目不显示空入口。
4. **护理计划与日历**：配置本机“家庭护理计划提醒”（默认开）、是否在收到计划后自动建立系统日历副本、目标可写日历和三级披露；首次主动启用时才申请权限并选择日历，所有设置均不上传。

记录目录只显示当前内建类型与具体自定义项目；具体自定义项目直接显示为独立按钮。fresh install 的四个常用槽位使用当前默认或用户明确选择的具体项目。

### 5.10 小组件

- 上：最近喂养 / 睡眠 / 排泄摘要与宝宝昵称（**产品有意暴露**，便于桌面一眼核对；仅 `home_screen`，非 keyguard）。  
- 肩窥残差为家用场景接受风险（访客桌面/投屏背景可能看到护理细节）；后续可选「仅快捷入口、隐藏摘要」开关。  
- 下：可配置快捷记录图标。  
- 每个 Widget 实例独立绑定宝宝与快捷类型；主题色可轻量体现。
- 快捷入口启动对应类型的预填 Composer；Widget 本身不得直接写记录。

### 5.11 护理计划日历

月历 + CarePlan 计划/提醒条目；CarePlan 可与家庭同步，系统日历配置只在本机。
本机提醒为**非精确**本地通知（与喂奶提醒同策略，见 [`tech.md`](./tech.md) §4）。

- 所有护理计划始终进入乐记日历；系统日历只是当前设备的可选单向副本。
- 乐记日历“＋”先选择具体记录项目并进入“安排护理”面板；不存在自由标题日程的创建、编辑或转换入口。
- 首次主动启用系统日历副本时申请权限并让用户选择可写日历，不静默采用默认账户。
- 三级披露首次默认预选“宝宝昵称 · 记录类型”，但必须由用户在授权流程中确认；后续修改只更新尚未发生的事项。
- 权限被撤销或目标日历消失时，计划仍正常保存并提示“未同步到系统日历”。
- 每台设备只发出一次提醒：系统日历副本与开始时提醒严格确认就绪时由系统日历负责；只有 provider 已确认释放/不存在时才由乐记回退，provider 仍持有已有提醒或结果不确定时保持单源并等待前台/重启恢复。
- 未来护理面板中的“同步到系统日历”默认开启；若本机尚未完成日历授权与目标选择，点按后进入设置流程，取消设置不阻断计划保存。

## 7. 校验温度

| 场景 | 交互 |
|------|------|
| 睡眠状态异常 | 写入 + `!` |
| 删除单条 | 编辑页确认一次 |
| 清除全部数据 | 多重确认 |
| 停止共享 | 明确确认文案 |
| 低月龄高热 | 建议就医说明（可关） |
| 记录暂不可保存 | 确认按钮保持与可保存态相同的圆角与尺寸，使用浅灰填充、灰色描边且无阴影（explained-disabled，非 Material 真禁用）；点击不调用持久化，在按钮正上方弹出非模态具体原因卡，并聚焦/高亮首个问题字段。原因卡保留到字段修改、再次点击灰态按钮或关闭面板；保存中/删除中为真禁用且不打开原因卡。TalkBack 只朗读具体原因，不朗读固定的“暂不可保存，点击查看原因”文案 |
