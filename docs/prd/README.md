## 1. 产品原则

1. **夜喂能记**：常用入口大热区、单手可达，先打开预填 Composer。
2. **确认后写入**：所有新增记录都必须在 Composer 中确认；打开入口本身不得落库。
3. **家庭一份日志**：数据模型按家庭/宝宝/成员；同步后全量共享。
4. **本地可用**：无网完整记账；同步是增强，不是门槛。
5. **核心全开**：主题色、暗色、导出等不设付费墙。
6. **自有品牌**：禁止使用 PiyoLog / ぴよログ / Piyo日志 商标与小鸡官方素材。

### 3.1 排泄记录（尿尿 / 便便）— 分档 + 图标

对齐参考产品「记法」分档，**界面以图标为主、文案为辅**，夜喂时靠图形辨认，不依赖长说明。

#### 3.1.1 尿尿量（新增）

| 代码 `pee_amount` | 中文 | 图标意图（自有绘制或合规素材） |
|-------------------|------|--------------------------------|
| 1 | **小** | 小滴 / 浅量 |
| 2 | **中** | 中等液滴（**默认**） |
| 3 | **大** | 大滴 / 满量 |

**交互：**

- 点「尿尿」：可 **一键记默认「中」**（最快路径），或进入三档图标条点选大/中/小后保存。
- 编辑页可改档。
- 时间轴摘要：图标 +「小/中/大」。
- 日汇总：计 **次数**；可选在详情/统计中展示各档次数。

#### 3.1.2 便便分档（记法 + 图标）

字段与参考记法一致；**每个枚举值必须有对应图标资源**（矢量优先，可自绘或使用可商用/自有授权网络素材，**禁止**使用 Piyo 官方资产）。

| 字段 | 代码 | 文案 | 图标意图 |
|------|------|------|----------|
| **量** `stool_amount` | 1 | 一点 | 很小一坨 |
| | 2 | 偏少 | 偏小 |
| | 3 | 正常 | 中等 |
| | 4 | 偏多 | 偏大 |
| **软硬** `stool_consistency` | 1 | 稀 | 水样/很软 |
| | 2 | 偏软 | 软 |
| | 3 | 正常 | 成形 |
| | 4 | 偏硬 | 硬块 |
| **色** `stool_color` | 0 | 未选 | 灰/空 |
| | 1 | 白 | 白色块 |
| | 2 | 黄 | 黄 |
| | 3 | 橙 | 橙 |
| | 4 | 褐 | 褐 |
| | 5 | 绿 | 绿 |
| | 6 | 红 | 红 |
| | 7 | 黑 | 黑 |

**规则：**

- 便便字段 **可整组省略**；若填写任一项，则 **量·软硬·色三者齐全**（缺省可补「正常/未选」策略在实现里写死并单测）。
- 编辑/快记 UI：三行 **图标芯片**（非纯文字列表）；选中态描边/主题色。
- 时间轴：优先展示 **量+软硬+色 三枚小图标**，旁注短文案可选。

**资源约定（工程）：**

- 路径建议：`designsystem` / `assets/excretion/`（如 `pee_1.webp`、`stool_color_2.webp`）。
- 风格：圆角、低刺激、深色模式可辨；与主题色协调。
- 来源：自绘 **或** 网络可免费商用图标（保留来源说明于 `docs/prd/assets-notes.md` 或资源目录 README）；**不得**复制原版小鸡便便美术。

## 4. 功能规格（精简）

### 4.1 通用记录

1. 底部 **图标网格** 打开按点击时刻预填的类型 Composer（可排序、隐藏）；仅点确认后写入。
2. 点时间轴条目 → 编辑时间/量/备注/照片 → 保存或删除（编辑页确认删除）。
3. 备注支持最近输入候选（本机）。
4. 时间轴默认 **新→旧**，可设置切换。
5. 日汇总：睡眠时长、尿/便次数、奶量等。
6. **一日时间条**：以选中日为中心、由连续四个本地午夜构造的三本地日横向三轨（通常 72h，DST 切换窗口为 71h/73h；非今日默认 D 为主、左右略露邻日；今日默认对准现在）；可横向拖动在真实窗口内窥视平移（不改选中日）；记录、当前时刻、午夜分隔、绘制/命中与平移共用同一瞬时轴；邻日标记变浅、午夜日界仅线无字；三天任一有日图类型即出图；跨午夜/DST 睡眠按实际经过时长连续绘制；汇总/明细/图例仍绑定选中日；筛选用 A2（D 上 0 条不进入）且选中后三日窗口内同类全亮。
7. 全量删除需多重确认。
8. **排泄**：尿尿大中小图标档；便便量/软硬/色图标档（见 §3.1）。
9. **最近备注**：候选严格按当前宝宝与记录类型查询。
10. **记录照片**：所有记录类型的公共备注区均可添加，单条新记录最多 3 张；
    支持缩略图、大图预览、左右切换与删除。选择后复制到应用私有目录，并作为
    记录附件参与新增、编辑、删除、家庭同步与导出，不再限定为备注/日记载荷字段。
    带照片记录与全部照片作为一个原子同步包：发送端完整上传后才发布，接收端
    完整下载后才显示；失败时不暴露只有记录或只有部分照片的中间状态。
11. **未来时间**：任一已开启的具体记录项目可保存为护理计划，但不得提前写入
    护理记录、汇总或启动计时/睡眠状态；到点后由用户履行，才形成关联记录。
    首版仅支持单次计划，不支持循环规则。

### 4.1.1 配方奶剂量步进（5ml）

| 项 | 要求 |
|----|------|
| **默认步进** | **`amount_step_ml = 5`**（5ml 一档） |
| **UI 同步** | 滚轮 / 加减按钮 / 快捷芯片（如 100、120、150）的间隔均按当前步进；改设置后**立即**作用于下一次打开的配方奶录入页 |
| **选择式** | 候选量按 5 的倍数生成；**上次量居中**（上次非 5 倍数时可对齐到最近档或仍居中显示精确上次值，实现二选一并单测固定一种） |
| **数字键盘** | 仍允许手输任意正整数 ml（不强制 5 的倍数），保存后时间轴显示实际值 |
| **设置** | 可配置步进（建议选项：**5 / 10 / 15** ml）；默认出厂为 **5** |
| **范围建议** | 常见 30–300ml；加减到边界时按钮禁用或不再增减 |

**挤奶 / 母乳瓶喂** 录入 ml 时 **共用同一 `amount_step_ml`**，与配方奶 UI 行为一致。

### 4.2 母乳计时

- 全屏左右大圆钮开始/停止；提示「上次侧」。
- **关 App 仍计时**（前台服务）；可设记录时刻为开始或结束。
- 点“完成并记录”先冻结点击时刻与左右时长，再在二级面板核对仅左（`L`）、仅右（`R`）、先左后右（`LR`）或先右后左（`RL`）、可选奶量、备注和圆盘结束时间；确认后才落库。
- 可在设置中关闭计时入口（纯配方奶用户）。
- **下次喂养计划**：新增母乳、配方奶或母乳瓶喂事实后可按默认间隔（如 3h）或调整时间确认；生成同类型的单次家庭护理计划，并出现在乐记日历与待履行区。计划不预填虚假奶量/时长，履行后才产生事实记录。
- 同一宝宝最多保留一条由此入口生成的开放计划，后续确认更新其稳定身份与时刻；选择「不提醒」只保存刚才的事实。通知与系统日历失败不回滚计划，提醒仍遵循护理计划的本机单一来源策略。

### 4.3 睡眠

- 「睡下」「醒来」；自动算时长。
- 连续两次睡下等异常：仍写入，列表标 `!`。

### 4.4 体温

- 手动录入。
- 可选：月龄 &lt; 3 个月且 ≥38℃ 显示就医建议（可关 + 免责声明）。

### 4.5 周汇总

- 喂养量/时间、睡眠条、排泄次数、体温。
- 可选：上周对比、周起始日、平均睡眠。
- Log、Summary、24 小时时间条和 Widget 必须复用同一 `CareAggregation`，
  对跨午夜与进行中睡眠给出一致结果。
- 聚合时钟：点事实仅 `timestamp ≤ now` 计入累计；睡眠按
  `[start, min(end, now)]` 裁剪。履行允许的「已确认但时刻未到」记录可在时间轴
  展示，但暂不进汇总，到点后自然计入（见 [data-model.md](./data-model.md) §5.1）。

### 4.6 成长

- 录入体重，以及 2 岁以下的身长、2 岁起的身高；成长页不统计头围趋势。
- 百分位曲线离线内置中国 `WS/T 423—2022` 7 岁以下按性别 P3/P50/P97 表，月龄按出生日期的实际年龄计算，不使用早产矫正月龄。
- P3/P97 只表示同年龄同性别的生长水平参考带，不单独用于营养或疾病诊断；越界时提示复测与咨询儿保/儿科。
- 性别未设置、7 岁及以上、早产或特殊疾病场景不套用默认参考带；产品不新增地区或人种字段。

### 4.7 家庭与同步

| 模式 | 行为 |
|------|------|
| **当前默认 DI** | **可信家庭服务器中心化**：自建 NAS/VPS `lezi-sync`；用户确认 HTTPS endpoint + 独立设备会话；**仅前台**同步（回前台 / 三页下拉 / 写成功 push）；同步管理员权威 Baby、Record、CustomItemDef、CarePlan、履行候选与记录/计划原子照片包；成员只拉取 Baby，不能写 Baby；`RealSyncPort` 为默认绑定 |
| 本机独立 | 宝宝主题与排序、图标排序、暗色、护理计划提醒/系统日历偏好、时间制等 **不同步** |
| 不做 | 部分字段共享、伴侣推送/即时通知同步、后台轮询同步、P2P 主路径、奶库、公网强制云 |

权威细节：[sync-trusted-endpoint.md](./sync-trusted-endpoint.md) · 数据接口：[data-model.md](./data-model.md)。

## 7. 非功能（摘要）

| 项 | 目标 |
|----|------|
| 快记 | 主路径为“点记录类型 → 核对/确认”；点击时刻在首次点选时冻结 |
| 单手 | 两套模板固定底部快捷坞；左右手偏好持久化；二级面板确认键位于拇指可达区 |
| 电池 | 计时用前台服务，避免无意义唤醒 |
| 隐私 | 数据默认本机；同步前明示全量共享；不采通讯录/物理位置；可信同步目标不读取 SSID、不申请仅为 SSID 存在的位置权限 |
| 无障碍 | 触控 ≥48dp；图标有描述；支持系统字体缩放 |

细节见 [tech.md](./tech.md)。
