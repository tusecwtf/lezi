## 1. 产品原则

1. **夜喂能记**：1～2 次点击完成常用记录；大热区、单手。  
2. **先写入、后提示**：异常用列表标记，不弹窗堵录入。  
3. **家庭一份日志**：数据模型按家庭/宝宝/成员；同步后全量共享。  
4. **本地可用**：无网完整记账；同步是增强，不是门槛。  
5. **核心全开**：主题色、暗色、导出等不设付费墙。  
6. **自有品牌**：禁止使用 PiyoLog / ぴよログ / Piyo日志 商标与小鸡官方素材。

## 4. 功能规格（精简）

### 4.1 通用记录

1. 底部 **图标网格** 一点生成当前时间记录（可排序、隐藏）。  
2. 点时间轴条目 → 编辑时间/量/备注/照片 → 保存或删除（编辑页确认删除）。  
3. 备注支持历史输入候选（本机）。  
4. 时间轴默认 **新→旧**，可设置切换。  
5. 日汇总：睡眠时长、尿/便次数、奶量等。  
6. **一日时间条**：0–24h 喂养/睡眠色带。  
7. 全量删除需多重确认。

### 4.2 母乳计时

- 全屏左右大圆钮开始/停止；提示「上次侧」。  
- **关 App 仍计时**（前台服务）；可设记录时刻为开始或结束。  
- 可在设置中关闭计时入口（纯配方奶用户）。  
- **下次喂奶提醒**：间隔（如 3h），记母乳/配方奶后确认；**仅本机**，不随同步推给对方。

### 4.3 睡眠

- 「睡下」「醒来」；自动算时长。  
- 连续两次睡下等异常：仍写入，列表标 `!`。

### 4.4 体温

- 手动录入。  
- 可选：月龄 &lt; 3 个月且 ≥38℃ 显示就医建议（可关 + 免责声明）。

### 4.5 周汇总（V1.5）

- 喂养量/时间、睡眠条、排泄次数、体温。  
- 可选：上周对比、周起始日、平均睡眠。

### 4.6 成长（V1.5）

- 录入身长体重（及后期头围等）。  
- 百分位曲线：可插拔数据源（如 WHO / 自备表）；**修正月龄**需预产期，过预产期后辅助线显示。  
- 文案注明数据来源，不冒充官方背书。

### 4.7 家庭与同步

| 阶段 | 行为 |
|------|------|
| **V1** | 引导可选「创建家庭」或「加入家庭」；发码/扫码 UI 存在；**SyncPort 为空实现**；文案说明「同步即将支持」；本机完整可用 |
| **V2** | 接后端；邀请码/QR；家庭内 **全量** 记录共享；下拉刷新；目标：对方新记录约 60s 内可见 |
| 本机独立 | 主题、图标排序、暗色、下次喂奶提醒、时间制等 **不同步** |
| 不做 | 部分字段共享、伴侣每条推送、奶库 |

详见 [data-model.md](./data-model.md)。

## 5. 信息架构

```text
启动
 ├─ 开始（新建宝宝）→ 昵称/性别/生日 → 主题色 → 记录
 └─ 加入家庭（V1 Stub / V2 真同步）

底部导航
 ├─ 记录      （主路径）
 ├─ 汇总      （V1.5；V1 可占位）
 ├─ 成长曲线  （V1.5；V1 可占位）
 ├─ 账户      （家庭/共享 Stub）
 └─ 菜单      （设置、导出、宝宝管理、关于）
```

全局入口：日历跳日、喂奶计时、搜索（V1.5）、返回今天、Widget（V1.5）。

页面线框与组件 → [ui.md](./ui.md)。

## 7. 非功能（摘要）

| 项 | 目标 |
|----|------|
