# 乐记第二套模板 · 390×844 首页设计说明

目标画布：Android 移动端 `390 × 844`。页面本身可纵向滚动；底部导航与快捷记录带固定，页面无横向滚动。

## 首屏垂直结构

| 区域 | 约高 | 设计与行为 |
| --- | ---: | --- |
| 珊瑚顶栏 | 92px | 左侧宝宝与日龄，中间日期/前后日，右侧搜索；整块使用珊瑚主色，白色文字。 |
| 今日 5 项摘要 | 70px | 白底五等分：奶量、母乳、睡眠、尿尿、便便；每格是 26px 自绘图标、等宽数字和 9px 标签，用 1px 竖线分隔。 |
| 24h 标题行 | 64px | 左侧“今天的节奏 / 24h 时间轴”，右侧“状态演示”；没有大卡片背景。 |
| 轨道与最近记录 | 首屏剩余可见约 470px | 左 48px 为浅珊瑚底的 0–24h 竖轨；每 2 小时刻度、彩色事件点、睡眠色块、当前时刻细线。右侧为 61px 高的紧凑日志行，依次显示时间、类型色图标、专属摘要和编辑入口。 |
| 快捷记录带 | 78px 固定 | 位于导航上方，顶部 2px 珊瑚线；六个可排序/隐藏项目 + “更多”，圆形自绘类型图标，触控热区 ≥48px。 |
| 五栏导航 | 64px 固定 | 记录 / 汇总 / 成长 / 账户 / 菜单；仅当前项使用珊瑚文字与顶部短线。 |
| FAB | 54px | 固定在快捷带右上方，用于打开全部记录类型；圆形珊瑚按钮，白色加号与实体阴影。 |

## 视觉重点

1. 首屏不出现第一套的奶油底、大圆角摘要卡、陶土胶囊 FAB 或三条横向大轨道。
2. 信息密度来自“共用网格 + 细分隔”，不是缩小触控区域：可点元素仍保持最小 48px。
3. 珊瑚只承担顶栏、FAB、当前 Tab 与关键状态；母乳、奶瓶、睡眠、排泄、体温各有稳定记录色。
4. 深色模式把主体切为 `#262727` 观察色对应的 OKLch 表面，保留同样的细分隔与类型色，不用纯黑。
5. 记录行的专属摘要直接显示用户下一步最需要核对的字段，例如“左12分 · 右8分”“尿中 · 便量3/软硬2”。

## 交互快照路径

- 点击底部“尿尿”立即写入默认“中”并刷新摘要、轨道和最近记录。
- 点击“睡眠”开始计时，快捷标签变为“醒来”，跨页 session bar 保留；再次点击结束并生成区间。
- 点击“母乳”打开左右圆形计时器；切页后仍持续计时。
- 点击最近记录右侧箭头进入该类型的专属编辑字段并可删除。
- 点击 FAB / “更多”进入 30 种 PRD 记录类型的完整入口矩阵。
