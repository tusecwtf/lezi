# 乐记第二套模板 · PRD 与第一套功能等价性

对照源：第一套 Open Design 原型的 `index.html` / `app.js` / `styles.css` / `components.css` / `prd-alignment.md`，以及乐记 `docs/prd/README.md`、`ui.md`、`data-model.md`、`tech.md`。本文件中的 `[x]` 只表示当前第二套原型已经有可点击、可保存或明确可演示的实现；真实系统能力未实现时保持 `[ ]`。

## 1. 信息架构与持久化

- [x] 5 栏底部导航：记录 / 汇总 / 成长 / 账户 / 菜单。
- [x] 当前宝宝、日期、记录、成长数据、偏好、项目顺序与显隐写入 `localStorage`：`leji-dense-template-v2`。
- [x] 母乳与睡眠计时状态独立写入 `localStorage`：`leji-dense-session-v2`，切换页面后继续。
- [x] 第二套使用独立 key 与独立目录，不读取或修改第一套项目。
- [x] 所有主要页面、弹层、快捷入口与行操作均有真实事件处理，不把未连线按钮算作完成。

## 2. 启动引导

- [x] 欢迎页：说明本机保存，主入口“开始创建宝宝”。
- [x] 资料页：昵称、生日、预产期、性别。
- [x] 识别色页：珊瑚 / 薄荷 / 莓果 / 天空；只用于宝宝档案识别，主界面仍保持珊瑚粉。
- [x] 完成后创建宝宝、记录/成长容器并进入记录首页。
- [x] “加入家庭”以明确 Stub 反馈“家庭同步将在后续版本开放”。

## 3. 记录首页

- [x] 宝宝切换/管理入口、日龄、日期前后切换与完整月历跳日。
- [x] 今日 5 项摘要：奶量 ml、母乳分钟、睡眠、尿次数、便次数；根据当前日记录自动计算。
- [x] 左侧 0–24h 轨道：2 小时刻度、记录类型事件点、睡眠色块、今日时间线。
- [x] 最近记录：时刻、类型自绘图标、类型专属摘要、备注、异常 `!`、编辑入口。
- [x] 底部快捷记录带：最多 6 项，受项目显隐/排序影响；FAB 打开全部项目。
- [x] 尿尿默认“一键记中”；洗澡一键写入；睡眠快捷项在“睡下/醒来”间切换。
- [x] 非今日日期仍可添加记录；返回今天可通过月历完成。
- [x] 记录空、加载、错误、离线、保存成功与记录中状态均可从状态演示进入。

## 4. 母乳与睡眠计时

- [x] 母乳左右圆形计时按钮；切侧、暂停、归零、结束并记录。
- [x] 记录左秒数、右秒数、开始侧/上次侧与可选估算 ml；编辑页可修改全部字段。
- [x] 可在设置关闭计时入口；记录时刻可选开始时/结束时。
- [x] 跨页 session bar 展示总时长、左右时长与当前侧；可直接结束保存。
- [x] 睡眠快捷项开始/结束；结束生成区间、时长与午睡标记。
- [x] 睡眠手动表单支持起止时间与午睡；超过 12 小时仍保存并标 `!`。
