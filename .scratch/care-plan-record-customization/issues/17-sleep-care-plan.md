# 17 — 睡眠计划履行语义

**What to build:** 让睡眠护理计划在安排时保持为意图；履行时才确认睡下或补记合法区间，并继续服从既有单一开放睡眠规则。

**Blocked by:** 15 — 全部非状态型具体项目可安排.

**Status:** done

- [x] 安排睡眠计划不创建开放睡眠、不改变首页睡眠状态也不产生 Record
- [x] 履行时可确认现在/所选过去时刻睡下，或手动补记合法完整睡眠区间
- [x] 确认睡下后只有实际开放睡眠存在，计划在形成对应事实前不得伪装成已完成
- [x] 已有开放睡眠发生变化时沿用既有状态重检和失败关闭规则
- [x] 完整区间继续执行结束晚于开始、不得选择未来时刻和跨天提示规则
- [x] 重复履行请求不能创建两个开放睡眠或两个关联 Record
- [x] CareLog 与 Composer 测试覆盖安排无副作用、睡下、补记、状态竞争和失败回滚
