# 08 — 自定义项目家庭同步与服务端 ACL

**What to build:** 将自定义项目定义与删除状态在家庭 NAS 内共享，并由服务端执行作者/管理员权限；每台设备仍保留自己的显示和布局偏好。

**Blocked by:** 03 — 服务器认证的稳定家庭成员身份; 06 — 统一记录设置与本机拖动排序; 07 — 自定义项目作者权限与历史快照.

**Status:** done

- [x] 自定义定义和 tombstone 具备可分页、幂等的出站/入站同步表示
- [x] 服务端根据认证 membership 绑定创建者，拒绝普通成员修改或删除他人定义
- [x] 管理员可管理全部定义；创建者离开后管理员仍可修改或删除
- [x] 名称和图标更新后其它设备的当前按钮跟随更新，历史记录/计划继续显示保存时快照
- [x] 本机启用、类别、类别/项目顺序和四个快捷槽位不出现在同步 payload
- [x] tombstone 收敛后不得复活已删除定义，历史数据仍可解释
- [x] 服务端契约、真实 SyncPort 和双成员测试覆盖授权、拒绝、离线改名、删除及布局隔离
