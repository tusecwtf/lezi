# 18 — 计划三张照片与履行带入

**What to build:** 让护理计划在本机支持最多三张计划照片，并在履行时默认带入护理记录草稿，始终保持计划与附件的事务一致性。

**Blocked by:** 04 — 所有记录类型的通用三张照片; 12 — 内建项目本地护理计划 tracer.

**Status:** done

- [x] 安排和编辑 CarePlan 时可添加、预览、滑动、删除或替换最多三张计划照片
- [x] CarePlan 与全部照片关联在同一本机领域事务提交，失败不留下部分计划
- [x] 履行草稿默认带入全部计划照片，用户可在三张上限内删除、替换或补充
- [x] 确认履行后 Record 保存最终草稿照片；计划原照片与履行后记录附件的所有权清楚且可审计
- [x] 跳过、软删除和编辑计划产生正确媒体 tombstone，不提前删除仍被有效实体引用的文件
- [x] 计划照片始终只属于乐记/NAS，不形成系统日历可读取附件
- [x] 领域、草稿和文件生命周期测试覆盖事务失败、履行带入、调整及清理
