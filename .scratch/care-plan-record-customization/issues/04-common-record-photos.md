# 04 — 所有记录类型的通用三张照片

**What to build:** 让每一种护理记录都能通过公共备注区保存最多三张记录照片，并以通用附件而非某几个 payload 的专属数组管理、预览和删除。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 所有记录类型的公共备注区均显示照片入口，Diary 与其它类型统一最多三张
- [x] 支持相册选择和现有相机入口；选中后显示缩略图，能打开大图并在多张间左右滑动
- [x] 保存前可删除、替换和补充照片；导入失败或异步回调过期不得污染当前草稿
- [x] 新记录和照片关联在同一本机领域事务提交；失败时不留下只有 Record 或只有附件的可见状态
- [x] 编辑和软删除产生正确的附件关联与媒体 tombstone；文件物理清理不得先于领域提交
- [x] 既有一至三张文本 payload 照片无损读取，并在后续编辑时安全规范到通用附件
- [x] Composer 会话恢复保留照片草稿且不会误删已持久化文件
- [x] 领域、草稿、迁移和最小 UI 测试覆盖 0–3 张、第四张拒绝、预览与失败原子性
