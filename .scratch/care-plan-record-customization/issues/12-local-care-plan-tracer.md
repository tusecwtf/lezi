# 12 — 内建项目本地护理计划 tracer

**What to build:** 先以一个普通内建项目打通本地“安排护理 → 待履行 → 完成后形成关联护理记录”的完整闭环，确立 CarePlan 与 Record 分离的主路径。

**Blocked by:** 01 — 具体记录项目身份与重复入口退出; 03 — 服务器认证的稳定家庭成员身份.

**Status:** done

- [x] 新建 Composer 的时间在未来时明确进入“安排护理”，当前或过去仍为“记录事实”
- [x] CarePlan 首个 schema 包含稳定 UUID、宝宝、具体项目、计划字段快照、绝对 instant、创建时区、创建 membership、状态和履行关联
- [x] 本票自带从当前已发布数据库版本的加法迁移与迁移测试，旧数据不变
- [x] 未来计划不进入 Record 时间轴、汇总、搜索或普通导出
- [x] 待履行计划在记录明细实际记录之前显示，并与普通记录行有清楚视觉区分
- [x] 点击计划进入“完成护理计划”，确认实际发生时间后原子创建一个关联 Record 并完成计划
- [x] 到达计划时刻本身不生成 Record；实际发生时间不能保存到未来
- [x] CareLog 与 Composer 测试覆盖创建、查询隔离、履行成功和事务失败回滚
