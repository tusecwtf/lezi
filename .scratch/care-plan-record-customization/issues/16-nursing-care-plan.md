# 16 — 母乳计划履行语义

**What to build:** 让母乳护理计划表达未来意图而不提前启动计时；到点履行时再由照护者选择开始计时或手动补记。

**Blocked by:** 15 — 全部非状态型具体项目可安排.

**Status:** done

- [x] 安排母乳计划只保存意图，不启动计时服务、不创建开放母乳状态也不产生 Record
- [x] 履行面板明确提供“开始计时”和“手动补记”两种现有语义
- [x] 开始计时后计划保持待履行，直到计时完成并形成实际 Record
- [x] 手动补记确认后原子创建母乳 Record 并完成计划
- [x] 计时取消或保存失败不得错误完成计划
- [x] 多次打开履行入口不能启动重复计时或产生重复 Record
- [x] 测试覆盖安排不副作用、两条履行路径、取消、失败和幂等关联
