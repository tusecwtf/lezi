# 01 — 具体记录项目身份与重复入口退出

**What to build:** 让内建项目和具体自定义项目都以稳定的“具体记录项目”身份贯穿新建目录、Composer、保存和回显；停止提供重复的“备注 / 其他 / 泛化自定义”新建入口，同时完整保留历史记录兼容。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 内建项目和具体自定义项目都能用稳定身份进入统一 Composer；不得再以“先打开泛化 custom、再默认第一个定义”代表具体项目
- [x] “更多”、快捷候选、日历项目候选等新建目录不再出现备注、其他和泛化自定义
- [x] 具体自定义项目直接显示自己的名称与图标，保存后记录保留项目身份及名称/图标快照
- [x] 历史 memo、other、custom 记录继续可读取、搜索、展示和编辑，不做破坏性迁移
- [x] 指向被移除泛化项目的既有本机引用能被识别为失效引用，供后续快捷槽位显示为空
- [x] 领域与 Composer 测试覆盖具体项目 round-trip、新建目录过滤和历史兼容
