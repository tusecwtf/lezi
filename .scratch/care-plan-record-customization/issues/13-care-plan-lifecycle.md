# 13 — 计划状态、日期分组与管理操作

**What to build:** 补全护理计划从待执行到错过、完成或跳过的本地生命周期，并让每天的记录明细以约定顺序展示仍待处理的计划。

**Blocked by:** 12 — 内建项目本地护理计划 tracer.

**Status:** done

- [x] 计划状态只使用 pending、missed、completed、skipped；missed 根据可控时钟和绝对时刻稳定派生
- [x] 今天视图先显示全部仍未处理的 missed 计划，再显示今天尚未到点的 pending 计划，组内按计划时刻升序
- [x] 查看其它日期时只显示该本地日期的计划；跨时区换算使用设备时区并可查看原计划时间
- [x] pending 使用主题强调，missed 使用琥珀色而非危险红
- [x] 计划可编辑、跳过和软删除；跳过和到点都不创建 Record
- [x] 把计划时刻改到当前或过去只使其成为 missed，不自动履行
- [x] 普通成员只能管理自己的计划，管理员可管理全部；本地界面和领域操作均执行相同规则
- [x] 状态、排序、日期边界、权限与 tombstone 测试使用可控 Clock 和显式 ZoneId
