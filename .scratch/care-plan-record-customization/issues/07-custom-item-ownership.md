# 07 — 自定义项目作者权限与历史快照

**What to build:** 让具体自定义项目成为有稳定身份和作者的家庭领域定义，并在本机先闭合创建、管理、删除和历史快照语义。

**Blocked by:** 01 — 具体记录项目身份与重复入口退出; 03 — 服务器认证的稳定家庭成员身份.

**Status:** done

- [x] 自定义定义持有稳定 UUID、创建 membership、名称、图标、更新时间和 tombstone
- [x] 任意成员可创建和使用自定义项目；普通成员只能修改或删除自己的定义，管理员可管理全部
- [x] 创建者离开家庭后，定义继续存在并由管理员管理
- [x] 其他成员可在本机关闭不用的定义，但关闭不等于删除共享定义
- [x] Record 与 CarePlan 可保存项目名称和图标快照，后续改名或删除不改写历史
- [x] 旧本机自定义项目加法迁移到稳定身份，不丢已有记录引用
- [x] CareLog 公开行为测试覆盖权限、离开接管、tombstone、快照和旧数据迁移
