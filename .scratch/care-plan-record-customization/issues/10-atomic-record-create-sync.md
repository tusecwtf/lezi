# 10 — 新建记录与照片原子同步 tracer

**What to build:** 用新建一条带 0–3 张照片的护理记录打通 Android 与 NAS 原子包协议，保证其他设备只会一次性看见完整记录。

**Blocked by:** 04 — 所有记录类型的通用三张照片; 09 — NAS 原子同步包协议扩展.

**Status:** done

- [x] 发送端先暂存全部照片字节，再提交 Record 元数据、照片引用和完整清单
- [x] 接收端先下载并校验完整包到本机暂存区，再在一个事务应用 Record、Media 与本机路径
- [x] 第 N 张上传/下载失败、校验失败、进程中断或应用事务失败时，接收方完全看不到新 Record
- [x] 未完整应用的包不得推进越过它的 durable cursor，也不得生成照片占位行
- [x] 创建者本机立即看见完整记录；发布前显示“仅本机 · 等待照片同步”或明确失败状态
- [x] 不支持原子包的 NAS 保留本机记录并说明等待升级，不走旧 metadata-first 降级路径
- [x] 手动重试和下一次前台同步能继续同一个幂等包，而非创建重复记录
- [x] SyncPort 集成测试覆盖 0、1、3 张照片以及上传、下载、应用三个阶段的失败不可见性
