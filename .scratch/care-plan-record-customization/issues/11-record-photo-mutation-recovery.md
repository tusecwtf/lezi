# 11 — 记录照片编辑、删除与恢复

**What to build:** 将带照片记录的编辑和删除纳入原子包生命周期；同步失败时其它设备继续看到旧完整版本，创建者能理解并恢复未发布修改。

**Blocked by:** 10 — 新建记录与照片原子同步 tracer.

**Status:** done

- [x] 记录字段或照片编辑在新包 commit 前不替换远端旧完整版本
- [x] 新版本完整 commit 后，接收端一次性替换 Record 与有效照片集合
- [x] 删除发布 Record 与关联媒体 tombstone；普通 pull 不再返回已删除事实，物理文件可延迟清理
- [x] 上传中断、commit 响应丢失、重复 commit 和接收应用失败均可幂等恢复
- [x] 本机状态区分等待同步与同步失败，点按解释其他成员仍看见旧版本并提供手动重试
- [x] 下次前台同步或手动拉取自动重试，不产生重复照片、复活 tombstone 或丢失旧版本
- [x] 编辑期间的本机并发修改不被迟到下载覆盖
- [x] 集成测试覆盖加图、删图、换图、仅改文字、整条删除和各种重试窗口
