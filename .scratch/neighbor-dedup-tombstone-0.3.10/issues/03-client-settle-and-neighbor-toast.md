# 03 — 客户端收敛与近邻落选轻提示

**What to build:** 已加入家庭的两台客户端完成既有同步周期后，时间轴与汇总与家庭权威图一致（近邻只剩胜者 live，落选为墓碑）。落选记录的作者 membership 在本机从 live 收敛为近邻落选后，看到一次不阻断轻提示（例如与家人同一时间的记录对齐）；同一同步周期无论落选几条最多一条提示。提示仅依据服务端本轮显式 neighbor-loser 信号，且仅当作者为当前登录 membership；普通远端手删不用近邻文案；旁观设备不提示。客户端不做乐观本地近邻 tombstone。

**Blocked by:** 01 — 护理记录墓碑永胜；02 — 家庭近邻裁决（触达分片 + 同事务落选 + 显式信号）

**Status:** ready-for-agent

- [ ] 双端经 SyncPort/RealSyncPort 周期后对近邻结果与权威一致（含 pull 到的落选墓碑）
- [ ] 本机不在服务器裁决前按近邻规则本地预删/预藏
- [ ] 显式信号含本人作者 uuid 且本机曾 live → 每同步周期最多一条轻提示；无冲突对话框、无时间轴长期「已合并」灰条
- [ ] 无 neighbor-loser 信号的远端手删不使用近邻对齐文案
- [ ] 仅旁观到他人落选时不提示
- [ ] 与 01 衔接：本机更高 dirty live 在对账/发布结算后不能复活权威 record 墓碑
- [ ] 次验收缝：隔离后端上的双客户端行为测试（或等价 RealSyncPort 共享后端测）覆盖收敛 + 提示门闩
