## 1. 总原则（优化后）

| 原则 | 落地 |
|------|------|
| 垂直切片 | 每票用户可感 + CareLog/SyncPort 可测，避免「只做 DB 层」票 |
| 硬依赖最小化 | 只锁真正门禁（如 08→05，03→02→01） |
| 并行最大化 | V1 中段 03–07；V1.5 的 01–04；V2 波次 A |
| 验收可判定 | Must = 数字/单测/双端步骤；Should = 体验增强 |
| 负向范围 | 「不做」写进验收（无库存、无部分共享、无逐条推送、无 IAP） |
| 阶段门禁 | V1-12 → V1.5-06 → V2-09；禁止跳阶段合主干能力 |

## 7. 建议执行顺序（一人团队）

1. 做完 **V1 全票** 按 `01→02→05→03→04→07→06→08→09→10→11→12`  
2. **V1.5** `01→02→03→04→05→06`  
3. **V2** `01 与 04/06 并行 → 02 → 03 → 05/07/08 收尾 → 09`  

双人可将 V1 的 03/04/06/07 与 05 分头；V2 一人专同步链 `01-02-03`，一人专 PDF/类型。
