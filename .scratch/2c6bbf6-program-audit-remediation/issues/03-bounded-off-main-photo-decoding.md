# 03 — 统一有界、后台图片解码

**What to build:** 为缩略图、冲突预览和全屏查看建立同一条按目标尺寸采样、可取消且不占用主线程的图片加载路径。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**Size:** M

## Acceptance criteria

- [ ] 所有用户可达的本地照片预览入口都使用同一权威加载契约，不再各自完整解码原图。
- [ ] 解码前读取边界并按目标显示尺寸采样；超大尺寸、异常方向与损坏输入有明确上限和占位结果。
- [ ] 文件读取与位图解码在非主线程完成，快速滚动或离开页面会取消不再需要的工作。
- [ ] 缩略图与全屏图分别使用合适的像素预算，不因缓存键碰撞复用错误尺寸或方向的位图。
- [ ] 文件缺失、格式不支持或解码失败时显示稳定占位/错误状态，不抛出导致进程退出的异常。
- [ ] 回归测试覆盖超大图、损坏图、缺失图、方向信息、取消和连续快速换图，并断言解码边界。

## Validation

运行图片加载单元测试、相关 Compose 测试、应用编译与静态检查；用一张超高分辨率图片做设备滚动和全屏 smoke。

## Documentation Gate

记录统一图片加载入口、像素预算与错误占位约定，供新增照片消费者复用。
