# 19 — 夏令时安全的三日时间轴

**What to build:** 以真实本地日界线构造前一天、当天和后一天的时间轴，使夏令时切换窗口可以是 71、72 或 73 小时，并让绘制、命中、遮罩与平移使用同一几何模型。

**Blocked by:** 18 — 记录页分钟级时钟刷新

**Status:** ready-for-agent

**Size:** M

## Acceptance criteria

- [ ] 三日窗口由连续四个本地 midnight 边界构成，不以固定 `72h` 替代日历天。
- [ ] 普通日总时长为 72 小时；春季跳时与秋季回拨所在窗口按真实时区得到 71 或 73 小时。
- [ ] Record 区间、CarePlan 标记、当前时刻线和已过期遮罩都通过同一“瞬时 ↔ 轴坐标”转换。
- [ ] 点击/拖动命中、焦点定位、自动居中和左右平移与可见绘制位置一致，不在 DST 缺口或重复小时偏移。
- [ ] 跨午夜、开放区间及恰落边界的记录按真实本地日裁剪，不重复也不丢失。
- [ ] 时区切换或日期跨日后重新建立窗口，并继承 Ticket 18 的生命周期时钟而不另起 ticker。
- [ ] 确定性测试至少覆盖 `America/New_York` 春秋切换与 `Asia/Shanghai` 非 DST 基线，包括几何和命中断言。

## Validation

运行时间轴纯逻辑、Compose 命中与截图测试，以及应用编译和静态检查；模拟器切换 DST 日期做平移 smoke。

## Documentation Gate

把“三个本地日而非固定 72 小时”写入时间轴规格与测试约定。
