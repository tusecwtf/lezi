# 23 — 汇总聚合移出主线程并降低重复扫描

**What to build:** 将首页/记录汇总的分组、区间裁剪与统计移到可取消的后台计算，并用单次分区替代对完整记录集的重复扫描。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**Size:** M

## Acceptance criteria

- [ ] 大批 Record 的过滤、按类型分组、睡眠裁剪与统计计算不在主线程执行。
- [ ] 一次输入快照先完成单次分区/索引，再生成各摘要；不为每个卡片重复遍历全部记录。
- [ ] 新输入、宝宝切换或页面销毁会取消旧计算，较旧结果不会覆盖较新状态。
- [ ] 空数据、开放区间、跨日区间、自定义类型与未知兼容类型的输出与现有产品规则一致。
- [ ] 大夹具回归测试同时断言数值等价、取消安全和扫描/复杂度边界，而不只测运行时间。
- [ ] UI 在计算期间显示稳定已有值或明确加载态，不因线程切换闪空或重复动画。

## Validation

运行聚合纯逻辑、ViewModel 调度与大夹具测试，以及应用编译和静态检查；低端模拟设备做滚动 smoke。

## Documentation Gate

若摘要定义未变化无需改 PRD；把计算线程与复杂度约束记录在架构文档或测试说明中。
