# 15 — 串行化成长记录写入

**What to build:** 对身高、体重等成长测量的保存与删除增加明确的单次执行状态，避免连点产生重复记录，并让失败结果留在可恢复界面。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**Size:** S–M

## Acceptance criteria

- [ ] 首次保存开始后，确认控件进入忙碌并拒绝后续点击，底层最多收到一次等价写入。
- [ ] 保存成功只关闭一次编辑界面并只插入一条测量记录。
- [ ] 校验失败不启动写入；字段错误可被读屏识别且用户输入保留。
- [ ] 保存异常或明确失败时界面不假装成功关闭，恢复为可重试状态并显示原因。
- [ ] 删除进行中同样阻止重复请求；返回 false、冲突或异常时保留条目并显示失败。
- [ ] 测试覆盖快速连点、慢存储、失败后重试、配置变化和保存/删除互斥。

## Validation

运行成长记录 ViewModel/仓储与 Compose 测试，以及应用编译和静态检查。

## Documentation Gate

若用户可见反馈有变化，同步更新成长记录交互文案。
