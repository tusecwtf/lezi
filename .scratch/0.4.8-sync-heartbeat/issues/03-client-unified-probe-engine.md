# 03: 客户端：统一探针引擎（availability 喂食、节奏、判定、能力门）

**What to build:** 已加入且前台时，一个探针引擎按统一模型工作：健康态 30s 基线、无变化按
±20% 抖动退避至 120s；每次探针既产出变化信号（三键×会话快照比对）又喂
`FamilyServerAvailability`——成功即复健 Available 并刷新最近健康时间，失败按既有传输失败
分类降级（单次即降级、无新迟滞），降级期节奏切换为既有 30s/120s/600s 重试梯。老服务端
（setup-status 无 `sync_heartbeat_v1` 或探针 404）永久停用引擎，不产生任何失败面。
本票交付引擎本体与引擎级测试（假时钟+假后端），端口接线在 04。

**Blocked by:** 01（端点契约与能力广播先行）。

**Status:** done
