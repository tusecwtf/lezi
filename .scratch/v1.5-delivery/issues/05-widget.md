# 05 — 桌面小组件

**Parent:** [../spec.md](../spec.md)

**What to build:** 用户可添加桌面小组件（**Glance** 或等价）：上区展示最近**喂养 / 睡眠 / 排泄**摘要；下区提供可配置的快捷记录入口（≥1）。绑定当前或选定宝宝；记录变更后在合理时间内刷新。小组件**只读**与 CareLog 相同的查询用例，不引入第二业务数据源。

**Blocked by:** V1 交付完成（CareLog 日/最近查询、快记入口 deep link 或 Activity；**软依赖**：建议日汇总/最近记录查询稳定后再接 UI，不硬等 01 周汇总）

**Status:** done

---

## 交付物

| 层 | 内容 |
|----|------|
| Domain | `WidgetSummaryDto`（或等价）：宝宝 id/昵称、最近喂养摘要、最近睡眠摘要、最近排泄摘要、生成时间 |
| 查询 | 与 CareLog 共用用例（如 `recentCareSummary(babyId)`）；**禁止** Widget 直接复制一套 SQL 业务规则而不复用 |
| Widget 配置 | 绑定 `babyId`；快捷类型子集（如 formula / pee / poop 等，可配） |
| Glance UI | 上：三态摘要；下：≥1 快捷图标；主题色可轻量用宝宝色 |
| 刷新 | 记录写入成功后 `requestUpdate`（或等价）；可选定时刷新兜底 |
| 测试 | 摘要 DTO 单测（给定记录 → 文案/时间正确）；不强制截图测试 |

**Seam：** Widget 只读 CareLog（或同一 domain usecase）；写操作只通过打开 App 既有快记路径完成。

## 验收标准

### 摘要 DTO（可单测）

- [x] **最近喂养**：在给定集合中取最新喂养类（`nursing` / `formula` / `pumped_feed` 等约定集合）生成可读摘要（如「配方奶 120ml · 10:30」）  
  **通过条件：** 单测固定 2 条喂养，DTO 对齐最新一条
- [x] **最近睡眠**：最新睡眠区间或进行中状态摘要合理（如「睡了 1h20m」或「睡觉中」）  
  **通过条件：** 单测
- [x] **最近排泄**：最新 pee/poop/both 摘要  
  **通过条件：** 单测
- [x] **无数据**：某类无记录时该槽位显示「暂无」类文案而非 null 崩溃  
  **通过条件：** 单测空宝宝三槽均安全
- [x] **宝宝隔离**：DTO 只含指定宝宝  
  **通过条件：** 单测

### 桌面 Widget

- [x] **可添加**：系统桌面长按/小部件列表出现「乐记」小组件，添加成功  
  **通过条件：** 真机或支持 Widget 的模拟器添加后可见表面
- [x] **上区三态**：喂养、睡眠、排泄摘要同时可见（可换行）  
  **通过条件：** 手测有数据时与 App 内最近记录一致（允许分钟级刷新差）
- [x] **下区快捷**：≥1 个快捷入口；点击进入 App 对应快记或记录页（deep link / activity）  
  **通过条件：** 点击后 App 打开且可完成或到达该类型录入
- [x] **快捷可配置**（最低）：配置页或 App 设置可改快捷类型子集，或提供合理默认 ≥1；若 V1.5 仅默认图标，须在实现注释标明「配置后续」，但默认集合仍须可用  
  **通过条件：** 手测默认快捷可点；若有配置，改后 Widget 反映新图标
- [x] **绑定宝宝**：多宝宝时 Widget 绑定当前宝宝或用户选定宝宝；摘要对应该宝宝  
  **通过条件：** 宝宝 A/B 数据不同，Widget 不串数据
- [x] **写入后刷新**：在 App 记一条喂养后，回到桌面，摘要在合理时间更新（立即 requestUpdate 或 ≤15 分钟内用户可见；**目标：返回桌面后首次可见已更新**）  
  **通过条件：** 手测记 mil 后桌面喂养摘要变为新值（允许一次手动点桌面触发重绘）
- [x] **只读一致性**：摘要数值与同一时刻 CareLog 查询一致  
  **通过条件：** DTO 单测即主证据；手测抽查

### 边界

- [x] **不引入第二数据源**：无独立 Widget 专用假数据表作为真相源  
  **通过条件：** 代码审查：构建 DTO 调用 domain/CareLog
- [x] **无广告 / 无登录墙**：添加与展示不要求账号  
  **通过条件：** 手测
