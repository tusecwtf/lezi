# 04 — TXT 导出

**Parent:** [../spec.md](../spec.md)

**What to build:** 用户从菜单/设置导出指定宝宝、指定时间范围内的记录为 **UTF-8 纯文本**，经系统分享或 SAF 保存；至少支持导出跨度 **≥1 个自然月** 的数据。导出逻辑经薄 **ExportPort**（实现读 CareLog/Repository；UI 不拼业务字符串）。无付费墙、无广告水印。

**Blocked by:** V1 交付完成（Record 可读、菜单/设置壳、宝宝列表）

**Status:** done

---

## 交付物

| 层 | 内容 |
|----|------|
| ExportPort | `exportTxt(babyId, from: LocalDate, to: LocalDate): Uri` 或 `String`/`OutputStream` 契约；失败可 Result |
| 实现 | 读区间内未软删记录，格式化为可读行（日期、类型中文名、摘要、备注等） |
| Feature UI | `:feature:export` 或设置项「导出 TXT」：选宝宝、起止日期、触发分享/保存 |
| 测试 | 固定记录集 → 输出字符串包含期望行；空区间行为；宝宝隔离 |

**Seam：** ExportPort 为 UI 唯一导出入口；内部可依赖 CareLog，禁止 UI 直接扫 Room。

---

## 验收标准

### ExportPort / 内容

- [x] **行内容**：每条导出记录至少含：日期时间、类型（中文）、关键摘要（如奶量 ml、体温 ℃）、备注/正文（若有）  
  **通过条件：** 单测样例：`formula 120ml` note=`加了两段` → 输出同时包含日期片段、`配方奶`（或约定中文）、`120`、`加了两段`
- [x] **UTF-8**：文本为 UTF-8，中文不乱码  
  **通过条件：** 单测字节可解码为含中文的 String；或手测分享到文件打开
- [x] **时间范围**：`from`/`to` 闭开或闭闭区间实现写死；边界日记录按约定纳入  
  **通过条件：** 单测边界各 1 条，断言 in/out
- [x] **≥1 自然月**：UI 与 Port 均允许选择跨度 ≥一个自然月（如 2026-01-01～2026-01-31 或 01-15～02-14）  
  **通过条件：** 手测可选满月；单测 Port 接受 ≥31 天跨度且含月内全部样例行
- [x] **宝宝隔离**：只导出指定 `babyId`  
  **通过条件：** 单测
- [x] **软删排除**：`deleted_at != null` 不出现  
  **通过条件：** 单测
- [x] **空区间**：无记录时不崩溃；生成合法空文件或提示「无数据可导出」  
  **通过条件：** 单测 + 手测

### UI / 系统协作

- [x] **入口**：菜单或设置「导出」分组可见「导出 TXT」（中文）  
  **通过条件：** 手测可达
- [x] **选宝宝与日期**：导出前可指定宝宝与起止；默认合理（当前宝宝、近 30 日或当月）  
  **通过条件：** 手测可改范围再导出
- [x] **系统分享或 SAF**：调起系统 Share Sheet 和/或 存储访问框架保存；用户可选邮件/网盘/文件等  
  **通过条件：** 模拟器或真机导出后能在目标处打开 `.txt`（或分享预览可见正文）
- [x] **不强制自存**：App 私有目录不**要求**长期保留导出副本作为唯一交付；分享后由系统/用户管理  
  **通过条件：** 代码/说明不强制「仅云端会员可导出」；无「导出次数用尽」
- [x] **无付费墙 / 无广告水印**：导出流程无购买引导；正文无广告  
  **通过条件：** 手测全文与 UI

### 范围上限（防越界）

- [x] **不做 PDF**：本票无 PDF 入口或标明 V2  
  **通过条件：** 导出区无可用 PDF 或仅灰显「即将推出」且不可真导出 PDF

---

## 不在本票范围

- PDF 电子书（V2）
- 加密导出、自动定时备份到云
- 导出照片二进制打包
- 周汇总/成长/搜索/Widget 功能本身（01–03/05）
- 真同步与家庭共享导出权限（V2）
