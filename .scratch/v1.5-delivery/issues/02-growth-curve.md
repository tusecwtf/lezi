# 02 — 身长体重 + 成长曲线

**Parent:** [../spec.md](../spec.md)

**What to build:** 支持 `height` / `weight` 记录类型（图标网格录入 + 时间轴展示）；「成长曲线」Tab 展示至少**一套**可插拔百分位曲线包与实测点；可配置数据源文案与免责；支持**修正月龄**（依赖宝宝 `due_date` + 开关，过预产期显示辅助线）。写入/查询经 **CareLog**。

**Blocked by:** V1 交付完成（Baby、Record、图标网格、编辑流、成长 Tab 入口）

**Status:** done

---

## 交付物

| 层 | 内容 |
|----|------|
| Model / DB | `Record.type`：`height`、`weight`；`payload_json`：`value` + `unit`（如 cm / kg 或 g，与 `SettingsLocal.units` 一致） |
| Baby | 可编辑 `due_date`（预产期；引导或宝宝编辑页；V1 若未做则本票补齐字段与 UI） |
| CareLog | `addMeasurement` / 列表查询（或通用 `addRecord` + by-type 查询）；供曲线投影 |
| 曲线包 | assets 或只读配置 ≥1 套（WHO 简化表或自备百分位表）；`SettingsLocal.curve_dataset` 可选切换（入口可简） |
| Feature UI | `:feature:growth`：指标切换（身长/体重）、曲线+点、空态引导、修正月龄开关、来源/免责文案；录入入口（本页或跳转记录） |
| 测试 | 测量写入读回；给定包+点投影不崩溃；无点空态；修正月龄 X 轴偏移单测（纯函数） |

**Seam：** CareLog 为测量唯一写入口；曲线包只读，不写业务库。

---

## 验收标准

### 记录类型

- [x] **录入身高**：图标或成长页可创建 `height`，含数值与单位，保存成功  
  **通过条件：** 数据库/CareLog 读回 `type=height`，`value` 与输入一致（允许单位换算后等价）
- [x] **录入体重**：同上，`type=weight`  
  **通过条件：** 读回一致
- [x] **时间轴可见**：身高/体重出现在记录 Tab 时间轴，摘要含数值+单位  
  **通过条件：** 手测当日时间轴可见对应 cell
- [x] **编辑/删除**：走既有编辑流可改时间/数值或删除（确认删除）  
  **通过条件：** 删后时间轴与曲线点消失
- [x] **图标显隐**：若走网格，类型受排序/隐藏设置约束（与 V1 一致）  
  **通过条件：** 隐藏后网格不再显示该图标（若本票仅成长页录入则可 N/A 并在实现注释标明）

### 成长 Tab · 曲线

- [x] **Tab 实装**：底部「成长」/「成长曲线」不再纯占位  
  **通过条件：** 进入后可见指标切换或默认曲线画布区域
- [x] **至少 1 套曲线包**：冷启可加载百分位参考线（如 P3/P50/P97 或产品选定分位），不因缺网失败  
  **通过条件：** 无网打开成长 Tab，参考线仍绘制；包来自本地 assets/配置
- [x] **实测点**：存在 ≥1 条 height 时身长图有点；≥1 条 weight 时体重图有点；坐标随生日推算月龄合理（不出现负无穷/NaN）  
  **通过条件：** 单测或手测：写入已知生日+测量日+值，点落在预期月龄附近
- [x] **指标切换**：身长 ↔ 体重切换后点与轴标签对应类型  
  **通过条件：** 手测切换后不会把体重点画在身长轴且数值串类型
- [x] **空态**：无任何测量时引导「去录入」类文案，不崩溃  
  **通过条件：** 新宝宝打开成长 Tab 见引导，无 native crash
- [x] **来源与免责**：界面固定展示数据来源说明 + 非医疗诊断免责（中文）  
  **通过条件：** 成长页可见，无需进入二级隐藏页；文案不含他牌商标

### 修正月龄

- [x] **预产期**：宝宝可设置 `due_date`（可空）  
  **通过条件：** 编辑保存后读回日期
- [x] **开关**：有「修正月龄」设置；**无预产期时**开关不可开或开启后提示需填预产期  
  **通过条件：** 手测无 `due_date` 无法在无提示下静默启用
- [x] **辅助线/轴**：`due_date` 已填且开关开、且当前日期 ≥ 预产期（或按 PRD「过预产期后辅助线」实现）时，图上体现修正月龄对照（辅助线或双轴说明，实现写死）  
  **通过条件：** 同一测量点在开关开/关下月龄定位不同或出现明确辅助线；单测修正函数：`correctedAge = f(birthday, dueDate, onDate)`
- [x] **关闭后恢复**：关修正月龄后按实际月龄显示  
  **通过条件：** 手测开关切换点位/说明变化可逆

### CareLog 单测

- [x] 写入 height/weight 后按 `babyId` 查询有序返回  
  **通过条件：** JUnit 绿
- [x] 其它宝宝测量不泄漏  
  **通过条件：** JUnit 绿
