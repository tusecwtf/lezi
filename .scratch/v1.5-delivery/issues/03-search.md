# 03 — 搜索记录与日记

**Parent:** [../spec.md](../spec.md)

**What to build:** 用户可按**关键字**搜索当前宝宝的备注/日记等文本字段；结果列表展示并可进入既有编辑流；无结果明确空态。查询经 **CareLog.search**（或等价），默认宝宝隔离。

**Blocked by:** V1 交付完成（含记录编辑页、memo/diary/note 字段、当前宝宝上下文）

**Status:** done

---

## 交付物

| 层 | 内容 |
|----|------|
| CareLog | `search(babyId, query: String): List<Record>`（或含高亮摘要的 DTO）；匹配规则文档化（含大小写、空白） |
| Feature UI | `:feature:search` 或记录 Tab 动作按钮进入：搜索框 + 结果列表（复用时间轴 cell 风格）+ 空态 |
| 入口 | 记录页动作区「搜索」和/或菜单；与 `SettingsLocal.action_buttons` 显隐兼容（若 V1 已有配置） |
| 测试 | 命中 / 不命中 / 多宝宝隔离 / 软删不命中 单测 |

**Seam：** 仅 CareLog 查询；不引入独立搜索引擎依赖（Room `LIKE` / FTS 可，实现自选）。

---

## 验收标准

### 查询语义

- [x] **命中 note**：记录 `note` 含关键字则返回  
  **通过条件：** 单测：插入 note=`布洛芬 2.5ml`，query=`布洛芬` → 恰好命中该条
- [x] **命中日记/备注正文**：`diary` / `memo` 的 `body`（或 payload 正文）含关键字则返回  
  **通过条件：** 单测 body 命中；仅标题型 type 无正文且 note 空则不因 type 误命中（除非实现明确支持 type 中文名搜索——若支持须单测）
- [x] **不命中**：无关关键字返回空列表  
  **通过条件：** query=`不存在的词xyz` → size=0
- [x] **宝宝隔离**：默认只搜当前/`babyId` 指定宝宝  
  **通过条件：** 宝宝 A 有「发烧」、B 有「发烧」；搜 A 只返回 A
- [x] **软删**：已删记录不出现  
  **通过条件：** 单测
- [x] **空白 query**：空串或纯空白不抛异常；返回空列表或提示输入（实现写死一种）  
  **通过条件：** 单测 + UI 不崩溃
- [x] **大小写**：中文为主；若含英文，大小写不敏感或全敏感须一致并单测写明  
  **通过条件：** 单测覆盖选定策略

### UI / 交互

- [x] **入口可达**：从记录主路径 ≤2 次点击进入搜索页/面板  
  **通过条件：** 手测路径记录 → 搜索
- [x] **结果列表**：命中项展示时刻、类型图标/中文、摘要或笔记片段；默认新→旧（或与时间轴排序设置一致）  
  **通过条件：** 手测 ≥2 条命中时顺序合理
- [x] **进入编辑**：点一条结果进入既有编辑页，可改存或删除后返回  
  **通过条件：** 手测改 note 保存后，再搜新关键字可命中
- [x] **无结果空态**：明确中文空态（非空白白屏、非崩溃）  
  **通过条件：** 搜无结果见「无结果」类文案
- [x] **多宝宝切换**：切换当前宝宝后重新搜索，结果集隔离  
  **通过条件：** 手测与单测一致

### 非功能（轻量）

- [x] **本地**：不访问网络完成搜索  
  **通过条件：** 飞行模式可搜本地数据

## 不在本票范围

- 全文搜索云端、拼音首字母、语音搜索
- 按类型筛选器高级组合（可后续）；本票关键字足够
- 搜索照片 OCR
- 周汇总/成长/导出/Widget（01/02/04/05）
- PDF、同步（V2）
