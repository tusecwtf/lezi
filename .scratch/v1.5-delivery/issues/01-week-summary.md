# 01 — 周汇总四图

**Parent:** [../spec.md](../spec.md)

**What to build:** 将「汇总」Tab 从占位改为实装：用户打开后看到**当前周**喂养、睡眠、排泄、体温四类可视化，可切换上一周/下一周；无数据时空态友好。支持可选：平均睡眠、与上周比较、周起始日（`SettingsLocal.week_start`）。聚合逻辑经 **CareLog** 扩展（如 `weekSummary(babyId, weekStart)`），图表 UI 不直连 Room。

**Blocked by:** V1 交付完成（记录写入、CareLog 日查询、底部「汇总」Tab 入口已存在）

**Status:** done

---

## 交付物

| 层 | 内容 |
|----|------|
| Domain / CareLog | `weekSummary(babyId, weekStart: LocalDate)`（或等价）：返回该周 7 日桶的喂养、睡眠、排泄、体温聚合 DTO |
| Domain 设置 | 读取/写入 `week_start`（周一/周日等）、`show_avg_sleep`、`compare_prev_week`（名可等价；落 SettingsLocal / DataStore） |
| Feature UI | `:feature:summary`：周导航 `‹ 本周 ›` + 四模块图（可滚动）；空态文案；可选对比/平均展示 |
| 测试 | 固定时钟 + 固定记录集 → 周桶数字单测（不测 Compose/图表库内部） |

**Seam：** CareLog 周聚合为唯一业务入口；UI 只消费 DTO。

## 验收标准

### 聚合（CareLog / 纯函数）

- [x] **喂养桶**：给定 `formula`/`pumped_feed` 的 `amount_ml` 与 `nursing` 的左右分钟（及可选 ml），按自然日落入正确周桶；合计 ml 与次数/分钟与输入一致  
  **通过条件：** 单测固定 3～7 条跨日记录，断言 7 日数组中对应下标的总量与次数
- [x] **睡眠桶**：给定带 `end_timestamp` 的 `sleep`，日睡眠总时长（分钟）落入正确日；跨午夜可按产品约定切分或计入开始日（实现二选一并在单测注释写死）  
  **通过条件：** 单测至少 1 条当日睡眠 + 1 条跨日（若支持）时长正确
- [x] **排泄桶**：`pee` / `poop` / `both_diaper` 按次计入对应日  
  **通过条件：** `both_diaper` 计 1 次排泄事件（或尿+便各 1，实现写死并测），不把其它 type 计入
- [x] **体温桶**：`temperature` 的 `celsius` 按日聚合（点列或日均，实现写死）；无体温日为空  
  **通过条件：** 单测 2 日各 1 点，DTO 可还原数值
- [x] **周界**：`week_start=MONDAY` 与 `SUNDAY` 时，同一 `timestamp` 落入的周窗口不同且与设定一致  
  **通过条件：** 单测同一条周日记录在两种 `week_start` 下 `weekStart`/`weekEnd` 不同
- [x] **宝宝隔离**：`weekSummary` 只聚合指定 `babyId`  
  **通过条件：** 两宝宝同周数据，互不出现对方合计
- [x] **软删**：`deleted_at != null` 的记录不计入  
  **通过条件：** 单测删除前后桶变化

### UI / 交互

- [x] **汇总 Tab 实装**：底部「汇总」进入后**不再**仅为「即将推出」占位；可见周标签与至少四块图区标题（喂养 / 睡眠 / 排泄 / 体温）  
  **通过条件：** 手测或截图路径：有宝宝时打开汇总不崩溃、四模块标题可见
- [x] **周导航**：`‹` / `›` 切换上一周/下一周；标题反映范围（如「本周」或起止日）  
  **通过条件：** 从本周点 `‹` 一次，聚合数据变为上一自然周；再 `›` 回到本周
- [x] **有数据周**：在本周写入喂养、睡眠、排泄、体温各 ≥1 条后，对应模块不再全空（有柱/点/条或数字）  
  **通过条件：** 手测四类均有可见数据痕迹
- [x] **空态**：新宝宝或该周零记录时不崩溃，示意空图或文案含「记几天就有图表」类提示（可等价中文）  
  **通过条件：** 清空该周数据后打开汇总，进程不退出且有空态文案
- [x] **多宝宝**：切换当前宝宝后，汇总数字/图随之切换  
  **通过条件：** 宝宝 A 有数据、B 无数据；切 B 见空态，切 A 见数据

### 可选能力（本票范围内，须可关）

- [x] **周起始日**：设置中可改周一/周日；改后当前周窗口与四图重算  
  **通过条件：** 改设置后无需重装，返回汇总即按新周界
- [x] **平均睡眠**：开关打开时展示本周平均睡眠（有睡眠数据时）；关闭不展示  
  **通过条件：** 开关切换 UI 有无「平均」相关文案/数字
- [x] **与上周比较**：开关打开时至少一类指标展示相对上周的对比（差值或箭头/文案）；关闭不展示  
  **通过条件：** 本周与上周写入不同合计，打开对比可见差异提示

### 回归边界

- [x] **不破坏 V1 记录 Tab**：完成汇总后，当日快记与时间轴仍可用  
  **通过条件：** 从汇总回记录，图标网格可写一条 formula
