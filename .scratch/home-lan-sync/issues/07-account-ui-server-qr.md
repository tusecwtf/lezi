# 07 — 账户 UI：服务器 / 扫码 / 状态 / 退出 / 删家庭

## What to build

账户/共享页 V2：

- **必填**家庭服务器地址（无默认）；可手改 host/port
- 创建家庭 / 生成邀请；**QR 载荷含 baseUrl + code**
- 扫码或粘贴加入（仍受客户端门闩：须在家 Wi‑Fi）
- 同步状态：空闲 / 同步中 / 非家网 / 错误；上次成功时间；「立即同步」
- 文案：仅家庭 Wi‑Fi；不对伴侣记录推送
- 退出家庭；owner **删除家庭数据**（多重确认）
- 加入前明示全量共享
- 错误主文案中文（避免裸奔 `Failed to connect to /10.0.2.2`）

## 交付物

| 工程 | feature/family UI |

## 验收标准（Must）

- [x] 未填 baseUrl 无法完成建家/加入（引导填写或扫码）
- [x] 生成的 QR/载荷可被解析出 baseUrl 与 code
- [x] 非家网点击同步 → 中文提示，不崩
- [x] 退出后本地不再 pull 该家庭
- [x] owner 删除需二次确认

## 不在本票范围

- P2P、公网中继
