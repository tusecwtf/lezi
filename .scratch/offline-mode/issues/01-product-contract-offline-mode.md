# 01 — 产品契约：离线模式

**What to build:** 把「离线模式」写进产品权威文档与术语表：未加入家庭的用户可先本机建宝宝并记账；**新建家庭 / 加入家庭只在账户菜单决定**，不在引导里二选一完成；未加入期间不同步，连上家庭后走既有同步与成员本机孤宝宝规则。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

## Acceptance criteria

- [ ] `CONTEXT.md` 增加 **离线模式** 词条，并与「本机孤宝宝」「家庭权威宝宝」「家庭向导」边界说清：离线阶段本机宝宝在未加入前不叫本机孤宝宝；加入为成员后才可能成为本机孤宝宝
- [ ] 同步/引导相关 PRD 写明：引导除「新建家庭」「加入家庭」外，提供 **离线模式**；离线模式不配置 NAS、不建会话
- [ ] PRD 写明：离线记账后，用户在**账户**发起新建或加入；不在离线引导内选择家庭路径
- [ ] 文档声明无新 wire / 无新服务器实体；复用现有建家、加入、成员再绑定与管理员上行
- [ ] 本 tracker `spec.md` 与文档一致，无矛盾措辞

## Out of scope

- 实现引导按钮或改导航门闩
- 改同步引擎行为
