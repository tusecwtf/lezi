# 04 — 稍后加入家庭：本机数据并入权威宝宝

**What to build:** 用户先走离线模式记账，之后在账户 **加入家庭** 时，本机先写数据不丢失：成为成员后按现有 **本机孤宝宝** 规则再绑定到家庭权威宝宝（单一权威自动合并、多个需选择）；未绑定前不得以无效宝宝引用上行；绑定后脏记录/计划可随前台同步发布。

**Blocked by:** 02 — 引导增加「离线模式」并进主屏

**Status:** complete

## Acceptance criteria

- [x] 离线模式写入的记录在加入成功后仍在本机可读
- [x] 恰有一个家庭权威宝宝时，本机孤宝宝数据自动再绑定（或与现产品自动合并行为一致）
- [x] 多个权威宝宝时，用户须明确选择合并目标；不得静默丢弃本机事实
- [x] 未再绑定前，出站不发布挂在孤宝宝上的记录/计划（沿用现成员防护）
- [x] 再绑定后，前台/下拉同步可将事实推到家庭（在家网与会话可用前提下）
- [x] 有自动化测试覆盖「先有本机宝宝与记录 → 加入为成员 → rebind/防护」关键路径

## Out of scope

- 管理员「新建家庭」首推路径（见 05）
- 改 NAS join API
