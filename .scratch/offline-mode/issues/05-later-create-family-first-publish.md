# 05 — 稍后新建家庭：本机数据首次发布

**What to build:** 用户先走离线模式记账，之后在账户 **新建家庭**（管理员）时，本机宝宝与护理事实成为家庭侧可同步数据：建家成功后本机宝宝可作为家庭权威宝宝上行，记录/计划/媒体在会话与家网可用时随前台同步首次发布，不得静默清空离线期数据。

**Blocked by:** 02 — 引导增加「离线模式」并进主屏

**Status:** complete

## Acceptance criteria

- [x] 离线期本机宝宝与记录在建家成功后仍在
- [x] 建家成功后角色为管理员；本机宝宝不按成员「禁止上传宝宝」规则丢弃
- [x] 前台同步可将本机宝宝与离线期记录发布到家庭服务器（家网可达时）
- [x] 不与 reclaim「接回前不得创建占位宝宝」路径混淆：本路径是空会话上的新建 + 已有本机数据
- [x] 有自动化测试或可重复脚本覆盖「本机数据 → 建家 → 首次 push/pull 可见」关键语义

## Out of scope

- 成员加入与孤宝宝 UI（见 04）
- 改 create-family wire 字段
