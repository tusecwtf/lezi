# 03 — 账户：未加入时用新建/加入完成家庭路径

**What to build:** 用户经离线模式已有本机宝宝时，在**账户**菜单能清楚完成家庭连接：主行动仍是 **新建家庭** 与 **加入家庭**（既有向导）；同步状态表达「本机可记，连上家庭后再同步」，不暗示必须先同步才能使用。

**Blocked by:** 01 — 产品契约：离线模式

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 未加入家庭时，账户概览主行动仍为新建家庭 / 加入家庭（不把入口只藏进网络设置）
- [ ] 已有本机宝宝、仍未加入时，状态文案不要求「先同步」；可表达本机使用、稍后连家庭
- [ ] 从账户可完整打开既有新建/加入向导，行为与未离线路径一致（网络步、称呼、成功后会话）
- [ ] 不在账户首屏堆叠服务器表单或三步同步条（符合账户概览 ADR/术语）

## Out of scope

- 离线引导入口本身（见 02）
- 加入后孤宝宝再绑定细节（见 04）
- 建家后首推细节（见 05）
