# 02 — 引导增加「离线模式」并进主屏

**What to build:** 在首启引导家庭选择步增加主入口 **离线模式**。用户选择后只走本机创建宝宝（不配置服务器、不 bootstrap、不加入），宝宝创建成功后离开引导进入五栏主屏，可立刻记录护理事实。

**Blocked by:** 01 — 产品契约：离线模式

**Status:** complete

## Acceptance criteria

- [x] 引导家庭选择步可见 **离线模式** 入口（命名即此四字，不作别名主文案）
- [x] 点离线模式进入本机建宝宝流程；不要求家庭网、主机、端口或 bootstrap
- [x] 本机宝宝创建成功后 `hasBaby` 为真，引导消失，进入主壳（默认记录等日常 Tab 可用）
- [x] 离线模式下可完成至少一类护理记录写入与列表可见（本机 Room 真相源）
- [x] 不在本路径完成「新建家庭」或「加入家庭」；会话角色保持未加入
- [x] 单元/适配测试覆盖：选择离线模式 → 建宝宝 → 应显示引导为假；未建宝宝前仍挡主壳（与现有门闩语义一致）
