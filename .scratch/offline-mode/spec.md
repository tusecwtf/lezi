# 离线模式 · Spec

**Status:** complete  
**Tracker:** [ISSUES.md](./ISSUES.md)

## Intent

允许用户在**尚未新建或加入家庭**时，以 **离线模式** 进入主屏并在本机记录护理数据；之后在**账户**菜单里再选择「新建家庭」或「加入家庭」，再与家庭局域网同步。

## Product decisions (locked)

| Decision | Choice |
|----------|--------|
| 入口命名 | **离线模式**（不用「先自己记」等别名作主名） |
| 引导路径 | 选择离线模式 → 本机创建宝宝 → 进主屏记账 |
| 家庭路径时机 | **不在引导里**决定新建还是加入；一律放到 **账户** 的「新建家庭 / 加入家庭」 |
| 同步 | 未加入：本地 Room 可用，不同步；加入/建家成功后：既有前台同步与成员本机孤宝宝再绑定规则适用 |
| Server / wire | 无新协议要求；优先复用现有建家、加入、孤宝宝再绑定与 owner 上行 |

## Glossary hooks

- **离线模式**：未加入家庭时的本机使用路径；可建本机宝宝并写入记录/计划。
- **本机孤宝宝**：仅在**普通成员加入家庭后**、本机宝宝尚不属于家庭权威宝宝集合时的称谓（见 `CONTEXT.md`）；离线模式阶段的本机宝宝在未加入前不称孤宝宝。
- **家庭权威宝宝**：管理员创建并经服务器下发的共享宝宝档案。

## Out of scope (this tracker)

- 已加入家庭后的「关闭同步开关」或断网专用模式
- 改 NAS API / 新 wire 实体
- 多宝宝复杂合并策略重写（沿用现有成员 rebind/选择）
