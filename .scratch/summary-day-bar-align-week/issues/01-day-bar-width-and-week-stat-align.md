# 01 — 汇总「日」柱状图限宽，并与 7 日统计口径对齐

**What to build:** 照护者在汇总页切到「日」时，喂养 / 睡眠 / 尿布主图不再出现拉满卡片的胖柱；主图系列与「周」图同一套 care 聚合口径一致——当日奶量、已完成睡眠分钟、尿/便次数，且同一天在「日」主图上的数值等于「周」图该日柱上的值。顶栏指标卡与卡片合计仍表示「当日」；「周 / 月」行为不变。日视图主图采用与周图相同的系列与组件形态；原先仅日视图使用的四时段喂养次数分布不再作为主图。

**Blocked by:** None — can start immediately

**Status:** complete

- [x] 汇总「日」下喂养、睡眠、尿布主图柱宽有上限，单日一根时不按全宽拉满；视觉密度与「周」七柱大致一致（居中或按最大柱宽收窄）
- [x] 日视图主图统计口径与周图对齐：喂养为当日奶量（同一 care 聚合）、睡眠为当日已完成睡眠分钟、尿布为当日尿/便次数
- [x] 固定样本下，锚点日在「日」主图上的值等于「周」图该日柱上的值
- [x] 四时段喂养次数分布不再作为日视图主图（移除或降级，不得抢主图位）
- [x] 顶栏当日指标卡与图表卡片「当日」合计语义不变；切到「周」「月」的系列长度、对比上周、日均睡眠等行为不回归
- [x] 自动化覆盖：单日柱宽不拉满全宽、日主图与周同日值一致；相关模块测试与构建通过
