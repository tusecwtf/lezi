## Problem Statement

照护者在记录首页看到顶部**日汇总**五格（奶、母乳、睡眠、尿、便）与下方**一日时间条**时，两块信息心智是同一套「今日节奏类型」，但交互不对称：

1. 时间条色块/圆点与图例已经可以进入**日图类型筛选**：选中类标记加重高亮、其它类弱化，明细收窄到该类。
2. 顶部日汇总五格与上述五类一一对应，却**不可点**，也无法呈现与时间条一致的「选中加重」反馈。
3. 想「先看今天尿了几次、再只盯尿」时，必须下移去点图例或时间条，而不能直接点汇总格。

结果是：日汇总仍是纯读数，没有成为与时间条同一筛选模型的第三入口；用户也无法从汇总格一眼读出「当前正在预览/筛选哪一类」。

---

## Solution

让记录页顶部五格日汇总成为**日图类型筛选**的第三入口，并与时间条共用同一选中态：

1. 五格可点；点某一格进入（或切换到）对应**日图类型**的筛选态。
2. 选中格呈现**按钮式加重**（描边/底色/字重等选中语言），与时间条上该类标记的点击加重预览**同源同步**——同一 `selected`，不是两套假状态。
3. 进入筛选后：时间条高亮/弱化、图例选中态、类型提示条、记录明细过滤等行为与现有日图类型筛选一致。
4. **日汇总数字始终为全日合计**，不因筛选改写（与既有产品结论一致）。
5. `warm` 与 `journal` 两套模板同一交互语义。

术语以 `CONTEXT.md` 为准：日图类型、日图类型筛选。

## User Stories

1. As a 照护者, I want 点顶部「尿」汇总格后进入尿的日图类型筛选, so that 我不必下移去点时间条
2. As a 照护者, I want 点顶部「便」汇总格后只看到便相关节奏与明细, so that 我能快速核对排泄
3. As a 照护者, I want 点顶部「奶」汇总格后筛选瓶喂类奶, so that 配方与瓶喂挤出乳可单独扫
4. As a 照护者, I want 点顶部「母乳」汇总格后筛选母乳, so that 母乳与瓶喂奶分开看
5. As a 照护者, I want 点顶部「睡眠」汇总格后筛选睡眠, so that 我能专注睡醒段落
6. As a 照护者, I want 点中某格后该格有明确的按钮加重选中态, so that 我知道当前筛的是哪一类
7. As a 照护者, I want 汇总格选中加重与时间条上该类标记加重预览同步出现, so that 上下两块信息读起来是同一选择
8. As a 照护者, I want 点汇总格后图例上对应类也进入选中态, so that 三个入口看起来是同一状态
9. As a 照护者, I want 再点已选中的同一汇总格时取消筛选, so that 退出方式与图例/色块一致
10. As a 照护者, I want 从「尿」汇总格改点「便」时直接切换筛选, so that 换类只需一次点击
11. As a 照护者, I want 在时间条上点出筛选后顶部对应汇总格也加重, so that 从下往上也能读出当前类
12. As a 照护者, I want 在图例上点出筛选后顶部对应汇总格也加重, so that 入口之间完全互通
13. As a 照护者, I want 取消筛选（再点/点空白/点提示条/换日）后汇总格恢复未选外观, so that 不会假高亮残留
14. As a 照护者, I want 筛选时五格数字仍是全日合计, so that 总览不会跟着列表一起变短
15. As a 照护者, I want 当日某类没有日图类型数据时点该汇总格不会卡在空筛选, so that 0 次格子不会变成死态
16. As a 照护者, I want 当日有尿数据时即使「尿」次数显示为汇总口径仍可点选, so that 汇总显示与可筛集合一致可用
17. As a 照护者, I want 尿+便记录在筛尿或筛便时仍按既有规则出现, so that 合并记录不丢
18. As a 照护者, I want 筛选「奶」仍不含吸奶, so that 与既有日图类型归类一致
19. As a 照护者, I want 点汇总格不会打开记录编辑 Composer, so that 点选只用于筛选预览
20. As a 照护者, I want 筛选后仍从明细行进入编辑, so that 改记录路径不变
21. As a 照护者, I want 换日后汇总格选中态自动清除, so that 不会把昨天的筛选带到今天
22. As a 照护者, I want 换宝宝后选中态清除, so that 不会把 A 宝的筛选带到 B 宝
23. As a 照护者, I want 选中类在同步/删除后当日消失时自动解除并去掉加重, so that 不会卡在 0 条
24. As a 照护者, I want 温暖卡片模板五格同样可点可加重, so that 换模板不丢能力
25. As a 照护者, I want 紧凑记录簿模板五格同样可点可加重, so that 两套模板语义一致
26. As a 照护者, I want 未筛选时五格均不呈现选中加重, so that 默认总览保持安静
27. As a 照护者, I want 选中一类时其它四格保持非加重外观, so that 一次只强调一类
28. As a 照护者, I want 汇总格触控目标足够大、可选中语义可读, so that 单手可点且 TalkBack 能理解
29. As a 照护者, I want 非今日日期下同样能用汇总格筛选, so that 回看历史日能力一致
30. As a 照护者, I want 下拉刷新后若该类仍在则筛选与加重保持, so that 刷新不无故打断
31. As a 照护者, I want 时间条因当日无日图类型而隐藏时，点有数据类汇总格仍进入筛选（列表收窄；无时间条可高亮则仅列表+格加重+提示若有）, so that 汇总入口不依赖时间条是否渲染
32. As a 照护者, I want 筛选状态仍不持久化, so that 重进记录页不会莫名其妙还在筛某类
33. As a 开发者 agent, I want 汇总格到日图类型的映射可用纯函数锁定, so that 五格与五类不会接线漂移
34. As a 开发者 agent, I want 点汇总格走同一页级 select reduce, so that 不出现第二套筛选状态机
35. As a 照护者, I want 点汇总格时有按下/选中加重反馈而不是完全无反馈的静态字, so that 交互像按钮而不是装饰
36. As a 照护者, I want 已选中格的加重语言与时间条标记加重方向一致（更醒目、对比更强）, so that 「预览加重」上下可对照
37. As a 照护者, I want 取消筛选后明细回到全日（含非日图类型）, so that 与既有筛选退出行为一致
38. As a 照护者, I want 点汇总格不会改写日汇总聚合口径或设置项, so that 这是临时视图导航
39. As a 照护者, I want 窄屏下五格仍可点且选中态不被裁切到不可辨, so that 小屏可用
40. As a 照护者, I want 从汇总格进入筛选后类型提示条仍显示类名与条数, so that 与时间条入口信息量一致（时间条可见时）

## Implementation Decisions

### 关系：扩展既有日图类型筛选，不另起炉灶

- 本功能**复用** `.scratch/day-chart-type-filter` 已落地的：
  - 日图类型五类与 `categoriesOf` / `filterRecords` / `toggleSelection` / `reconcileSelection`
  - 页级临时 `selected: DayChartCategory?`
  - 时间条高亮/弱化、图例选中、类型提示条、明细过滤、换日/换宝宝清除
- **新增**：日汇总五格作为**第三入口** + 五格的选中加重外观，绑定同一 `selected`。
- **不**改变日汇总数字口径；**不**把筛选持久化进设置。

### 五格 ↔ 日图类型映射（稳定）

| 日汇总格（产品标签） | 日图类型 | 说明 |
|----------------------|----------|------|
| 奶 / 奶量 / 奶ml | 奶 | 汇总数字仍为配方+瓶喂挤出乳 ml 等现网全日口径 |
| 母乳 | 母乳 | 现网母乳分钟全日口径 |
| 睡眠 | 睡眠 | 现网睡眠时长全日口径 |
| 尿 / 尿尿 | 尿 | 现网尿次全日口径 |
| 便 / 便便 | 便 | 现网便次全日口径 |

- 映射是固定表，**不是**根据格子上的 `RecordType` 图标语义临时推断出第二套分类。
- 实现上可用纯函数：`summaryCell → DayChartCategory`（或等价 key），供接线与单测共用。

### 交互

| 用户动作 | 结果 |
|----------|------|
| 点汇总格 C（该类当日有日图类型数据） | 与点图例 C 相同：`toggleSelection`（同类取消、异类切换） |
| 点汇总格 C（该类当日无日图类型数据） | **不进入** sticky 空筛选；保持 `selected` 不变或视为未命中（实现任选其一，验收以「不出现 0 条死态」为准） |
| 点时间条/图例改变 `selected` | 对应汇总格选中加重同步 |
| 再点已选格 / 点空白 / 点提示条 / 换日 / 换宝宝 / reconcile 清除 | 汇总格全部回到未选外观 |

- 点汇总格**不**打开 Composer、**不**新建记录、**不**跳转汇总 Tab。
- 时间条隐藏（当日无任一日图类型）时：若五格仍显示全日 0，点格不得卡死；有数据类时仍可筛列表。

### 选中加重视觉

- **同源**：汇总格 `selected == 对应日图类型` 时呈现加重；时间条用现有标记高亮/弱化。
- **加重方向**（按钮感，非整页换肤）：
  - 选中格：更强描边/底色/字重或容器 elevation 一类「按下后加重」的选中语言；
  - 未选格：保持现网默认汇总外观（可略静，但不强制整条 dim 到不可读——数字仍须可读，因全日合计仍有意义）。
- 视觉应跟设计系统现有选中语言（图例 chip 的 primary 描边/容器等）**同一家族**，不必像素复制图例，但用户应能感到「和点时间条是一回事」。
- `warm` 的独立 Metric 卡与 `journal` 的条带五格都要有选中态；两套布局可不同，语义相同。

### 状态与模块边界

- **筛选真源**仍在记录页状态层（现有 reduce），日汇总 UI **只消费** `selected` + 回调，不私藏第二套 selected。
- 日汇总组件（条带/Metric）可增加：`selectedCategoryKey` / `onCategorySelect` 或等价参数；无业务归类硬编码在 Canvas。
- **主业务接缝不变**：日图类型纯模型 + 页级 `reduceDayChartFilter`；本功能只增加「汇总格 → category key」映射与 UI 接线。
- **无** Room / 同步 / 设置 schema 变更。

### 无障碍（最低）

- 汇总格表达可选中筛选；选中态对 TalkBack 可读（如「已选尿，再点取消筛选」），风格对齐现有图例 `contentDescription`。
- 触控目标尽量满足现网 ≥48dp 原则；五格并排时以整格为热区。

## Testing Decisions

### 什么叫好测试

- 只断言**对外行为**：给定汇总格身份与当日 records / 当前 selected，得到映射出的日图类型、toggle 后 selected、列表过滤结果是否与图例入口一致。
- 不测 Compose 像素、主题色具体 ARGB、动画插值。
- 不测 Room / 同步。

### 主接缝（优先复用 + 一条薄映射）

1. **既有**：`DayChartCategories` + `reduceDayChartFilter` / `resolveDayChartSelection`（已有 domain 与 feature/log 单测）——本功能**不得**分叉第二套 toggle/reconcile。
2. **新增薄接缝**：日汇总格 → `DayChartCategory`（或稳定 key）的纯映射；单测锁定五格各映射到奶/母乳/睡眠/尿/便，且无第六类。

至少覆盖：

1. 五格映射表正确、稳定
2. 对映射结果执行与图例相同的 `Select(key)` reduce → selected 一致
3. 再点同类 → null；点另一类 → 切换
4. 无数据类不产生 sticky 空筛选（与 `reconcileSelection` / 入口守卫一致）
5. 换日/换宝宝清除后汇总侧 selected 也为 null（走既有 ChangeContext，无需新逻辑则只回归接线）

### Prior art

- `domain`：`DayChartCategoriesTest`
- `feature/log`：`DayChartFilterWiringTest`
- 日汇总数字本身：`DailySummaryTest` / `CareAggregation`——**不要**为点选去改聚合断言；本功能不改变口径

### 非主接缝

- 两套模板选中态视觉：人工或截图 smoke 即可
- 真机点五格与时间条互相同步：可选 device smoke

## Out of Scope

- 改写日汇总数字为「仅筛选类合计」或局部高亮数字
- 把吸奶并入「奶」、第六汇总格、体温进五格
- 筛选状态持久化、跨日/跨宝宝记忆
- 点汇总格打开编辑/新建/跳转汇总周图
- 重做时间条几何、拆五物理轨
- 汇总 Tab / Widget / 搜索的同类点选
- 数据模型、同步协议、导出
- 护理计划待履行区与汇总格联动

## Further Notes

- 产品一句话：顶部五格从「只读合计」升级为「可点的日图类型筛选入口」，加重预览与时间条同源。
- 与 `day-chart-type-filter` 的关系：该 spec 已规定「日汇总不随筛选变数字」；本 spec **遵守**该条，只补「可点 + 加重同步」。
- 若实现时发现 journal `RecordSummaryStrip` 与 warm `SummaryMetric` 参数形状不一，允许在 UI 层各接同一回调，但 **selected 真源只有一处**。
- 可选后续：把「日汇总 chips 可筛」写回 `docs/prd/ui.md` 组件表一行；`CONTEXT.md` 日图类型筛选定义可扩写「含日汇总格入口」。
