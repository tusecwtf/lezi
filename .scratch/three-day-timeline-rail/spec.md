## Problem Statement

照护者回看「一天的节奏」时，时间条被锁在选中自然日的 0–24h 内：

1. **跨午夜睡眠与夜喂**被切成两天，连续感差。  
2. **无法窥视邻日**，要改日期栏才能看到前后节奏。  
3. journal 纵向轨道与 warm 横向轨道两套几何，后续加平移成本高。

---

## Solution（grill 锁定）

| 决策 | 选择 |
|------|------|
| 3 天窗口锚点 | 日期栏选中日 **D**：`D−1 \| D \| D+1` |
| 拖动 vs 选中日 | **纯窥视**，不改 D；汇总/列表/日期栏仍跟 D |
| 轴形态 | **连续 72h** 横向轴，可平移 |
| 邻日样式 | 非 D 标记**变浅** |
| 今日默认视口 | 以 wall-clock **现在**为中心 |
| 非今日默认视口 | **D 为主 + 左右略露邻日** |
| 点标记 | 只认**日图类型**；列表仍筛 **D** |
| 筛选高亮 | **72h 内该类全亮**；列表仍只含 D |
| 空筛门闩 | 该类在 D 上 0 条 → **不进入筛选（A2）** |
| 图例 / 可筛集合 | **只看 D** |
| 跨午夜睡眠 | 轴上**一条连续条**；统计/列表归属仍按自然日 |
| 日界 | **只有线、无字** |
| 「现在」线 | 仅当现在落在 72h 窗口内才画 |
| 出图 | **三天任一有日图类型**即显示 |
| 模板 | **统一横向 72h**；删除 journal 竖轴实现以精简代码 |

日汇总始终全日口径，不随窥视/筛选变。日图类型五类与筛选状态模型沿用现网（临时、非持久、换日清空）。

---

## Out of Scope

- 拖动改选中日 / 松手吸附换日  
- 图例并集三天、或允许 D 上 0 条的粘性筛选  
- 日界旁日期文字标签  
- 竖轴 journal 保留双实现  
- 汇总页周网格、Widget 时间条  
- 数据模型 / 同步协议变更
