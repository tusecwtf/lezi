# 01 — 清除本机记录：屏障补偿与诚实失败

**Parent:** [../spec.md](../spec.md)

**What to build:** 已加入家庭时，照护者清除本机记录（及清除全部本地，若入口仍在）只有在同步侧屏障全部完成后才算成功。若本机记录已删而后续清理失败：提醒必须停、已删记录不得再被推上家庭服务器，界面诚实失败并说明可重试清理；不承诺恢复已删本机内容。文案始终是「只清本机、家庭服务器还在、下次家网同步可能拉回」，禁止做成全家永久删除或自动离开家庭。

**Blocked by:** None — can start immediately

**Status:** complete

## Acceptance criteria

- [x] 已加入家庭：确认/成功文案表明仅本机清除；服务器历史保留；下次家庭同步可能重新下载（无「永久抹掉全家」表述）
- [x] 仅当领域删除 + 提醒收尾 + Outbox/同步屏障全部完成后 UI 才成功
- [x] 领域提交前失败：本机记录/日程/提醒不变；UI 非成功（既有行为）
- [x] 领域已提交、屏障中失败：相关提醒已取消；Outbox 不得再 push 已删记录类实体；UI 失败并提示本机可能已部分清理、服务器仍保留、请重试清理
- [x] 重试屏障可再次执行收尾，不要求先恢复已删本机行；成功后设备对后续同步一致（不再复活那些删除）
- [x] 清除全部本地（若可达）遵守同一「成功后置 + 提交后补偿」规则
- [x] 未加入家庭时清除文案不恐吓家庭服务器；仍无虚假「世界已清空」
- [x] 本票不做：自动 leave、清除后挂起同步、服务器 tombstone 清历史
- [x] 接缝 S1 单测：提交前失败；提交后屏障失败不复活 push；重试；成功路径
- [x] P1 纪律：不拆家庭上帝屏；仅允许修 bug 所需最薄提取
