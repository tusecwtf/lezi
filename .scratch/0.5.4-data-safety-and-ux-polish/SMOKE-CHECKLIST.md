# 0.5.4 两台真机冒烟清单（人工执行）

> 票 18 的不可自动化部分。spec Testing Decisions「验收基线」两流验证点 +
> 0.5.1/0.5.2/0.5.3 三张发布票共同欠下的真机步骤，一次收口。
> **角色**：设备 A / 设备 B = 两台已加入同一家庭的手机（家庭管理员账号在 A）。
> 每步通过打 `[x]`；不通过在行尾记「(FAIL: 现象)」，不要跳过不记。

## 0. 安装（两台都做）

- [ ] 两台直接安装 0.5.4 / versionCode **34** 的 **release** 签名 APK（覆盖安装，数据保留）
- [ ] 系统设置 → 应用信息确认版本 `0.5.4`（34）
- [ ] 打开 App 正常进入记录页，底部无强制更新壳（**预期**：NAS 与更新渠道仍指 0.5.3，
      本机 34 > 渠道 33，应用内「检查更新」不会也不能提示 0.5.4——这不是缺陷）

## 1. 数据安全（spec：dismiss 不复活 / 宝宝合并 / 退出设备披露）

- [ ] **S1 去掉后不复活**：让一条记录在两端产生未对齐（A、B 各改一次同一记录）；
      A 在「待处理」对它选「只从这台手机去掉」，确认文案含
      「若家人之后修改了这条，它也不会再回到这台手机。」
- [ ] S1 续：B 再修改那条记录并等两端同步完成；A 下拉刷新记录页与「待处理」
      → 该记录**不**在 A 复活（时间轴、待处理都不出现）
- [ ] **S2 宝宝合并**（A 家庭管理员操作）：把两个家庭宝宝合并
      → 合并后所有记录/计划归入保留的宝宝；被并掉的宝宝名下无残留记录；
      A、B 两端时间轴一致、待处理不新增无法处理的卡片
- [ ] **S3 退出披露**（先别真退）：在 B 制造 ≥1 条未同步记录（离线记一条），
      打开 账户 → 退出这台设备 → 弹窗显示「还有 N 条未同步，退出后将永久丢弃」，
      N 与 B 顶部待同步徽章一致
- [ ] S3 续：点「先同步再检查」→ 回到联网等一轮同步 → 弹窗计数减少或归零；
      最后**取消**退出（本步不要真的退出；真退出语义不变、仍会清数据）
- [ ] S3 续（可选，需愿承担清理）：NAS 断开时重复上一步 → 「仍然退出」仍可点，
      不会被困在弹窗里
- [ ] **S3 被动移除收据**（可选，需牺牲一台登录态）：A 在成员/设备管理移除 B；
      B 下次打开家庭/网络设置面 → 看到「该设备于 … 被家庭管理员移除，已清理 N 条未同步内容。」

## 2. UX 信任面与动效（spec：暗色收件箱/弹层、空周期汇总、导出、通知计时、长辈模式）

- [ ] **T1/M1 暗色收件箱**：系统深色下打开冲突收件箱：首帧**不**闪「目前没有待处理项」；
      有卡片时行内无「删除状态待加载 / 提交者详情待加载」这类词；顶部有一句「什么会出现在这里」的解释
- [ ] T1 续：飞行模式打开收件箱 → 出明确错误态与「重试」；恢复网络点重试 → 内容正常
- [ ] **M1 暗色弹层/表盘**：深色下打开任一记录二级面板与计时表盘 → 底色为品牌蓝黑，不再发紫
- [ ] **T2 空周期汇总**：汇总页切到一个没有任何记录的周期 → 图表区显示「这个范围还没有记录」
      空态卡；KPI 区维持现状；切回有记录的周期图表恢复
- [ ] **T3 导出终态**：导出一次 TXT 或 PDF：生成期按钮上方出现进度条与
      「正在生成，最长约半分钟」；完成后 Snackbar「已生成 · 可分享」；分享面板点取消
      → 提示文件已生成、可在本页再次分享
- [ ] T3 续（空范围）：把导出范围设为无记录区间 → 空态提示，不产出近空文件
- [ ] **T4 记录行异常读屏**（任一台）：开 TalkBack，滑到带「!」的记录行 → 朗读含「有异常」；
      正常行不追加该词
- [ ] **T5 通知计时**：开始喂奶计时，锁屏或下拉通知：通知在走秒；有「暂停」与「结束」两个按钮
- [ ] T5 续：点「暂停」→ 通知变「已暂停」静态文案；点「继续」恢复走秒
- [ ] T5 续：点「结束」→ 拉起完成表单（计时**没有**被静默丢弃），保存后计时正常收口
- [ ] **M3 触觉**（系统触觉开启前提下）：记录保存成功、删除确认执行、计时开始/暂停、
      底部长按切宝宝 → 各有一次轻微触觉
- [ ] **M5 小组件**：桌面小组件跟随系统深浅色（深色系统下是深色底），颜色与 App 同一品牌色板
- [ ] **长辈模式**：设置里开长辈模式 → 过一遍记录页（顶栏、坞槽、时间条、二级面板、汇总）
      → 无重叠无截断；关掉后再过一遍 → 恢复正常（跟随系统字体缩放）
