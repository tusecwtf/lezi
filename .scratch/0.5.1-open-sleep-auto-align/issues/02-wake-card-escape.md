# 02: 来源角色开睡不再卡住醒来，醒来卡可改两端时间

**What to build:** 底栏和头像只认时间轴上看得见的开放睡眠。确认醒来看「这条是否仍投影
开放」，来源角色存量也能被指定醒来。失败时说「家里的状态刚变了」，不说「出了点小问题」。
醒来卡片上：醒来时刻人人可改；**睡下时刻仅当能管理这条 SleepStart 时可改**（作者本人含
其它设备，或 Owner——与时间轴编辑同一条权限）。有权时确认可同时写下睡下主时间（仅当
有改动）和 WakeObservation；无权时睡下保持只读，确认只写醒来，不得因睡下把整单失败。
醒来仍须晚于睡下。不开放醒来卡删除整条睡眠。工作树里的底栏/分类对齐保留，不回退。

**Blocked by:** None (can start immediately)
