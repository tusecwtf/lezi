## 2. 计划逻辑优化（分波）

原问题：同步串行过长，05/08 与 01 关系含糊，03 易被冒烟跳过。

```text
波次 A 并行:  01 Sync │ 04 PDF │ 06 类型 │ 07 测量
波次 B:       02 邀请（←01）│ 05/08 本机可先做，同步栏←01
波次 C:       03 双机 60s（←02）
波次 D:       09 冒烟（←01–08，硬含 03）
```

| 优化 | 说明 |
|------|------|
| 05/08 分栏验收 | **本机 Must** 不阻塞在 01；**同步 Must** 写明依赖 01/02 |
| 09 硬依赖 03 | 无双机报告不得关门 |
| 04 与同步解耦 | 缩短「能导出 PDF」路径 |
| 关键路径 | `01→02→03→09` 为同步最小链 |
