## 验收标准（Must）

- [x] 选宝宝与日期范围可生成 PDF 文件
- [x] PDF 含封面或标题 + 至少一条日志可读文本
- [x] 可选含图：有日记图时可选嵌入（失败则明确降级）
- [x] 系统分享面板可调起
- [x] 无会员/水印付费墙
- [x] 自动化：生成文件 size&gt;0 且路径可读
