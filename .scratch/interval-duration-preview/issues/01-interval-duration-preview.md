# 01 — 区间时长预览与短校验

**Parent:** [../spec.md](../spec.md)

**What to build:** 照护者在睡眠或 Interval（如散步）快记/编辑半屏里选好起止时刻后，在时间控件正下方立刻看到与时间轴列表一致的「时长 …」；仅睡下或尚无结束时不冒充已完成时长；区间未完成或不合法时同一位置给短警示，并禁用确认，直到区间合法。区间相关校验句、预览警示与圆盘拒收主句共用短文案表；睡眠跨夜选错日期被拒时额外提示先改次日。

**Blocked by:** None — can start immediately

**Status:** done

## Acceptance criteria

- [x] 编辑已完成睡眠 / 补记整段（含「同时记醒来」且已有结束）/ 确认醒来（已有结束）时，起止时间控件下显示合法预览：`时长 X小时Y分` 或 `时长 不足1分`，规则与列表摘要一致
- [x] 仅确认睡下（结束为空、合法进入进行中）时不显示合法时长预览
- [x] 需要结束但未选结束时，时间下始终显示短提示（睡眠「请选择醒来时刻」/ Interval「请选择结束时刻」），确认 disabled
- [x] 结束 ≤ 开始、结束或开始在未来时：时间下短警示（睡眠「醒来须晚于睡下」等；Interval「结束须晚于开始」；未来统一「不能选未来时刻」），不显示误导性时长数字，确认 disabled
- [x] 区间恢复合法后确认立刻可点（非忙碌时）；取消始终可点
- [x] 睡眠圆盘因结束 ≤ 开始拒收：主句为短句，并附加「跨天请先把日期改为次日」；不写入非法结束，草稿保持上一合法值；Interval 拒收仅短句
- [x] 母乳/配方奶手填分钟等非起止区间类型不出现本票的区间时长预览
- [x] 不做异常偏短/偏长软提醒
- [x] 快记草稿主接缝单测覆盖：合法预览、仅睡下无预览、醒来/完整段有预览、非法与未选结束短文案 + 不可确认、Interval 分词、不足 1 分、旧长句期望已更新为短句表
