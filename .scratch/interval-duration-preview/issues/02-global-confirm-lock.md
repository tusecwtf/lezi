# 02 — 全局确认锁定与「打开不吼」

**Parent:** [../spec.md](../spec.md)

**What to build:** 任意类型快记草稿在校验失败时，确认/保存按钮立刻不可点；用户一打开表单若默认还不合法（如母乳左右为 0、日记正文空），不要立刻用红字呵斥——底部错误仅在改过相关字段或点过一次确认后再出现。区间类仍以时间下说明为主，非法时底部不重复同一句。取消始终可走；编辑删除不因草稿校验失败而灰掉。

**Blocked by:** 01 — 区间时长预览与短校验

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 全类型：`validationError != null` 时主确认 disabled（仍受保存中/删除中等忙碌态约束）
- [ ] 非区间类型：底部展示校验原因，但仅在草稿已 dirty 或用户点过一次确认后显示；打开瞬间非法只灰确认、不立刻红字
- [ ] 区间类型：时间下预览/警示为主；区间非法时底部不重复同一句时间下警示
- [ ] 取消在非忙碌时始终可点；编辑态删除不因校验失败禁用
- [ ] 草稿接缝单测：母乳 0+0、空日记等不可确认；`showValidation`（或等价）在未 dirty 且未尝试确认时为 false，dirty 或尝试确认后为 true
- [ ] 与 01 的区间可确认态兼容：合法醒来默认结束等路径在其它字段也合法时可直接确认
