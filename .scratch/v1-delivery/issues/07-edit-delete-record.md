# 07 — 编辑与删除记录

**Parent:** [.scratch/v1-delivery/spec.md](../spec.md)

## What to build

用户点时间轴条目进入编辑页，可改**时间 / 量 / 备注**等类型相关字段并保存；删除需**确认**；保存或删除后时间轴、日汇总、（若已有）时间条立即与数据一致。领域侧 CareLog `update`/`delete` 可单测。

## Blocked by

02 — 快记配方奶/尿尿 + 时间轴 + 日汇总

## Status

ready-for-agent

## 交付物

### 用户可见

- 点时间轴 cell → 编辑页：类型标题（中文）· 时间 · 类型特化字段 · 备注 · 保存 / 取消 / 删除
- 至少支持本阶段已有类型的关键字段编辑：`formula.amount_ml`、通用 `timestamp`、`note`；sleep 起止若已有则可改
- 删除：一次确认对话框（中文）；确认后条目从时间轴消失
- 保存/删除后：日汇总数字立即正确；已实现时间条则刷新

### 工程产物

- CareLog：`updateRecord` / `deleteRecord`（软删 `deleted_at` 优先，与 data-model 一致）
- 删除后查询默认排除已删；汇总不计入已删
- domain 单测：改 ml 后汇总变化；删除后 timeline 条数与汇总变化

## 验收标准

### Must（可测 / 自动化优先）

- [x] **改量**：formula 160 → update 为 200 → 读回 `amount_ml==200`；当日 feedMl **== 200**（仅此一条时）
- [x] **改时间跨日**：记录从日 D1 改到 D2 → D1 timeline 不再包含；D2 包含；两日汇总随之迁移（误差 0）
- [x] **改备注**：`note` 从空→「补记」→ 读回字符串完全相等
- [x] **删除**：delete 后默认 `timeline` **不含**该 `client_uuid`；feedMl/尿次等汇总减去该条贡献（误差 0）
- [x] **软删**：若用 `deleted_at`，物理行可仍在但查询层过滤；重复 delete 幂等不炸
- [x] **乐观/立即一致**：update/delete 返回成功后，同进程内立刻 query 已是新状态（无需第二进程）

### 可人工冒烟

- [x] 点条目改配方奶 ml 并保存，时间轴摘要与日汇总立即变
- [x] 点删除 → 确认框 → 确认后条目消失；点取消则仍在
- [x] 编辑页取消不保存时，数据与进入前一致
- [x] 中文：保存、取消、删除、确认文案完整
