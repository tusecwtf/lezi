# 13 — 配方奶 5ml 步进 + UI 与设置同步

**Parent:** [../spec.md](../spec.md) · 需求 B · PRD §4.1.1  
**Delta:** 相对初版 V1 默认 10ml → **默认 5ml**，且录入 UI 必须与 `amount_step_ml` 绑定。

**What to build:**  
配方奶（及挤出乳 ml 录入）**默认 5ml 一档**；加减按钮、快捷量芯片、选择式列表间隔均等于当前步进；设置可改为 5/10/15；改后**下次打开录入页立即同步**；数字键盘仍可手输任意 ml；上次量居中。

**Blocked by:** 02 — 快记配方奶/尿尿 + 时间轴 + 日汇总  

**Status:** done

## 交付物

| 类型 | 内容 |
|------|------|
| 用户可见 | 配方奶录入：± 按步进；芯片按步进；可选设置改步进 |
| 工程 | `SettingsLocal.amount_step_ml` 默认 **5**；录入 ViewModel/状态订阅步进；单测 |
| 共用 | `formula` / `pumped_feed` / `pump_express` 的 ml UI 同行为 |

## 验收标准（Must）

### 默认与渲染

- [x] 未改设置时 `amount_step_ml == 5`
- [x] 打开配方奶录入：点「+」一次，ml **增加 5**（例 120→125）
- [x] 点「-」一次，ml **减少 5**（到底限不再减或禁用）
- [x] 快捷芯片间隔为 5 的倍数（或由步进生成），点击后输入框 = 芯片值
- [x] 选择式列表相邻候选差的绝对值为 **5**（默认步进下）

### 设置同步

- [x] 设置将步进改为 **10** → 关闭再打开配方奶页 → 「+」变为 +10
- [x] 改为 **15** → 同理 +15
- [x] 改回 **5** → 恢复 +5
- [x] **无需杀进程**：仅离开录入页再进入即可看到新步进（同一次 App 会话）

### 手输与汇总

- [x] 数字键盘可输入 123 等非步进倍数并保存；时间轴显示 123
- [x] 日汇总奶量仍为实际 ml 之和（误差 0）

### 共用类型

- [x] 喂挤出乳或挤奶（若入口已有）的 ml 控件使用同一 `amount_step_ml`

### 单测

- [x] 默认步进 = 5
- [x] 设置 15 后，领域「步进候选序列」相邻差为 15
- [x] 保存任意 ml 不强制对齐到步进倍数

## 验收标准（Should）

- [x] 上次量居中显示在选择式列表
- [x] 步进设置项中文：「配方奶剂量步进」选项 5/10/15 ml
