# 09 — 多宝宝切换 + 主题色 + 深色模式

**Parent:** [.scratch/v1-delivery/spec.md](../spec.md)

## What to build

用户可**添加第二宝宝**并切换当前宝宝（点昵称 / 长按相关 Tab），记录**不串孩**；每宝宝**主题色**驱动顶栏/强调色；菜单**一键深色**护眼。可选：长按昵称跳到兄/姐相同日龄那天。

## Blocked by

- **硬依赖**：01 — 工程骨架 + 创建首个宝宝  
- **完整体验建议**：02 完成后再验收「切换后时间轴/汇总跟随」（数据隔离单测不依赖 02 UI）

## Status

ready-for-agent

## 交付物

### 用户可见

- 宝宝管理：添加宝宝（昵称/性别/生日/主题色）；编辑已有宝宝（含可选预产期字段可先存）
- 切换当前宝宝：
  - **点昵称**打开切换列表/下拉（必须）
  - **长按**「记录 / 汇总 / 成长」Tab 快捷切换（V1 至少一种 Tab 长按可用；PRD 要求相关 Tab）
- 切换后：顶栏昵称、主题色、时间轴、日汇总均为新宝宝数据
- 每宝宝主题色明显区分（顶栏背景或主强调色随宝宝变）
- 菜单月亮按钮或等价：**一键深色**；再点回浅色；重启后偏好保持（SettingsLocal）
- 可选 must-not-block：长按昵称 → 若存在兄姐，跳到「当前宝宝日龄 = 兄姐当日日龄」的历史日

### 工程产物

- CareLog：`addBaby`、`switchBaby`/`setCurrentBaby`、`listBabies`；记录查询强制 `baby_id`
- Baby.`theme_color` 持久化；当前宝宝 id 本机偏好
- `dark_mode` 在 SettingsLocal
- domain 单测：多宝宝写入互不污染

## 验收标准

### Must（可测 / 自动化优先）

- [x] **隔离写入**：宝宝 A 记 formula 100、宝宝 B 记 formula 50 → A 的 daySummary.feedMl **== 100**，B **== 50**
- [x] **隔离时间轴**：A 的 timeline 条数/id 集合与 B 不相交
- [x] **切换当前**：setCurrentBaby(B) 后「当前宝宝」读回 B 的 id/昵称
- [x] **主题色持久**：创建时 color=X，杀库再开读回 X
- [x] **深色偏好持久**：设 dark_mode=true → 重启代理读回 true
- [x] **添加第二宝宝**：listBabies 数量 **== 2**，字段完整

### 可人工冒烟

- [x] UI 添加第二宝宝并点昵称切换，顶栏昵称与记录列表立即切换且不串数据
- [x] 两宝宝选不同主题色，切换时顶栏/强调色可见变化
- [x] 长按记录 Tab（或汇总/成长）可切换宝宝（至少一种手势稳定可用）
- [x] 一键深色后主记录页背景与文字对比可读（夜喂不刺眼的主观通过即可）
- [x] 深色重启后仍保持
- [x] 中文：添加宝宝、切换、深色等文案

## 不在本票范围

- 兄姐同日龄跳转的精致动画（可选做，失败不挡 V1）
- 家庭成员多账号切换（V2）
- 主题色云同步（默认不同步）
- 成长修正月龄曲线（V1.5；预产期仅可存）
