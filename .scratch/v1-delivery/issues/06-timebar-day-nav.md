# 06 — 一日时间条 + 历史日导航

**Parent:** [../spec.md](../spec.md) · PRD §4.1、§5

**What to build:** 0–24h 喂养/睡眠色带；‹› 与跳日；非今日「返回今天」。

**Blocked by:** 02（有喂养数据即可；有 03/05 时色带更完整）

**Status:** done

## 交付物

| 用户可见 | 时间条、日期栏、返回今天 |
| 工程 | 时间条分段计算；按日查询 |

## 验收标准（Must）

- [x] **分段**：当日存在 formula/nursing 与 sleep 时，时间条上可见对应色段（位置与钟点大致一致，允许 UI 粗粒度）
- [x] **‹ ›**：切到昨天，时间轴与日汇总变为昨天数据；今日记录不出现
- [x] **跳日**：可跳到指定 YYYY-MM-DD，列表仅该日
- [x] **返回今天**：非今日时按钮可见，点击后 viewDate=今天且数据正确
- [x] **空日**：无记录日时间条不崩溃（空或占位）
