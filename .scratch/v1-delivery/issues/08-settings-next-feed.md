# 08 — 图标设置 + 下次喂奶本机提醒

**Parent:** [.scratch/v1-delivery/spec.md](../spec.md)

## What to build

用户可在设置中**排序/显隐**记录图标、**关闭喂奶计时入口**；记母乳/配方奶后可确认**下次喂奶**本机通知；拒绝通知权限后仍可完整记账。SettingsLocal 仅本机，永不进同步域。菜单提供清除全部数据的**多重确认**入口（对齐 PRD 4.1.7）。

> **配方奶步进 5/10/15 与录入 UI 同步** → 主责票 **13**。本票若放步进设置项，必须写入同一 `amount_step_ml`，且验收以 13 为准。

## Blocked by

- **硬依赖**：02 — 快记 + 时间轴 + 日汇总  
- **联调建议**：05 — 母乳计时（完成 nursing 后触发「下次喂奶」确认体验）；无 05 时至少 formula 路径可设提醒

## Status

ready-for-agent

## 交付物

### 用户可见

- **菜单/设置**分组（可精简但需可用）：
  1. 记录项目：图标排序、显隐  
  2. 喂奶：计时开关、记录时刻为开始/结束（若 05 已接）、提醒间隔（如 3h）  
  3. 显示相关可与 09 分工；本票至少不挡深色入口  
  4. 数据：清除全部 → **多重确认**（≥2 步）  
  5. 关于：应用名「乐记」等简短信息  
- 隐藏某类型后，记录页网格**立即**不显示该图标；排序后网格顺序一致
- 关闭 `timer_enabled` 后，记录页**无**喂奶计时入口
- 记 formula（及 nursing 若已有）后：可确认/调整下次喂奶时间；到点**本机通知**
- 拒绝通知权限：记账主路径仍可用，仅无提醒

### 工程产物

- `SettingsLocal`（DataStore 或等价）：`item_order_json`、`hidden_items`、`timer_enabled`、`amount_step_ml`、`nursing_interval_min`、`next_feed_at`、`record_at_start_or_end` 等
- 本机通知：NotificationCompat + 精确闹钟策略；系统不允许精确闹钟时**降级**（非精确或应用内提示），并在实现/注释中说明
- `RECEIVE_BOOT_COMPLETED`：重启后重挂未触发的下次喂奶闹钟（若 `next_feed_at` 仍在未来）
- Settings **不**经 SyncPort/家庭表同步
- 清除全部：CareLog 或专用 API，多重确认仅 UI，领域一次清除

## 验收标准

### Must（可测 / 自动化优先）

- [x] **显隐**：`hidden_items` 含 `pee` → 对外「可见图标列表」API/UI 模型**不含** pee；去掉隐藏后恢复
- [x] **排序**：设定 order [formula, pee, …] → 可见列表顺序**完全一致**
- [x] **计时开关**：`timer_enabled=false` → 「计时入口可见」为 false
- [x] **下次喂奶时刻**：间隔 180min，在 T 完成喂养并确认默认 → `next_feed_at` **== T+180min**（注入时钟，误差 0s 或 ≤1s 文档化）
- [x] **步进入口（若本票提供）**：写入 `amount_step_ml`；完整 UI 同步验收见 **13**
- [x] **无权限不阻断**：模拟通知权限 false 时，`addFormula`/`addPee` 仍成功
- [x] **Settings 非同步域**：SettingsLocal 存储路径不写入 Family/Record 同步实体；代码层无「push settings」调用
- [x] **清除全部**：确认执行后 Record 查询为空、汇总为 0；需 ≥2 次确认才调用清除（UI 冒烟 + 清除 API 单测）

### 可人工冒烟

- [x] 隐藏「尿尿」后网格立即消失；排序拖动后顺序保持
- [x] 关闭喂奶计时后记录页无计时按钮
- [x] 记一笔配方奶 → 确认下次提醒 → 将间隔改为 1 分钟（调试）可收到本机通知（或系统设置允许下）
- [x] 系统设置中拒绝通知后仍能记奶/尿，无崩溃
- [x] 清除全部：第一步确认后取消则数据仍在；走完多重确认后数据清空
- [x] 中文设置项标签可读

## 不在本票范围

- 深色模式完整 UI（→ 09；本票不阻挡入口即可）
- 真同步设置、云端备份
- TXT/PDF 导出入口实装（V1.5/V2；菜单可灰显「即将推出」）
- 自定义记录项目（V2）
- 伴侣端推送提醒（明确不做）
