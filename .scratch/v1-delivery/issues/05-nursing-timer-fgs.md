**Blocked by:** 02

| 用户可见 | 计时全屏、完成进时间轴的母乳记录 |

## 验收标准（Must）

- [x] **完成写库**：左运行 ≥10s、右 ≥5s 后完成 → 记录含 left/right 分钟（允许 0.1 误差）且 type=nursing
- [x] **关界面**：计时中回记录页再进计时，秒数继续（非归零）
- [x] **杀进程**：计时中 force-stop → 再开：要么恢复进行中秒数，要么明确已安全结束并提示；**禁止无提示丢状态**
- [x] **上次侧**：完成后再次打开计时，展示上次侧提示
- [x] **单测**：给定 leftSec/rightSec → payload 字段正确（可注入时钟）
- [x] **权限**：需 FGS 时声明合规类型；拒绝后有降级说明（若适用）

## 验收标准（Should）

- [x] 可设置记录时刻为开始或结束（设置项可与 08 共用）
