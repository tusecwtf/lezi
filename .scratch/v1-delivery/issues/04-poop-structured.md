# 04 — 排泄：尿尿大中小 + 便便分档图标

**Parent:** [../spec.md](../spec.md) · PRD §3.1 排泄记录

**What to build:**  
- **尿尿**：量档 **小 / 中 / 大**（图标选择）；默认可一键「中」。  
- **便便**：量 1–4 · 软硬 1–4 · 色 0–7；选择器与时间轴 **图标化**（非纯文字）。  
- **尿+便**：同时采集尿尿量 + 便便三字段。  
- 图标资源自绘或合规素材（见 `docs/prd/assets-notes.md`）。

**Blocked by:** 02

**Status:** done

## 交付物

| 类型 | 内容 |
|------|------|
| 用户可见 | 尿尿三档图标；便便三行图标芯片；时间轴图标摘要 |
| 工程 | `pee_amount`；stool_* payload；excretion 图标资源；单测 |

## 验收标准（Must）

### 尿尿

- [x] 可保存 `pee_amount` ∈ {1,2,3}，默认 **2（中）**
- [x] UI 为 **三枚图标**（非仅文字），选中态可辨
- [x] 一键路径：点尿尿默认记「中」≤2 次操作完成
- [x] 可改为小/大；时间轴摘要含档位图标或「小/中/大」
- [x] 日汇总 **尿次** +1（按次，不按量加权）

### 便便

- [x] 可不填结构字段保存便便
- [x] 若填任一项 → 量/软硬/色 **三者齐全**（单测）
- [x] 枚举边界：量 1–4、软硬 1–4、色 0–7
- [x] 选择器每档有 **独立图标**（色档至少以色块+外形区分）
- [x] 时间轴展示量+软硬+色的 **图标组合**（可附短文案）
- [x] 单独便便 → 日汇总便次 +1

### 尿+便

- [x] 一次写入后日汇总 **尿+1 且 便+1**
- [x] 可带 `pee_amount` 与便便三字段

### 资源

- [x] 资源不包含 Piyo 商标素材；路径/清单可对照 `assets-notes.md`

## 验收标准（Should）

- [x] 深色模式下图标对比度可辨
- [x] 无障碍：contentDescription 含「尿尿中量」等文案

## 不在本票范围

- 周排泄图（V1.5）、照片必选、医疗诊断文案
