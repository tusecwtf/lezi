# 02 — 快记配方奶/尿尿 + 时间轴 + 日汇总

**Parent:** [../spec.md](../spec.md) · PRD §3–4.1、§6.1

**What to build:** 图标一键/简表记配方奶(ml)、尿尿；时间轴新→旧；日汇总奶量与尿次与数据一致。

**Blocked by:** 01

**Status:** done

## 交付物

| 类型 | 内容 |
|------|------|
| 用户可见 | 记录页图标网格、时间轴、日汇总 chips |
| 工程 | CareLog `addRecord`/`dayRecords`/`daySummary`；单测 |

## 验收标准（Must）

- [x] **配方奶**：选/输 120ml 保存后时间轴摘要含「120」与类型名；**日汇总奶量 = 当日 formula(+后续可累加类型) ml 之和**，与手动加总差为 0
- [x] **尿尿**：1 击写入（默认量档「中」，详见 **04** 图标三档）；日汇总尿次 +1
- [x] **顺序**：同日 2 条记录，较新的排在列表上方（默认新→旧）
- [x] **相对时间**：条目显示「N 分钟/小时前」类文案
- [x] **持久化**：force-stop 后两条仍在且汇总不变
- [x] **单测**：固定 2 条 formula(100,50)+1 pee → milk=150, pee=1
- [x] **归属**：记录 `babyId` = 当前宝宝

## 验收标准（Should）

- [x] 1–2 tap 完成尿尿（默认中量）；配方奶 ≤3 次主要操作

## 不在本票范围

- 便便/尿尿图标分档完整（→ **04**；本票尿尿可先默认中量无三图标）
