# 03 — 睡眠睡下/醒来 + 异常软标记

**Parent:** [../spec.md](../spec.md) · PRD §4.3

**What to build:** 睡下/醒来配对算时长；异常仍写入并标 `!`，不弹窗阻断；日汇总含睡眠分钟。

**Blocked by:** 02

**Status:** done

## 交付物

| 用户可见 | 睡下/醒来图标、时间轴睡眠摘要与 `!`、日汇总睡眠 |
| 工程 | CareLog 睡眠配对逻辑；单测 |

## 验收标准（Must）

- [x] **正常配对**：睡下 T0、醒来 T0+60min → 一条闭合睡眠 **duration=60±1 分钟**；日汇总睡眠分钟含 60
- [x] **异常不阻断**：连续两次「睡下」→ 第二次**写入成功**且至少一条带 **anomaly/`!`**；无模态死锁
- [x] **仅醒来**：无开放睡下时点醒来 → 写入成功并标异常（或产品等价策略，需文档一致）
- [x] **单测**：上述两场景纯函数/CareLog 断言通过
- [x] **不弹窗**：异常路径无 `AlertDialog` 强制确认才能继续记

## 不在本票范围

- 午睡着色、周睡眠图、修正月龄
