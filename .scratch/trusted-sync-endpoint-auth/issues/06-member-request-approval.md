# 06 — 普通成员申请并由管理员批准

**What to build:** 让普通成员声明家庭称呼和设备称呼，发送一条没有家庭数据权限的登录申请；管理员下次前台打开 App 时看到角标，并能批准为新成员或拒绝。批准后的设备领取独立 session 并完整同步。

**Blocked by:** 04 — 轮换设备会话并安全处理凭证丢失

**Status:** ready-for-agent

- [ ] 登录申请 24 小时过期，并返回高熵、仅限 status/cancel/一次领取 session 的 pending secret；公开 request ID 不能查询家庭或领取凭证。
- [ ] 服务端对来源请求速率和家庭待处理总量设限；申请在批准前不能调用成员、设备或同步 API。
- [ ] 申请设备显示「等待管理员确认」，可检查结果、取消并保持离线；不增加后台轮询、FCM 或系统 push。
- [ ] 管理员账户首页显示具有 TalkBack 数量语义的待确认角标，并可在「家庭成员与设备」中查看声明称呼、设备称呼和申请时间。
- [ ] 管理员可用唯一家庭称呼新建 membership 或拒绝；批准后设备只可成功领取一次 session，再执行可独立重试的完整同步。
- [ ] 普通成员看不到全家庭待处理列表；申请过期、拒绝和取消不创建 membership、Device 或 credential。
- [ ] Rust Router、Android coordinator 与 Compose 测试覆盖过期、限速、无权限、角标、批准、拒绝、单次领取和首次同步失败。
