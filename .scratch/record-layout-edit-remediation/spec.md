## 目标

让记录页布局编辑在视觉、拖放规则、持久化、无障碍和回归证据上形成一条可独立验收的生产路径：编辑界面延续当前“添加记录”的四列分类卡片风格，所有反馈与实际落点一致，完整设备布局以一个原子快照保存，并且触摸、TalkBack 与键盘操作共用同一套规则。

[`p1-redundancy-ui-debt/02`](../p1-redundancy-ui-debt/issues/02-layout-migration-residue-cleanup.md)
共同交付；旧表面清理只在 P1/02 实施，本目录不保留第二份清理票。

## 当前问题

- 编辑态采用独立的桌面图标墙表达，与当前“添加记录”的分类卡片页面割裂。
- Dock 的锁定“更多”和内部间隙可能被误判为拖出坞外；拖放边界可能在节点离开后继续参与命中。
- 类别标题没有形成可操作的排序表面。
- “本机已删除”在项目很多、小屏或字体放大时缺少有界布局和完整可读语义。
- 四槽、隐藏集合、类内序和类别序分开落盘，可能暴露混合快照。
- 空槽文案暗示可短按选择，但批准行为是日常短按无操作。
- 旧包装器、未消费参数和并行布局入口增加了重复实现与回归面。

## 锁定产品边界

1. 日常 Dock 始终为 **4 个可配置槽 + 固定“更多”**；“更多”不占槽，也不是投放目标。
2. 空槽必须保留，允许 0–4 个有效快捷方式；任何后台逻辑都不得自动补位。
3. 槽、隐藏集合、类内序和类别序均为设备本地布局，不进入家庭同步协议。
4. 编辑态的短按、拖动和无障碍动作都不得直接写入护理 Record；所有新建记录入口仍须打开 Composer，并在用户确认后才持久化事实。
5. 当前“添加记录”页面是布局编辑目录的视觉权威：分类标题、四列卡片、图标底板、字号、间距和主题 token 应共享或同源。
6. 编辑态不重复“常用补充”分区；常用关系只由底部四槽表达。
7. warm / journal、浅色 / 深色共用相同业务语义和布局不变量。

## 权威布局

```text
┌──────────────────────────────────────┐
│ 编辑布局                       完成  │
├──────────────────────────────────────┤
│ 分类标题                             │
│ [四列记录卡片，与“添加记录”同源]      │
│ ……目录滚动……                        │
├──────────────────────────────────────┤
│ 本机已删除（有界、可读、可恢复）       │
├──────────────────────────────────────┤
│ [槽0][槽1][槽2][槽3][更多·锁定]       │
└──────────────────────────────────────┘
```

进入全屏编辑态后隐藏记录页日期 chrome 和主导航 tabs，只保留“编辑布局 / 完成”的编辑顶栏。退出后恢复日常记录页，不改变用户当前日期上下文。

## 拖放契约

| 来源 | 目标 | 结果 |
|------|------|------|
| 目录项目 | 四槽之一 | 指派或替换；若已占另一槽则换位，保持唯一 |
| 已绑定槽 | 另一槽 | 两槽交换 |
| 已绑定槽 | 整个 Dock 外且不在删除区 | 只清空源槽 |
| 已绑定槽 | “更多”或 Dock 内间隙 | 无操作 |
| 目录项目 / 已绑定槽 | 本机已删除 | 本机隐藏，并清空所有指向它的槽 |
| 已删除项目 | 删除区外 | 恢复到所属类别当前可见末尾，不自动占槽 |
| 目录项目 | 同类别项目 | 类内精确落点排序 |
| 目录项目 | 其他类别 | 无操作 |
| 类别标题 | 另一类别标题 | 类别排序 |

一个 pointer 位置在任一时刻只能对应一个当前可见目标；视觉高亮必须与最终 reducer intent 完全一致。

## 持久化契约

完整 `DeviceLayoutSnapshot` 至少包含：精确四槽、隐藏/本机已删除集合、类内项目序、类别序和必要的布局版本。一次用户意图只提交一个完整快照；观察者不能看到部分字段先后变化。快速连续操作按用户顺序归约，最后成功快照获胜。写入失败保留上一份有效快照，并向编辑界面提供可重试结果；完成或系统返回不能把尚未耐久的最后快照伪装为成功。

## 无障碍契约

拖放继续是触摸主路径，但不是唯一可执行路径。TalkBack 和键盘用户必须能够通过语义动作完成槽位指派/换位/清空、隐藏/恢复、项目排序和类别排序。语义动作只能发出与触摸相同的布局 intent，并通过同一个原子快照 writer 持久化。

日常空槽短按为 no-op，其标签不得声称会打开选择器；编辑态空槽则应如实说明可在编辑中指派。所有动作具有名称、当前状态、成功或失败反馈，且热区不小于 48dp。

## 测试与验收原则

- 纯 reducer / 命中解析测试锁定业务不变量，不用像素拖距替代规则断言。
- Compose 测试锁定当前节点注册、互斥高亮、语义动作和关键 chrome。
- 持久化测试必须覆盖并发连续意图、写失败、取消、重启和混合快照负例。
- 最终设备回归覆盖进入、完整拖放矩阵、完成/返回、force-stop 重进、两套视觉主题和 TalkBack/键盘。
- 任一票只有在自己的 Acceptance criteria、Validation 和 Documentation Gate 都有当前 HEAD 证据后才能标记完成。

## 不在本 tracker 范围

- 家庭共享布局或改变同步 wire。
- Record / CarePlan 领域模型重构。
- Widget 快捷方式与四槽联动。
- 新增第三套布局设置入口。
- 重新设计“添加记录”页面本身；本次只复用其当前视觉语言。
