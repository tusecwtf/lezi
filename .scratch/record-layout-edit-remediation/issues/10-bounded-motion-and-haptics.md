# 10 — 克制的编辑动效与限频触觉反馈

**What to build:** 让布局编辑静止状态保持稳定，只在触摸拖动的拾取、新合法落点和成功放下三个阶段提供短动效与限频触觉，使反馈清晰但不持续干扰或重复震动。

**Blocked by:** 03 — 当前可见且互斥的拖放目标

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 删除编辑页静止图标的持续晃动和对应无限动画；未拖动时四列卡片、分类标题、本机已删除和 Dock 均保持稳定。
- [ ] 长按成功拾取时提供一次短视觉与轻触觉反馈；未达到长按、手势取消或不可拖来源不反馈。
- [ ] 指针首次进入一个新的合法当前目标时反馈一次；停留在同一目标、目标内部移动或重组后仍是同一目标时不重复。
- [ ] 成功产生布局 intent 并被接受时提供一次放下确认；非法落点、no-op、自身落点、失败或取消不制造成功反馈。
- [ ] 进入删除区与普通目标的视觉状态除颜色外还有边框、形态或语义差异；反馈不造成卡片、Dock 或页面布局位移。
- [ ] 系统动画关闭/缩放后立即切换状态且业务不变；系统触觉关闭时不尝试补偿性重复震动，TalkBack/键盘路径依靠 Ticket 06 的语义反馈而非伪造触觉。
- [ ] 反馈状态以 Ticket 03 的权威当前目标为输入，不复制第二套命中判断；拖动结束、取消或节点失效后完整清理。
- [ ] 状态机与 Compose 测试覆盖拾取、目标切换、同目标停留、合法放下、no-op、取消、系统动画关闭和触觉调用限频。

## Validation

- 运行当前目标解析、拖动反馈状态机、动画关闭与 Compose 交互定向测试。
- 运行 `:feature:log:testDebugUnitTest`、相关 connected/Compose 测试、`:feature:log:lintDebug` 与 `:app:assembleDebug`。
- 在设备上分别以系统动画/触觉开启和关闭完成拾取、跨目标、合法放下、非法放下与取消 smoke，记录无持续晃动和无重复反馈。
- 运行 `git diff --check`，确认布局编辑不再保留无限晃动动画。

## Documentation Gate

更新布局编辑设计：静止卡片稳定，短动效与触觉只服务拾取、新合法目标和成功放下；记录系统动画/触觉关闭时的等价业务与无障碍反馈。
