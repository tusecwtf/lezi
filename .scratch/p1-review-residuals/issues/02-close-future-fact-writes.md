# 02 — 事实写入关闭未来时间（创建严 / 履行 +5 分钟）

**What to build:** 用户不能再通过新建护理记录、确认睡眠、完成母乳计时等**事实写入**路径把「尚未发生」的时间记成护理记录。未来时间只能走护理计划或显式「转为护理计划」。履行计划时，实际发生时间允许比设备当前时钟最多晚 **5 分钟**（含睡眠结束时间），以吸收确认瞬间的时钟与操作抖动。

**Blocked by:** None — can start immediately.

**Status:** done

**Severity:** P1  
**Lane:** immediate

- [x] 新建事实、睡眠确认、母乳完成等创建路径对时间点使用与现有「更新记录」相同的严格规则（0 时钟宽容）；睡眠闭区间结束时间不得落在未来。
- [x] 履行计划时，实际开始时间与睡眠结束时间允许 ≤ now + 5 分钟；超过则拒绝并给出可理解错误。宽容常量单源，单测覆盖边界（恰好 5 分通过、超过失败）。
- [x] 更新已有记录的未来时间规则保持「须走转为计划」语义，不与本票冲突。
- [x] 回归：创建路径拒绝未来 start/end；履行路径 5 分钟矩阵；既有 convert / update 行为不回退。
