# 02 — 本机布局策略：本机已删除 ↔ 目录末尾恢复 + 清槽

**What to build:** 记录项目可进入本机已删除（本机隐藏）；进入时所有指向它的常用槽立即清空；从本机已删除恢复时落入所属类别当前可见列表末尾，且不自动占回常用槽。允许目录被全部收进本机已删除。家庭级删除自定义定义不在本票范围。

**Blocked by:** 01 — 本机布局策略：常用槽指派 / 唯一换位 / 清空

**Status:** complete

- [x] 项目进入本机已删除后，日常目录可见集合不再包含它
- [x] 进入本机已删除时，所有等于该 key 的常用槽存储引用被清空（不是仅 resolve 时显示空白）
- [x] 从本机已删除恢复后，项目出现在所属类别当前可见顺序的末尾（不恢复隐藏前精确下标）
- [x] 恢复后常用槽不会自动重新绑定该项目
- [x] 允许全部记录项目进入本机已删除（无「至少保留一个」拦截）
- [x] 本机已删除不影响既有护理记录事实，也不触发家庭自定义定义 tombstone
- [x] 旧「隐藏保序恢复」「隐藏仍保留槽引用」类测试口径已改写或删除，新行为有单测
