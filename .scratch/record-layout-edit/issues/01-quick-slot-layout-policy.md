# 01 — 本机布局策略：常用槽指派 / 唯一换位 / 清空

**What to build:** 本机四个常用槽的指派、替换、槽间换位、清空与「同一记录项目不可占多槽（再指派则换位）」成为可单测的布局策略行为；长度恒为 4，空槽允许。尚不必上新的编辑 UI。

**Blocked by:** None — can start immediately.

**Status:** complete

- [x] 将记录项目指派到空槽后，该槽指向该项目，其余槽不变
- [x] 指派到已占用槽时覆盖该槽快捷方式，不把原项目送入本机已删除
- [x] 同一 catalog key 已在另一槽时再指派到目标槽 → 两槽内容换位，结果仍唯一
- [x] 槽间交换不改变槽位数（恒为 4）
- [x] 清空某槽只去掉快捷方式指针，不改变所有记录目录或本机已删除集合
- [x] 空槽允许（可同时存在多个空槽）
- [x] 上述不变量有 JVM 单测覆盖，且不依赖 Compose 拖拽几何
