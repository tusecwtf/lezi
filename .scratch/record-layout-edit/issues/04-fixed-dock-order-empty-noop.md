# 04 — 日常坞：固定四槽+更多在右；空槽短按无操作

**What to build:** 非编辑态常用坞从左到右固定为四个槽再「更多」，不再随惯用手镜像整坞；空槽短按无操作（不再打开槽位选择/设置）；已绑定槽与「更多」的日常记账路径保持。显示设置中的惯用手仍可用于圆盘等表单靠边。

**Blocked by:** 01 — 本机布局策略：常用槽指派 / 唯一换位 / 清空

**Status:** ready-for-agent
