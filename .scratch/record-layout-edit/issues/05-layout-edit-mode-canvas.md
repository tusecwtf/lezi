# 05 — 布局编辑态画布：长按进入 / 完成退出 + 拖放接线

**What to build:** 照护者在记录页长按记录项目图标进入布局编辑态；自动展开「上常用四槽 · 中分类所有记录 · 底本机已删除」画布；编辑态短按不记账；拖放与 ×/拖出清槽调用已落地的本机布局策略并持久化；完成或系统返回退出后日常页立即反映新布局。替换仅靠拖，不提供点选槽位列表。

**Blocked by:**
- 02 — 本机布局策略：本机已删除 ↔ 目录末尾恢复 + 清槽
- 03 — 本机布局策略：类内序 + 类别序（编辑意图）
- 04 — 日常坞：固定四槽+更多在右；空槽短按无操作
