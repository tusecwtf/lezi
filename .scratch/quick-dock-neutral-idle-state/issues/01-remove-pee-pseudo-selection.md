# 01 — 消除快捷记录坞的尿尿伪选中态

**Parent:** [../spec.md](../spec.md)

**What to build:** 照护者打开记录首页时，所有未处于真实交互或领域状态的快捷记录槽位都呈现一致的中性容器；“尿尿”仍保留自己的名称、图标和类型色，但不再像已选中。左右手布局、用户排序以及打开预填记录面板的行为保持不变。

**Blocked by:** None — can start immediately

**Status:** in-progress（自动化完成，device pending）

## Acceptance criteria

- [x] 空闲“尿尿”与其他空闲记录槽位使用相同的中性容器语义，不再按记录类型固定应用主题填充色
- [x] 名称、图标和类型色继续区分尿尿、睡眠、母乳、配方奶及更多入口；修复不把所有图标改成同一种颜色
- [x] 左手、右手及用户自定义顺序下结果一致：位置变化不产生或移动伪选中态
- [x] 打开、取消或确认预填记录面板后，快捷槽位不遗留 selected、checked、focused 或固定高亮语义
- [ ] `warm` 与 `journal` 在浅色模式均无尿尿伪选中态；深色模式保持可读对比且无同类误导
- [x] 快捷槽位顺序、惯用手镜像、触控热区、启用/隐藏设置、睡眠动作文案及统一记录面板路由保持现有行为
- [x] PRD明确“最高频入口”只约束位置和可达性，空闲槽位不得仅因记录类型而显示选中或强调状态
- [x] 自动化回归在当前尿尿类型特判上失败，并覆盖至少两个记录类型、左右手和一次自定义顺序；修复后目标测试与相关模块构建通过
- [ ] 记录首页完成 `warm`、`journal` 代表性设备宽度视觉验证，并保存可复核的验证结论
