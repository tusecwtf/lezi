# 01 — 家庭称呼可认

**What to build:** 建家/加入时必须填写自由文本**家庭称呼**（引导「我是宝宝的？」）；成员列表能认出每人称呼且管理员标 ★；本人可改自己的称呼；系统永不把「我（本机）」上传或展示给他人；并为时间轴上传者解析备好**可链到称呼的数据源**（不依赖账户首屏改版）。

**Blocked by:** None — can start immediately.

**Status:** done

**Size:** L  
**Seams:** S2, S4（触 S3 数据前提）

- [x] 建家/加入时家庭称呼硬必填；空白不可完成（客户端拦截；服务端空名 422，不再静默收成 null）
- [x] 引导语含「我是宝宝的？」；称呼为自由文本，非亲属枚举芯片
- [x] 不得上传「我（本机）」；他人视图永不出现该占位文案
- [x] 成员安全投影仍只含称呼 / role / is_self（及解析上传者所需的最小可链键，若采用）；不暴露 token
- [x] 成员行展示称呼；管理员 ★；历史空名用角色或「家人」兜底
- [x] 仅本人可改自己的称呼；不能改他人
- [x] 上传者解析源就绪：后续 05 能把非本机记录解析为当前家庭称呼（写清映射策略，禁止裸奔 device id 给用户）
- [x] Out of scope：踢人、照护者一等实体、账户首屏 IA 大改（留给 03）、时间轴 UI（留给 05）
- [x] S2/S4 测试覆盖必填、禁占位名、改自己称呼、members 投影
