# 乐记 PRD 对齐与验收记录

## 交付范围

本原型是「乐记」宝宝日常记录产品的移动端优先交互原型。以同目录 `index.html`、`styles.css`、`components.css`、`app.js` 构成可运行版本；视觉方向冻结为 390×844 紧凑移动端（奶油/浅蓝/浅黄/暖灰 + 砖红 FAB），无 hero/营销页。

## 信息架构

| 导航 | 首要任务 | 已实现表面 |
| --- | --- | --- |
| 记录 | 快速记下当下 | 紧凑宝宝/日期、今日摘要 5 格、24h 三行时间轴、最近记录、快捷入口、FAB（仅本页） |
| 汇总 | 看懂一天规律 | 日/周/月、喂养/睡眠/尿布指标、节律条、睡眠片段、四类趋势与对比、空状态 |
| 成长 | 追踪发育变化 | 身高/体重/头围、WHO 示例参考线、修正月龄、历史表、空状态 |
| 账户 | 管理宝宝与家庭 | 多宝宝、本机 ID、无需登录、家庭三入口 Stub |
| 菜单 | 收纳低频能力 | 搜索、状态演示、深色、记录设置、项目显隐/排序、导出 TXT、两步清除、关于 |

## 功能对齐

### §0 视觉重心

- [x] 首页：宝宝/日期 → 今日摘要 5 格 → 24h 时间轴 → 最近记录；快捷网格在后
- [x] FAB 砖红/陶土色，仅记录页；五栏导航；触控 ≥48px；无横向页面滚动

### §1 记录类型与高频路径

- [x] 母乳：左右计时、暂停/继续/结束；状态写入 `localStorage`（`leji-session-v1`）；跨页 session bar
- [x] 配方奶 / 喂挤出乳 / 挤奶：奶量与备注可保存
- [x] 小便、洗澡：一点击即写入并 Toast
- [x] 便便：便量 4 档、稠度 4 档、颜色 8 档；独立便与尿+便表单一致
- [x] 都有：打开尿布表单并默认尿+便
- [x] 睡眠：开始/醒来计时主路径 + 手动起止次路径；异常时长软提醒不阻断
- [x] 体温：℃/℉；月龄&lt;3 且 ≥38℃ 非阻断就医提示
- [x] 备忘、日记（正文 + 照片占位）、散步、症状、用药、就医、其他
- [x] FAB 首屏高频 +「更多」渐进披露

### §2 今日页

- [x] 摘要 5 项：奶量 ml、母乳分钟、睡眠、尿次数、便次数（体温不占 5 格）
- [x] 日期/日历切换；最近记录可编辑类型专属字段并删除
- [x] 摘要/时间轴/列表自动重算

### §3 汇总

- [x] 日/周/月
- [x] 四块趋势：喂养、睡眠、尿布、体温；较上一周期对比；可点击空状态
- [x] 原生 CSS 图，无外链

### §4 成长

- [x] 体重/身高/头围切换与历史表
- [x] WHO 示例 P3/P50/P97 参考线 +「WHO 示例数据源 · 仅供趋势参考」
- [x] 预产期字段 + 修正月龄开关（有预产期时显示）
- [x] 可演示成长空状态

### §5 账户与家庭 Stub

- [x] 「数据仅保存在本机」「无需登录」+ 稳定本机 ID
- [x] 成员仅本机；按钮文案：**新建家庭 / 输入邀请码 / 扫码加入**
- [x] 三入口统一反馈：**家庭同步将在后续版本开放**

### §6 菜单与设置

- [x] 记录项目显隐 + 上移/下移排序，影响首页快捷网格
- [x] 喂养设置：母乳计时入口、提醒间隔示例（仅本机，不发通知）
- [x] 相对时间、深色、12/24h、单位、减少动态
- [x] TXT 导出真实预览/下载；PDF 标后续版本
- [x] 清除数据：**两步确认**（继续 → 输入「清除」）
- [x] 状态演示：正常/加载/记录空/汇总空/成长空/记录中/保存成功/错误/离线/启动引导
