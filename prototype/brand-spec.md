# 乐记 · 品牌规范

## 品牌核心

**品牌名：乐记**
一句话：把宝宝每天的小事，记成一家人的成长史。

品牌气质是“安静、可信、有人情味”。界面以奶油色为底、浅蓝承载信息、浅黄提示温度；不做医疗化压迫，也不过度幼态。

## 核心色票

```css
:root {
  --bg: oklch(97.6% 0.012 86);
  --surface: oklch(99.2% 0.005 86);
  --fg: oklch(29% 0.035 252);
  --muted: oklch(55% 0.03 250);
  --border: oklch(88.5% 0.025 244);
  --accent: oklch(55% 0.12 236);
}
```

- 奶油背景 `--bg` 是主画布，不使用纯白铺满全屏。
- 浅蓝 `--accent` 只用于主操作、当前态与少量关键数据。
- 浅黄为签名辅助面，用 `color-mix()` 从 `--bg` 与语义黄色推导，不另立第二品牌主色。
- 深色模式维持相同冷暖关系：深蓝灰画布、柔白正文、低饱和蓝色强调。

## 字体

- 展示字：`"STKaiti", "KaiTi", "Noto Serif SC", serif`
- 正文字：`"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`
- 数字字：`"SFMono-Regular", "Cascadia Code", "Roboto Mono", monospace`

标题略带手记感，正文保持长时间记录时的可读性；数字统一等宽，便于时间和测量值快速比较。

## 版式与组件姿态

1. 以 390×844 单手使用为第一画布，内容最大宽度 760px，桌面端仍保留手机式信息密度。
2. 首页视觉重心固定为“宝宝今日状态 + 24h 时间条”，先看全局，再进入具体记录。
3. 卡片采用柔和面色与细边界，不使用彩色左边框；圆角统一 8px（与紧凑记录簿控件对齐），操作控件最小 48px。
4. 五栏导航常驻底部；复杂能力通过底部浮层与模态框渐进披露。
5. 图标统一为 1.8px 描边的单色 SVG，状态变化依靠文字、形状和颜色共同表达。
